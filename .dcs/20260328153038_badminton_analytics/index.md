## セッション概要

### アイデア
バドミントン分析アプリ「badkichi」のPRD作成。ダブルスの試合動画（YouTube/ローカル）を再生しながら、ショットタイミングとポイント結果を手動入力。バドミントンのルールを活用したルールエンジンで、最小限の入力からサービス/レシーブの得点率等の戦術分析を自動算出。蓄積データは将来のAI自動検出の教師データとしても活用。

### カテゴリ

### 優先度

## クイックサマリー

### 主要な要件（MVP）
1. ダブルスの試合管理（4人の選手、セット目標ポイント設定）
2. 動画再生（YouTube/ローカル）+ ショットタイミング・ポイント結果の手動入力
3. ルールエンジンによるサーバー/レシーバー自動推論
4. 統計ダッシュボード（サービス得点率、ラリー分析、動画ジャンプ）
5. 例外処理（レット、スコア修正、左右修正、得点者スキップ）

### 技術的な考慮事項
- Nuxt 3 + Nuxt UI + Supabase + ECharts
- YouTube IFrame API + HTML5 Video API
- 入力元・動画ソース・対戦形式の抽象化（将来の拡張性）

### 次のステップ
- `/tsumiki:kairo-requirements` で正式な要件定義書を作成
- PRD を入力として tsumiki の仕様駆動ワークフローに進む
