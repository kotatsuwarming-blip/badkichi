## タスク概要

video-playback ユニットの最終タスク。Phase 1-3 で個別実装した純関数・アダプタ・ローダー・
`useVideoPlayer` composable・`VideoPlayer.client.vue` を**結合**し、dataflow.md の主要フロー1-5 を
モック / jsdom ベースで統合検証する。あわせて責務境界（REQ-404 / REQ-405 / REQ-406）と
CSR 境界（REQ-401）を**静的 / 設計レビュー観点**で検証する。

検証対象の結合フロー（dataflow.md）:
1. **YouTube ロード〜再生**（フロー1）: `attach` → `mount` → 状態反映 → `play`
2. **ローカルロード〜再選択**（フロー2）: `needsReselect` → 再供給 → 復帰
3. **「打った」瞬間の現在時刻取得**（フロー3）: `getCurrentTimeMs` 同期即時 / 未ロード `null`
4. **指定 ms シーク**（フロー4）: `seekToMs` の `clampMs` 境界
5. **オーバーレイスロット表示**（フロー5）: slot props（`durationMs` / `currentTimeMs` / `status`）供給

> **重要（テスト範囲の明示）**: video-playback は外部 API（YouTube IFrame API / HTML5 Video API）に
> 依存するため、本タスクの統合テストは**モック / jsdom ベース**で composable + component を結合検証する
> 範囲に限定する。実ブラウザ E2E は MVP 範囲外であり、上位ユニット（match-recording /
> stats-dashboard）統合時に実施する。

> テスト方針（memory `feedback_test_coverage`）: 境界値 + 分岐網羅を最小限。冗長ケースは作らない。
> 純関数 / アダプタ単体は Phase 1-3 でカバー済みのため、本タスクでは**重複させず結合経路のみ**を検証する。

## 実装詳細

### 1. 結合フロー検証（モック / jsdom） 🔵

**信頼性**: 🔵 *dataflow.md フロー1-5*

`useVideoPlayer` composable と `VideoPlayer.client.vue` を結合し、外部 API はモックで差し替えて
jsdom 上で検証する。YouTube IFrame API（`window.YT`）と HTMLVideoElement のメソッド / プロパティ
（`play` / `pause` / `currentTime` / `duration` / イベント）をモック化し、アダプタ経由の状態反映が
composable の reactive state へ伝播することを確認する。

**テストファイル**: `tests/unit/components/VideoPlayer.flow.test.ts`

検証経路（重複回避のため結合点のみ）:

- **フロー1（youtube）**: `useVideoPlayer({ type: 'youtube', url })` → `attach(el)` → モック
  `YT.Player` の `onReady` / `onStateChange` 発火 → `state.status` / `state.durationMs` 反映 →
  `controls.play()` がアダプタの `playVideo()` を呼ぶ
- **フロー2（local）**: `useVideoPlayer({ type: 'local', file })` → `attach(el)` → モック video の
  `loadedmetadata` → `state.durationMs` 反映 → `controls.play()` 反映
- **フロー2 再選択**: `file` なし（失効相当）で `state.needsReselect = true` → file 再供給で
  `attach` 復帰 → `needsReselect = false`
- **フロー3**: `controls.getCurrentTimeMs()` が**同期的**に ms 整数を返す（ポーリングなし）。
  未ロード（`durationMs = null`）状態で `null` を返す（NaN / 負値を返さない）
- **フロー4**: `controls.seekToMs(ms)` がアダプタ内 `clampMs` を経て 0〜duration に丸めてシークする
  （0 / duration / 超過 / 負値の境界）
- **フロー5**: `VideoPlayer.client.vue` を `@vue/test-utils` でマウントし、`timeline` / `overlay`
  スロットへ slot props（`durationMs` / `currentTimeMs` / `status`）が渡ることを確認する

### 4. CSR 境界の確認（TC-401-01） 🔵

**信頼性**: 🔵 *requirements.md REQ-401 / ADR-010*

## 統合テスト要件

**テストファイル**: `tests/unit/components/VideoPlayer.flow.test.ts`
方針: 最小・境界中心。冗長ケースは作らない。youtube / local の両系統を最小ペアでカバーする。

### 統合TC-1: youtube 結合フロー（フロー1 / TC-001-01, TC-003-01） 🔵

**信頼性**: 🔵 *dataflow.md フロー1*
**Given**: `useVideoPlayer({ type: 'youtube', url })` と モック化された `YT.Player`
**When**: `attach(el)` 後にモックが `onReady` / `onStateChange` を発火し、`controls.play()` を呼ぶ
**Then**: `state.status` / `state.durationMs` が反映され、`play()` がモックの `playVideo()` を呼ぶ

### 統合TC-2: local 結合フロー + 再選択（フロー2 / TC-001-02, TC-103-01, TC-103-02） 🔵

**信頼性**: 🔵 *dataflow.md フロー2*
**Given**: `useVideoPlayer({ type: 'local', file })` と モック video 要素
**When**: file あり → `loadedmetadata` 発火 / file なし → 再生試行 → file 再供給
**Then**: file あり時は `durationMs` 反映・再生開始、file なし時は `needsReselect = true`、
再供給後に `attach` 復帰し `needsReselect = false`

### 統合TC-3: 現在時刻取得（フロー3 / TC-004-01, TC-004-02, TC-004-B01） 🔵

**信頼性**: 🔵 *dataflow.md フロー3 / NFR-001 / REQ-201*
**Given**: 再生中 / 未ロードの 2 状態
**When**: `controls.getCurrentTimeMs()` を呼ぶ
**Then**: 再生中は同期的に ms 整数（`Math.round(sec*1000)`）を返し、未ロードは `null`
（NaN / 負値を返さない）。呼び出しはポーリングを伴わず即時に返る

### 統合TC-4: シーククランプ境界（フロー4 / TC-005-01, TC-005-B01/B02/B03） 🔵

**信頼性**: 🔵 *dataflow.md フロー4 / REQ-104 / EDGE-101*
**Given**: duration = D の再生可能状態
**When**: `controls.seekToMs` に 中間値 / 0 / D / D 超過 / 負値 を渡す
**Then**: 中間 / 0 / D はそのまま、超過は D に、負値は 0 にクランプしてアダプタのシークが呼ばれる

### 統合TC-5: オーバーレイスロット slot props（フロー5 / TC-008-01, TC-009-01, TC-009-02） 🔵

**信頼性**: 🔵 *dataflow.md フロー5 / REQ-008/009*
**Given**: `VideoPlayer.client.vue` を `timeline` / `overlay` スロット付きでマウント
**When**: state（`durationMs` / `currentTimeMs` / `status`）が更新される
**Then**: 両スロットへ slot props が渡り、`left = ms / durationMs` の配置算出が可能。
コントロール（再生 / 一時停止・シークバー・現在時刻 / 総時間・速度選択）が描画される

### 統合TC-6: 異常系・バッファ（TC-001-E01, TC-EDGE-001, TC-EDGE-003, TC-EDGE-004） 🔵

**信頼性**: 🔵 *dataflow.md エラーフロー / error-handling カテゴリ D*
**Given**: 無効 URL / モック onError / モック video error / buffering 状態
**When**: 各経路を発火する
**Then**: `state.error`（`youtube-invalid-url` / `youtube-load-failed` / `local-decode-failed`）が
設定され、buffering 時は `state.status = 'buffering'` で他操作を阻害しない
