## タスク概要

video-playback のエラー文言・再選択誘導文言を `videoPlayer.error.*` キーとして `i18n/locales/en.json`
と `i18n/locales/ja.json` の両方に追加する。`VideoPlayerError.messageKey` はこのキーを指し、
composable / コンポーネントは `messageKey` で文言を解決する（コードに文言を埋めない, error-handling
原則5）。`VideoPlayerErrorCode`（kebab-case）と locale の messageKey（camelCase）の対応を明示する。

## 依存タスク

- **前提タスク**: TASK-0001（型・`VIDEO_PLAYER_ERROR_CODE` 定義）
- **後続タスク**: TASK-0009（エラー/再選択 UI が本キーを `t()` で解決）

## 完了条件

- [ ] `i18n/locales/en.json` / `i18n/locales/ja.json` に `videoPlayer.error.*` を追加（両言語整合）
- [ ] 最低限のエラーキー: `youtubeInvalidUrl` / `youtubeLoadFailed` / `localDecodeFailed` / `localReselectNeeded`
- [ ] 再選択誘導文言: `reselectPrompt` / `youtubeRecommendation`、別動画導線文言 `specifyAnotherVideo`

- [ ] `pnpm typecheck` / `pnpm lint`（i18n キー存在チェックを含む場合はそれも）を通る

## 実装詳細

### 1. 既存 locale 構造の確認（破壊防止） 🔵

**信頼性**: 🔵 *既存 i18n/locales/*.json の構造維持*

追記前に `i18n/locales/en.json` と `i18n/locales/ja.json` を Read し、トップレベルのキー（`errors` /
`app` / `common` / `login` / `layout` 等）と nest 構造（camelCase オブジェクト）を確認する。
既存キーを変更・削除せず、新規トップレベルキー `videoPlayer` を追加する（en/ja で同一構造）。

### 2. VideoPlayerErrorCode → messageKey 対応表 🔵

**信頼性**: 🔵 *TASK-0001 VIDEO_PLAYER_ERROR_CODE / error-handling 原則5*

| VideoPlayerErrorCode (kebab) | messageKey (camel)                      | 用途 / 出典 |
|------------------------------|-----------------------------------------|-------------|
| `youtube-invalid-url`        | `videoPlayer.error.youtubeInvalidUrl`   | EDGE-002（再生前 URL 検証失敗） |
| `youtube-load-failed`        | `videoPlayer.error.youtubeLoadFailed`   | EDGE-001（動画ロード失敗 → 別動画導線併設） |
| `local-decode-failed`        | `videoPlayer.error.localDecodeFailed`   | EDGE-003（ローカル動画デコード失敗） |
| `local-reselect-needed`      | `videoPlayer.error.localReselectNeeded` | REQ-103（再読み込みで File 失効 → 再選択） |

UI 補助文言（エラーコードに直結しないが `videoPlayer.error.*` 配下に集約）:

| messageKey                               | 用途 |
|------------------------------------------|------|
| `videoPlayer.error.reselectPrompt`       | 再選択 UI の説明（「同じ動画を選び直してください」, REQ-103） |
| `videoPlayer.error.youtubeRecommendation`| 長時間記録は YouTube 推奨の UX 誘導（REQ-301） |
| `videoPlayer.error.specifyAnotherVideo`  | `youtube-load-failed` の「別動画を指定」導線ラベル（EDGE-001） |

### 3. locale JSON への追記 🔵

**信頼性**: 🔵 *error-handling 原則5*

既存トップレベルキーの末尾に `videoPlayer` を追加する（en は空文字・ja は実文言が既存方針）。

**en.json（追記イメージ）**:

```json
"videoPlayer": {
  "error": {
    "youtubeInvalidUrl": "",
    "youtubeLoadFailed": "",
    "localDecodeFailed": "",
    "localReselectNeeded": "",
    "reselectPrompt": "",
    "youtubeRecommendation": "",
    "specifyAnotherVideo": ""
  }
}
```

**ja.json（追記イメージ）**:

```json
"videoPlayer": {
  "error": {
    "youtubeInvalidUrl": "YouTube の URL が正しくありません。URL をご確認ください",
    "youtubeLoadFailed": "動画を読み込めませんでした。別の動画を指定してください",
    "localDecodeFailed": "この動画ファイルを再生できませんでした",
    "localReselectNeeded": "動画の参照が切れました。同じ動画を選び直してください",
    "reselectPrompt": "同じ動画を選び直してください",
    "youtubeRecommendation": "長時間の記録には YouTube のご利用をおすすめします",
    "specifyAnotherVideo": "別の動画を指定"
  }
}
```

※ 文言の最終文面は実装時に調整可。キー構造（en/ja 整合）と messageKey 命名は本表に従う。

## 注意事項

- ESLint 規約: JSON は no comma dangle（末尾カンマ禁止）。既存フォーマットに合わせる。
- en/ja で **同一のキー構造** を維持する（片方だけにキーを足さない）。
- messageKey 命名は対応表（camelCase）に厳密に従い、`VideoPlayerErrorCode`（kebab）と混同しない。
- 文言は locale JSON のみに置き、コード側に直書きしない（error-handling 原則5）。
- 既存トップレベルキー（errors / app / common / login / layout 等）を壊さない（追加のみ）。
