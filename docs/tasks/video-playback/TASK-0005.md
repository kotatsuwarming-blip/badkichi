## タスク概要
HTML5 Video API（`HTMLVideoElement`）を内部契約 `VideoPlayerAdapter extends VideoPlayerControls`（interfaces.ts §アダプタ）に適合させる Strategy アダプタを実装する。`LocalSource.file` から `URL.createObjectURL(file)` を生成して `video.src` に束ね、`HTMLMediaElement` のイベント／状態を統一値（`PlayerStatus` / `PlayerEvent`）へ変換する。時刻は **ms 単位 integer 統一**（`Math.round(video.currentTime * 1000)`）。`getCurrentTimeMs()` は未ロード時 `null`（REQ-201、NaN・負値を返さない）、ポーリングなし同期取得（NFR-001）。`seekToMs(ms)` は `clampMs(ms, durationMs)`（TASK-0003）で範囲補正してから `video.currentTime = sec` へ渡す（REQ-104）。エラーは cross-cutting カテゴリ D として `VideoPlayerError`（`code` + `messageKey`、生文字列比較禁止）で扱い、`error` イベントで `local-decode-failed`（EDGE-003）を emit する。`destroy()` で `URL.revokeObjectURL` し自動再アクセスしない（NFR-101）。

## 実装詳細
### 1. Html5Adapter の構造とライフサイクル 🔵
**信頼性**: 🔵 *architecture.md アダプタパターン §60 + interfaces.ts VideoPlayerAdapter + REQ-102/103 + NFR-101*
ファクトリ関数またはクラスで `VideoPlayerAdapter` を実装する（`use*` ではない＝Vue composable ではない、architecture.md §109）。`mount(el)` で渡された `HTMLVideoElement`（または `el` 内に生成した `<video>`）に対し、`LocalSource.file` から `objectUrl = URL.createObjectURL(file)` を生成して `video.src = objectUrl` を設定する。`loadedmetadata` で `durationMs` を確定し `durationchange` を発火。`destroy()` で `URL.revokeObjectURL(objectUrl)`・全リスナ解除・`video.removeAttribute('src')` を行い、セッション跨ぎの自動再アクセスをしない（NFR-101）。
**実装ファイル**: `app/utils/video-playback/html5-adapter.ts`
```ts
// app/utils/video-playback/html5-adapter.ts
import type { LocalSource, PlaybackRate, PlayerEvent, PlayerStatus, VideoPlayerAdapter, VideoPlayerError } from '~/types/video-playback'
import { clampMs } from './clamp'

export function createHtml5Adapter(source: LocalSource): VideoPlayerAdapter {
  let video: HTMLVideoElement | null = null
  let objectUrl: string | null = null
  let durationMs: number | null = null
  let status: PlayerStatus = 'unstarted'
  let lastError: VideoPlayerError | null = null
  const handlers: Record<PlayerEvent, Array<() => void>> = {
    statuschange: [],
    durationchange: [],
    error: [],
    ended: []
  }
  const emit = (event: PlayerEvent): void => {
    for (const h of handlers[event]) h()
  }
  const setStatus = (next: PlayerStatus): void => {
    if (next === status) return
    status = next
    emit('statuschange')
  }

  const onLoadedMetadata = (): void => {
    if (!video) return
    const sec = video.duration
    durationMs = Number.isFinite(sec) && sec > 0 ? Math.round(sec * 1000) : null
    emit('durationchange')
  }
  const onCanPlay = (): void => setStatus('paused')
  const onPlaying = (): void => setStatus('playing')
  const onPause = (): void => setStatus('paused')
  const onWaiting = (): void => setStatus('buffering')
  const onEnded = (): void => {
    setStatus('ended')
    emit('ended')
  }
  const onError = (): void => {
    // EDGE-003: 未対応コーデック/破損。識別子は const 集約・文言は locale JSON
    lastError = { code: 'local-decode-failed', messageKey: 'videoPlayer.error.localDecodeFailed' }
    emit('error')
  }

  return {
    async mount(el: HTMLElement): Promise<void> {
      video = el instanceof HTMLVideoElement ? el : el.querySelector('video')!
      objectUrl = URL.createObjectURL(source.file)
      video.addEventListener('loadedmetadata', onLoadedMetadata)
      video.addEventListener('canplay', onCanPlay)
      video.addEventListener('playing', onPlaying)
      video.addEventListener('pause', onPause)
      video.addEventListener('waiting', onWaiting)
      video.addEventListener('ended', onEnded)
      video.addEventListener('error', onError)
      video.src = objectUrl
    },
    destroy(): void {
      if (video) {
        video.removeEventListener('loadedmetadata', onLoadedMetadata)
        video.removeEventListener('canplay', onCanPlay)
        video.removeEventListener('playing', onPlaying)
        video.removeEventListener('pause', onPause)
        video.removeEventListener('waiting', onWaiting)
        video.removeEventListener('ended', onEnded)
        video.removeEventListener('error', onError)
        video.removeAttribute('src') // NFR-101: 自動再アクセスしない
      }
      if (objectUrl) URL.revokeObjectURL(objectUrl)
      objectUrl = null
      video = null
    },
    play(): void {
      void video?.play()
    },
    pause(): void {
      video?.pause()
    },
    seekToMs(ms: number): void {
      if (!video) return
      const clamped = clampMs(ms, durationMs) // REQ-104
      video.currentTime = clamped / 1000
    },
    setPlaybackRate(rate: PlaybackRate): void {
      if (video) video.playbackRate = rate
    },
    getCurrentTimeMs(): number | null {
      // REQ-201: 未ロード時 null（NaN・負値を返さない）
      if (!video) return null
      const sec = video.currentTime
      if (!Number.isFinite(sec) || sec < 0) return null
      return Math.round(sec * 1000)
    },
    getDurationMs(): number | null {
      return durationMs
    },
    getStatus(): PlayerStatus {
      return status
    },
    on(event: PlayerEvent, handler: () => void): void {
      handlers[event].push(handler)
    }
  }
}
```

### 2. 状態マッピング（HTMLMediaElement → PlayerStatus） 🔵
**信頼性**: 🔵 *interfaces.ts PlayerStatus + REQ-007 + EDGE-004（buffering）*
イベント駆動で `PlayerStatus`（`'unstarted' | 'buffering' | 'playing' | 'paused' | 'ended'`）へ統一する。初期値は `'unstarted'`、`canplay`/`pause` → `'paused'`、`playing` → `'playing'`、`waiting` → `'buffering'`、`ended` → `'ended'`。`paused`/`ended`/`seeking` の判定が必要な箇所では `HTMLMediaElement` の `paused` / `ended` プロパティを参照する。`setStatus` は前回値と同一なら `statuschange` を発火しない（冗長発火抑止）。

### 3. 時刻・シークの ms 統一とクランプ 🔵
**信頼性**: 🔵 *architecture.md §現在時刻取得 + REQ-104 / REQ-201 / NFR-001 + interfaces.ts clampMs*
`getCurrentTimeMs()` は `setInterval` を使わず呼び出し時に同期取得（NFR-001）。`Math.round(video.currentTime * 1000)`。未ロード（`video` 未生成）または `currentTime` が `NaN`/負値の場合は `null`（REQ-201）。`seekToMs(ms)` は `clampMs(ms, durationMs)`（負値→0 / 超過→duration、`durationMs` が null なら 0 以上に丸めるのみ）で補正後、秒へ変換（`clamped / 1000`）して `video.currentTime` に代入する（REQ-104 / EDGE-101）。

### 4. エラー（カテゴリ D） 🔵
**信頼性**: 🔵 *cross-cutting/error-handling カテゴリ D / 原則 3・5 + architecture.md §エラーハンドリング + EDGE-003*
`error` イベントで `VideoPlayerError`（`code: 'local-decode-failed'` / `messageKey: 'videoPlayer.error.localDecodeFailed'`）を生成して `error` イベントを emit する。`code` は `VideoPlayerErrorCode` の const union を使い**生文字列比較を禁止**、文言は locale JSON 側で解決する（コードに表示文字列を埋めない）。

## 注意事項
- 時刻は必ず **ms 単位 integer**。HTML5 API は秒 float のため `Math.round(sec * 1000)` を境界で必ず通す（生の秒値を上位へ漏らさない）。
- `seekToMs` は必ず `clampMs`（TASK-0003）を経由する。アダプタ内で独自に範囲判定しない（REQ-104 の一元化）。
- `getCurrentTimeMs()` はポーリング禁止（NFR-001）。`setInterval`/`requestAnimationFrame` を本アダプタに置かない（UI 進捗用 rAF は composable 側の責務）。
- `destroy()` の `revokeObjectURL` 漏れはメモリリーク＋失効後の自動再アクセスにつながる（NFR-101）。mount で生成した `objectUrl` を必ず破棄する。
- エラーは `VideoPlayerErrorCode` の const union を使う。`'local-decode-failed'` 等の生文字列を上位で直接比較しない（error-handling 原則 3）。
- `el` が `<video>` でない場合（ラッパ要素を渡された場合）の取得方法は VideoPlayer.client.vue（Phase 4）の DOM 構造に合わせて確定する。本タスクでは `HTMLVideoElement` 直渡し or 内部 `querySelector('video')` の両対応で実装する。
