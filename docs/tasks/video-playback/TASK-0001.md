## タスク概要

`design/video-playback/interfaces.ts` で確定済みの型定義を実コードへ落とし込む基盤タスク。
`app/types/video-playback.ts` に全型（`VideoSourceType` / `PlayerStatus` / `PlaybackRate` /
`VideoSource` union / `VideoPlayerErrorCode` / `VideoPlayerError` / `VideoPlayerControls` /
`VideoPlayerState` / `VideoPlayerAdapter` / `UseVideoPlayerReturn` / `VideoPlayerProps` /
`VideoPlayerSlotProps` / `VideoPlayerSlots`）と `PLAYBACK_RATES` 定数を配置する。
あわせて `app/utils/video-playback/` ディレクトリ（実装の置き場）と、テストは既存慣習どおり
`tests/unit/utils/video-playback/` を scaffold し、後続の純関数・アダプタ・ローダーの置き場を用意する。

error-handling 原則3（識別子は const 集約・生文字列比較禁止）に従い、`VideoPlayerErrorCode` は
union 型に加えて値を集約した const オブジェクト（`VIDEO_PLAYER_ERROR_CODE`）を用意し、
コード側が生文字列を直書きしないようにする。

本ユニットは DB・認証・他ユニットに非依存（REQ-404 / REQ-405）であり、本タスクは型と
ディレクトリ scaffold のみで実行コードを含まない（typecheck で品質を担保する）。

## 実装詳細

### 1. 型ファイルの配置 🔵

**信頼性**: 🔵 *interfaces.ts の全型を実コードへ転記*

interfaces.ts の内容を `app/types/video-playback.ts` へ転記する。`declare function`（型のみ宣言）
だった `extractYouTubeId` / `clampMs` は、実装は後続タスクで `app/utils/video-playback/` に置くため、
型ファイル側では純関数の戻り値型契約のみコメントで残すか、`import type` で参照できる形に整える。
`PlayerEvent` は実装で必要十分な最小集合（🟡）として転記する。

**実装ファイル**: `app/types/video-playback.ts`

```typescript
import type { Ref } from 'vue'

export type VideoSourceType = 'youtube' | 'local'

export type PlayerStatus = 'unstarted' | 'buffering' | 'playing' | 'paused' | 'ended'

export type PlaybackRate = 0.5 | 0.75 | 1 | 1.25 | 1.5 | 2

export const PLAYBACK_RATES: readonly PlaybackRate[] = [0.5, 0.75, 1, 1.25, 1.5, 2]

export interface YouTubeSource {
  type: 'youtube'
  url: string
}

export interface LocalSource {
  type: 'local'
  file: File
}

export type VideoSource = YouTubeSource | LocalSource

export interface VideoPlayerError {
  code: VideoPlayerErrorCode
  messageKey: string
}

export interface VideoPlayerControls {
  play(): void
  pause(): void
  seekToMs(ms: number): void
  setPlaybackRate(rate: PlaybackRate): void
  getCurrentTimeMs(): number | null
}

export interface VideoPlayerState {
  status: PlayerStatus
  durationMs: number | null
  currentTimeMs: number
  rate: PlaybackRate
  needsReselect: boolean
  error: VideoPlayerError | null
}

export type PlayerEvent = 'statuschange' | 'durationchange' | 'error' | 'ended'

export interface VideoPlayerAdapter extends VideoPlayerControls {
  mount(el: HTMLElement): Promise<void>
  destroy(): void
  getDurationMs(): number | null
  getStatus(): PlayerStatus
  on(event: PlayerEvent, handler: () => void): void
}

export interface UseVideoPlayerReturn {
  state: Readonly<Ref<VideoPlayerState>>
  controls: VideoPlayerControls
  attach(el: HTMLElement): Promise<void>
  detach(): void
}

export interface VideoPlayerProps {
  player: UseVideoPlayerReturn
}

export interface VideoPlayerSlotProps {
  durationMs: number | null
  currentTimeMs: number
  status: PlayerStatus
}

export interface VideoPlayerSlots {
  timeline?: (props: VideoPlayerSlotProps) => unknown
  overlay?: (props: VideoPlayerSlotProps) => unknown
}
```

### 2. エラーコードの const 集約 🔵

**信頼性**: 🔵 *error-handling 原則3（生文字列比較禁止）*

`VideoPlayerErrorCode` union と整合する const オブジェクトを定義し、アダプタ／composable が
エラー生成時に生文字列を直書きしないようにする。`messageKey` は locale JSON 解決用キー
（例: `'videoPlayer.error.youtubeLoadFailed'`）であり、文言はコードに埋めない（原則5）。

**実装ファイル**: `app/types/video-playback.ts`

```typescript
export type VideoPlayerErrorCode =
  | 'youtube-invalid-url'
  | 'youtube-load-failed'
  | 'local-decode-failed'
  | 'local-reselect-needed'

export const VIDEO_PLAYER_ERROR_CODE = {
  youtubeInvalidUrl: 'youtube-invalid-url',
  youtubeLoadFailed: 'youtube-load-failed',
  localDecodeFailed: 'local-decode-failed',
  localReselectNeeded: 'local-reselect-needed'
} as const satisfies Record<string, VideoPlayerErrorCode>
```
