## タスク概要

TASK-0008 で土台を作った `VideoPlayer.client.vue` を拡張し、(1) 汎用オーバーレイスロット
（`timeline` / `overlay`）、(2) エラー提示（inline/banner）、(3) 再選択 UI を追加する。
スロットはドメイン非依存（REQ-009/405）であり、video-playback は「ショット」「ラリー」を一切
知らない。マーカー / フラッシュ等の中身は上位（ドメイン側）が slot props を使って描画する。

エラー文言は locale JSON（`videoPlayer.error.*`、TASK-0010 で追加）を `messageKey` で解決する
（生文字列を埋めない, error-handling 原則5）。

## 実装詳細

### 1. 汎用オーバーレイスロット（REQ-009/405） 🔵

**信頼性**: 🔵 *REQ-009/405 / interfaces.ts VideoPlayerSlotProps / VideoPlayerSlots*

`timeline`（シークバー上の絶対配置層）と `overlay`（再生面上の層）を提供。両者に slot props
`{ durationMs, currentTimeMs, status }`（`VideoPlayerSlotProps`）を渡す。video-playback 側は
left 位置を **算出しない**（上位が `left = ms / durationMs` で算出して描画）。本ユニットは絶対配置
できる「層（コンテナ）」と slot props のみ提供し、ドメイン概念は一切持たない（REQ-405）。

**実装ファイル**: `app/components/VideoPlayer.client.vue`（TASK-0008 を拡張）

```vue
<template>
  <div class="video-player">
    <!-- 再生面 + overlay 層 -->
    <div ref="playerEl" class="video-player__surface">
      <div class="video-player__overlay">
        <slot name="overlay" :duration-ms="state.durationMs" :current-time-ms="state.currentTimeMs" :status="state.status" />
      </div>
      <!-- ローディング / エラー / 再選択（後述） -->
    </div>

    <!-- 標準コントロール（TASK-0008）+ timeline 層 -->
    <div class="video-player__controls">
      <div class="video-player__timeline">
        <slot name="timeline" :duration-ms="state.durationMs" :current-time-ms="state.currentTimeMs" :status="state.status" />
        <!-- シークバー本体は TASK-0008 -->
      </div>
    </div>
  </div>
</template>
```

### 2. エラー提示（inline/banner, error-handling カテゴリ D） 🔵

**信頼性**: 🔵 *error-handling カテゴリ D / 原則5（文言は locale JSON）/ EDGE-001*

`state.error` が非 null のとき、プレーヤー領域に inline/banner（`UAlert` 等）で提示する。文言は
`state.error.messageKey`（例 `videoPlayer.error.youtubeLoadFailed`）を i18n の `t()` で解決する
（生文字列を埋めない）。`error.code === 'youtube-load-failed'`（`VIDEO_PLAYER_ERROR_CODE` 経由で比較）
の場合は「別動画を指定」導線（ボタン/リンク）を併設する（EDGE-001）。

```vue
<script setup lang="ts">
import { VIDEO_PLAYER_ERROR_CODE } from '~/types/video-playback'
const { t } = useI18n()
const emit = defineEmits<{ reselectFile: [file: File]; requestNewSource: [] }>()

const isYoutubeLoadFailed = computed(
  () => state.value.error?.code === VIDEO_PLAYER_ERROR_CODE.youtubeLoadFailed
)
</script>

<template>
  <UAlert v-if="state.error" :title="t(state.error.messageKey)" color="error">
    <template v-if="isYoutubeLoadFailed" #actions>
      <UButton @click="emit('requestNewSource')">{{ t('videoPlayer.error.specifyAnotherVideo') }}</UButton>
    </template>
  </UAlert>
</template>
```

### 3. 再選択 UI（REQ-103/301 / NFR-101） 🔵

**信頼性**: 🔵 *REQ-103（再読み込みで失効した local の再選択）/ REQ-301（長時間は YouTube 推奨）/ NFR-101（自動再アクセス禁止）*

`state.needsReselect` が `true` のとき、「同じ動画を選び直してください」という説明 + ファイル再選択
input を提示する。選択された File は上位へ `reselectFile` で emit（親が新しい `useVideoPlayer(source)`
を再生成する想定）。長時間記録の文脈では YouTube 推奨の UX 誘導（REQ-301）を文言として添える。
自動でファイルへ再アクセスしない（NFR-101）＝必ずユーザ操作起点。

```vue
<template>
  <div v-if="state.needsReselect" class="video-player__reselect">
    <p>{{ t('videoPlayer.error.reselectPrompt') }}</p>
    <input type="file" accept="video/*" @change="onReselect">
    <p class="hint">{{ t('videoPlayer.error.youtubeRecommendation') }}</p>
  </div>
</template>
```
