## タスク概要
YouTube IFrame Player API を内部契約 `VideoPlayerAdapter extends VideoPlayerControls`（interfaces.ts §アダプタ）に適合させる Strategy アダプタを実装する。`mount(el)` で `ensureApiLoaded()`（TASK-0004）を待ってから `new YT.Player(el, { videoId })` を生成し、`onReady` / `onStateChange` / `onError` を登録する。`YT.PlayerState` を統一値 `PlayerStatus` へマッピングし、`statuschange` / `durationchange` / `ended` を発火する。時刻は **ms 単位 integer 統一**：YouTube は秒 float を返すため `getCurrentTimeMs()` は `Math.round(getCurrentTime() * 1000)`、未ロード／`NaN` 時は `null`（REQ-201）、ポーリングなし同期取得（NFR-001）。`seekToMs(ms)` は `clampMs(ms, durationMs)`（TASK-0003）で補正後 `seekTo(sec, true)` を呼ぶ（REQ-104）。エラーは cross-cutting カテゴリ D として `VideoPlayerError`（`code` + `messageKey`、生文字列比較禁止）で扱い、`onError`（コード 2/5/100/101/150）で `youtube-load-failed`（EDGE-001）を emit する。

## 実装詳細
### 1. YouTubeAdapter の構造とライフサイクル 🔵
**信頼性**: 🔵 *architecture.md アダプタパターン §60 + interfaces.ts VideoPlayerAdapter + REQ-101 + ADR-010*
ファクトリ関数またはクラスで `VideoPlayerAdapter` を実装する（`use*` ではない、architecture.md §109）。`mount(el)` は `await ensureApiLoaded()`（TASK-0004：`window.YT` のロードと `onYouTubeIframeAPIReady` 解決を保証）後に `new YT.Player(el, { videoId, events: { onReady, onStateChange, onError } })` を生成する。`videoId` は `extractYouTubeId(source.url)`（TASK-0004）で解決済みを受け取る、または内部で解決する（null なら `youtube-invalid-url` は再生前検証 TASK-0007 側の責務のため、本アダプタは有効 ID 前提）。`destroy()` で `player.destroy()` を呼び、内部参照を破棄する。
**実装ファイル**: `app/utils/video-playback/youtube-adapter.ts`
```ts
// app/utils/video-playback/youtube-adapter.ts
import type { PlaybackRate, PlayerEvent, PlayerStatus, VideoPlayerAdapter, VideoPlayerError, YouTubeSource } from '~/types/video-playback'
import { clampMs } from './clamp'
import { ensureApiLoaded, extractYouTubeId } from './youtube-loader' // TASK-0004

// YT.PlayerState 数値定数（生文字列・生数値の散在を防ぐ）
const YT_STATE = {
  UNSTARTED: -1,
  ENDED: 0,
  PLAYING: 1,
  PAUSED: 2,
  BUFFERING: 3,
  CUED: 5
} as const

// onError で再生不可と判断するコード（埋め込み無効/削除/非公開等、EDGE-001）
const LOAD_FAILED_CODES = new Set([2, 5, 100, 101, 150])

function mapState(state: number): PlayerStatus {
  switch (state) {
    case YT_STATE.PLAYING: return 'playing'
    case YT_STATE.PAUSED: return 'paused'
    case YT_STATE.BUFFERING: return 'buffering'
    case YT_STATE.ENDED: return 'ended'
    default: return 'unstarted' // UNSTARTED / CUED
  }
}

export function createYouTubeAdapter(source: YouTubeSource): VideoPlayerAdapter {
  let player: YT.Player | null = null
  let durationMs: number | null = null
  let status: PlayerStatus = 'unstarted'
  let lastError: VideoPlayerError | null = null
  const handlers: Record<PlayerEvent, Array<() => void>> = {
    statuschange: [],
    durationchange: [],
    error: [],
    ended: []
  }
  const emit = (event: PlayerEvent): void => {
    for (const h of handlers[event]) h()
  }
  const setStatus = (next: PlayerStatus): void => {
    if (next === status) return
    status = next
    emit('statuschange')
  }
  const readDuration = (): void => {
    const sec = player?.getDuration() ?? 0
    durationMs = Number.isFinite(sec) && sec > 0 ? Math.round(sec * 1000) : null
    emit('durationchange')
  }

  return {
    async mount(el: HTMLElement): Promise<void> {
      await ensureApiLoaded() // TASK-0004
      const videoId = extractYouTubeId(source.url)! // 有効 ID 前提（再生前検証は TASK-0007）
      await new Promise<void>((resolve) => {
        player = new YT.Player(el, {
          videoId,
          events: {
            onReady: () => {
              readDuration()
              setStatus(mapState(player!.getPlayerState()))
              resolve()
            },
            onStateChange: (e) => {
              if (durationMs === null) readDuration()
              setStatus(mapState(e.data))
              if (e.data === YT_STATE.ENDED) emit('ended')
            },
            onError: (e) => {
              if (LOAD_FAILED_CODES.has(e.data)) {
                // EDGE-001: 埋め込み無効/削除/非公開。識別子は const 集約・文言は locale JSON
                lastError = { code: 'youtube-load-failed', messageKey: 'videoPlayer.error.youtubeLoadFailed' }
                emit('error')
              }
            }
          }
        })
      })
    },
    destroy(): void {
      player?.destroy()
      player = null
    },
    play(): void {
      player?.playVideo()
    },
    pause(): void {
      player?.pauseVideo()
    },
    seekToMs(ms: number): void {
      if (!player) return
      const clamped = clampMs(ms, durationMs) // REQ-104
      player.seekTo(clamped / 1000, true)
    },
    setPlaybackRate(rate: PlaybackRate): void {
      player?.setPlaybackRate(rate)
    },
    getCurrentTimeMs(): number | null {
      // REQ-201: 未ロード/NaN は null（NaN・負値を返さない）
      if (!player) return null
      const sec = player.getCurrentTime()
      if (!Number.isFinite(sec) || sec < 0) return null
      return Math.round(sec * 1000)
    },
    getDurationMs(): number | null {
      return durationMs
    },
    getStatus(): PlayerStatus {
      return status
    },
    on(event: PlayerEvent, handler: () => void): void {
      handlers[event].push(handler)
    }
  }
}
```

### 2. 状態マッピング（YT.PlayerState → PlayerStatus） 🔵
**信頼性**: 🔵 *interfaces.ts PlayerStatus + REQ-007 + architecture.md §エラーハンドリング表*
`YT.PlayerState` の数値（UNSTARTED/-1, ENDED/0, PLAYING/1, PAUSED/2, BUFFERING/3, CUED/5）を `mapState` で統一値へ変換する：`PLAYING`→`'playing'` / `PAUSED`→`'paused'` / `BUFFERING`→`'buffering'`（EDGE-004） / `ENDED`→`'ended'` / `UNSTARTED`・`CUED`→`'unstarted'`。生数値の散在を防ぐため `YT_STATE` const を経由する。`ENDED` のときのみ `ended` イベントを追加発火する。`setStatus` は同一値で `statuschange` を再発火しない。

### 3. 時刻・シーク・速度の ms 統一とクランプ 🔵
**信頼性**: 🔵 *architecture.md §現在時刻取得 + REQ-104 / REQ-201 / REQ-006 / NFR-001 + interfaces.ts clampMs*
`getCurrentTimeMs()` は `setInterval` を使わず呼び出し時に `player.getCurrentTime()` を同期取得し `Math.round(sec * 1000)`（NFR-001）。未ロード（`player` 未生成）または `NaN`/負値は `null`（REQ-201）。`getDurationMs()` は `Math.round(getDuration() * 1000)`、`0`/`NaN` は `null`（EDGE-102）。`seekToMs(ms)` は `clampMs(ms, durationMs)` 補正後、秒へ変換して `seekTo(clamped / 1000, true)`（第 2 引数 `true`＝即時シーク、REQ-104）。`setPlaybackRate(rate)` は `PlaybackRate`（0.5〜2 の 6 段階、REQ-006）を `player.setPlaybackRate` へそのまま渡す。

### 4. エラー（カテゴリ D） 🔵
**信頼性**: 🔵 *cross-cutting/error-handling カテゴリ D / 原則 3・5 + architecture.md §エラーハンドリング + EDGE-001*
`onError` のコードが `2/5/100/101/150`（埋め込み無効・削除・非公開等）のとき `VideoPlayerError`（`code: 'youtube-load-failed'` / `messageKey: 'videoPlayer.error.youtubeLoadFailed'`）を生成して `error` イベントを emit する。対象外コードは無視する。`code` は `VideoPlayerErrorCode` の const union を使い**生文字列比較を禁止**、文言は locale JSON 側で解決する。`youtube-invalid-url`（EDGE-002）は再生前 `extractYouTubeId` 検証の責務（TASK-0007）であり本アダプタの捕捉対象外。

## 注意事項
- 時刻は必ず **ms 単位 integer**。YouTube API は秒 float のため `Math.round(sec * 1000)` を境界で必ず通す（生の秒値を上位へ漏らさない）。
- `seekToMs` は必ず `clampMs`（TASK-0003）を経由し、`seekTo` の第 2 引数は `true`（即時シーク）を渡す（REQ-104）。
- `getCurrentTimeMs()` はポーリング禁止（NFR-001）。UI 進捗用の `requestAnimationFrame` は composable 側の責務で、本アダプタには置かない。
- `mount` は `ensureApiLoaded()`（TASK-0004）の解決を必ず待つ。`window.YT` 未ロードで `new YT.Player` を呼ぶと失敗する。
- `onError` のコード判定は `2/5/100/101/150` の集合（`LOAD_FAILED_CODES`）に限定する。それ以外（再生位置系の一時エラー等）を `youtube-load-failed` に誤マッピングしない（EDGE-001）。
- エラーは `VideoPlayerErrorCode` の const union を使う。`'youtube-load-failed'` 等の生文字列を上位で直接比較しない（error-handling 原則 3）。`YT.PlayerState` の生数値も `YT_STATE` const を経由する。
- `youtube-invalid-url`（EDGE-002）は本アダプタの捕捉対象外（再生前 `extractYouTubeId` 検証 = TASK-0007 の責務）。
