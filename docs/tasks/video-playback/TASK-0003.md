## タスク概要

ms 値を有効範囲 `[0, durationMs]` にクランプする純関数 `clampMs(ms, durationMs): number` を実装する。
負値は 0 に、`durationMs` 超過は `durationMs` に丸める（REQ-104）。`durationMs` が `null`
（総再生時間が未取得）の場合は下限 0 のみ適用し、上限は設けない（0 以上に丸めるのみ）。
`seekToMs` の範囲外シーク（EDGE-101）と duration 未取得時の境界（EDGE-102）の基盤となる純関数。

時刻は ms 単位 integer 統一（data-foundation B-14）であり、本関数は float 等値比較を回避した
整数前提の境界丸めを担う。

## 実装詳細

### 1. 範囲クランプロジック 🔵

**信頼性**: 🔵 *REQ-104 / EDGE-101 / EDGE-102 / interfaces.ts*

下限は常に 0。上限は `durationMs` が `number` のときのみ適用し、`null` のときは適用しない。
整数前提（ms 単位 integer）で float 等値比較を避ける。副作用なし・DOM 非依存の純関数。

**実装ファイル**: `app/utils/video-playback/clamp.ts`

```typescript
export function clampMs(ms: number, durationMs: number | null): number {
  if (ms < 0) {
    return 0
  }
  if (durationMs !== null && ms > durationMs) {
    return durationMs
  }
  return ms
}
```

### テストケース2: duration ちょうど（上限境界） 🔵

**信頼性**: 🔵 *EDGE-101*
**Given**: `ms = 60000`, `durationMs = 60000`
**When**: `clampMs(60000, 60000)`
**Then**: `60000` を返す（上限ちょうどは素通し）

### テストケース3: duration 超過 → duration 🔵

**信頼性**: 🔵 *REQ-104 / EDGE-101*
**Given**: `ms = 70000`, `durationMs = 60000`
**When**: `clampMs(70000, 60000)`
**Then**: `60000`（上限に丸め）

### テストケース4: 負値 → 0 🔵

**信頼性**: 🔵 *REQ-104 / EDGE-101*
**Given**: `ms = -500`, `durationMs = 60000`
**When**: `clampMs(-500, 60000)`
**Then**: `0`（下限に丸め）

### テストケース5: durationMs = null は下限 0 のみ 🔵

**信頼性**: 🔵 *EDGE-102（duration 未取得）*
**Given**: `ms = 70000`, `durationMs = null`（および負値ケース）
**When**: `clampMs(70000, null)` / `clampMs(-500, null)`
**Then**: 上限は適用せず `70000` を返し、負値は `0` に丸める
