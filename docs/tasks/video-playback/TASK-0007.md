## タスク概要

video-playback ユニットの公開形態である composable `useVideoPlayer(source)` を実装する。
親コンポーネントが `const player = useVideoPlayer(source)` で生成し、薄い `VideoPlayer.client.vue`
（TASK-0008/0009）へ `:player="player"` で渡す中核ロジック層。返り値は interfaces.ts の
`UseVideoPlayerReturn`（`{ state: Readonly<Ref<VideoPlayerState>>, controls: VideoPlayerControls,
attach(el): Promise<void>, detach(): void }`）。

ソース種別でアダプタを選択し（`youtube` → YouTubeAdapter / `local` → Html5Adapter、Phase 2 実装）、
アダプタのイベント購読で `state.status` / `durationMs` / `error` を反映する。記録経路の
`getCurrentTimeMs()` は同期即時取得（ポーリングなし, NFR-001）で controls 経由委譲し、UI 進捗
`state.currentTimeMs` は **再生中のみ requestAnimationFrame** で更新して記録経路と分離する。

本タスクは状態提供のみで UI を持たない（描画は TASK-0008/0009）。アダプタはモックして単体検証する。

## 実装詳細

### 1. アダプタ選択と state の初期化 🔵

**信頼性**: 🔵 *architecture.md §アダプタ選択 / interfaces.ts VideoPlayerState*

`source.type` により `youtube` → YouTubeAdapter、`local` → Html5Adapter を選択。`state` は
`ref<VideoPlayerState>` で内部保持し、返り値では `readonly(state)` で公開する。エラーコードは
`VIDEO_PLAYER_ERROR_CODE`（TASK-0001 の const）経由で生成し生文字列比較を避ける（error-handling 原則3）。

**実装ファイル**: `app/composables/useVideoPlayer.ts`

```typescript
import { readonly, ref } from 'vue'
import type {
  UseVideoPlayerReturn,
  VideoPlayerAdapter,
  VideoPlayerState,
  VideoSource
} from '~/types/video-playback'
import { VIDEO_PLAYER_ERROR_CODE } from '~/types/video-playback'
import { extractYouTubeId } from '~/utils/video-playback/extract-youtube-id'
import { createYouTubeAdapter } from '~/utils/video-playback/youtube-adapter'
import { createHtml5Adapter } from '~/utils/video-playback/html5-adapter'

export function useVideoPlayer(source: VideoSource): UseVideoPlayerReturn {
  const state = ref<VideoPlayerState>({
    status: 'unstarted',
    durationMs: null,
    currentTimeMs: 0,
    rate: 1,
    needsReselect: false,
    error: null
  })

  let adapter: VideoPlayerAdapter | null = null
  let rafId: number | null = null

  // ... attach / controls / rAF / detach（以下の節）
  return { state: readonly(state), controls, attach, detach }
}
```

### 2. attach(el): 検証 → mount → イベント購読 🔵

**信頼性**: 🔵 *EDGE-002 / REQ-103 / NFR-101 / dataflow.md §attach*

- youtube: `extractYouTubeId(source.url)` が `null` なら `state.error` に `youtube-invalid-url` を設定し
  mount しない（EDGE-002, 再生前検証）。
- local: `source.file` が未提供（再読み込みで File 参照が失効）なら `state.needsReselect = true` とし、
  自動再アクセスしない（REQ-103 / NFR-101）。
- 正常時は選択アダプタの `mount(el)` を `await` し、`on(...)` で `statuschange` → `state.status`、
  `durationchange` → `state.durationMs`、`error` → `state.error`、`ended` → `state.status = 'ended'`
  を反映する。

```typescript
async function attach(el: HTMLElement): Promise<void> {
  if (source.type === 'youtube') {
    if (extractYouTubeId(source.url) === null) {
      state.value.error = {
        code: VIDEO_PLAYER_ERROR_CODE.youtubeInvalidUrl,
        messageKey: 'videoPlayer.error.youtubeInvalidUrl'
      }
      return
    }
    adapter = createYouTubeAdapter(source)
  } else {
    if (!source.file) {
      state.value.needsReselect = true
      return
    }
    adapter = createHtml5Adapter(source)
  }

  adapter.on('statuschange', () => { state.value.status = adapter!.getStatus() })
  adapter.on('durationchange', () => { state.value.durationMs = adapter!.getDurationMs() })
  adapter.on('ended', () => { state.value.status = 'ended'; stopRaf() })
  adapter.on('error', () => { /* アダプタが設定した error を反映（実装で確定） */ })
  await adapter.mount(el)
}
```

### 3. controls: アダプタへの委譲（記録経路は同期即時） 🔵

**信頼性**: 🔵 *NFR-001（getCurrentTimeMs 同期即時, ポーリングなし）/ REQ-201 / REQ-202*

`play` / `pause` / `seekToMs` / `setPlaybackRate` / `getCurrentTimeMs` をアダプタへ委譲。
`seekToMs` は `clampMs`（アダプタ内 or 委譲先）でクランプ済の値を渡す。`getCurrentTimeMs` は
同期で即時に返し、未ロード（durationMs == null）時は `null`（REQ-201）。`play` 開始で rAF を起動、
`pause` で停止する。

```typescript
const controls = {
  play() { adapter?.play(); startRaf() },
  pause() { adapter?.pause(); stopRaf() },
  seekToMs(ms: number) { adapter?.seekToMs(ms) },
  setPlaybackRate(rate) { adapter?.setPlaybackRate(rate); state.value.rate = rate },
  getCurrentTimeMs(): number | null {
    return adapter ? adapter.getCurrentTimeMs() : null
  }
}
```

### 4. UI 進捗: requestAnimationFrame（再生中のみ, 記録経路と分離） 🔵

**信頼性**: 🔵 *NFR-001（UI 進捗は rAF, 記録経路と分離）*

`state.currentTimeMs` は再生中のみ rAF ループで `adapter.getCurrentTimeMs()` の値を反映する。これは
表示専用であり、記録経路（`controls.getCurrentTimeMs()` の同期即時取得）とは独立。停止・`ended`・
`detach` で `cancelAnimationFrame` する。

```typescript
function startRaf() {
  if (rafId !== null) return
  const tick = () => {
    const t = adapter?.getCurrentTimeMs()
    if (t !== null && t !== undefined) state.value.currentTimeMs = t
    rafId = requestAnimationFrame(tick)
  }
  rafId = requestAnimationFrame(tick)
}

function stopRaf() {
  if (rafId !== null) { cancelAnimationFrame(rafId); rafId = null }
}
```

### 5. detach(): 破棄とリーク防止 🔵

**信頼性**: 🔵 *architecture.md §ライフサイクル*

`adapter.destroy()` を呼び、rAF を解除し、購読リスナを解除する。コンポーネント側は
`onBeforeUnmount` で `detach()` を呼ぶ（TASK-0008）。

```typescript
function detach() {
  stopRaf()
  adapter?.destroy()
  adapter = null
}
```
