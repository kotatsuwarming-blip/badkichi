## タスク概要

YouTube IFrame Player API スクリプト（`https://www.youtube.com/iframe_api`）を初回利用時に
**一度だけ** 注入し、`window.onYouTubeIframeAPIReady` コールバックを Promise 化して以降キャッシュする
ローダーを実装する。複数プレーヤーが同一ページに存在しても注入と ready 解決は 1 回だけ行い、
2 回目以降の呼び出しはキャッシュ済み Promise を返す。`ensureApiLoaded(): Promise<typeof YT>` 的な
API を公開し、YouTubeAdapter が `mount` 時にこれを `await` してから `YT.Player` を生成する。

YouTube IFrame API は **API キー不要**。ブラウザ専用 API（`window` / `document` 前提）のため
CSR 限定（REQ-401, `import.meta.client`）で初期化する。

## 実装詳細

### 1. ready Promise のモジュールスコープキャッシュ 🔵

**信頼性**: 🔵 *REQ-101 / REQ-401 / architecture.md*

モジュールスコープに `loadPromise: Promise<typeof YT> | null` を保持する。`ensureApiLoaded` は
キャッシュがあればそれを返し、なければ新規に Promise を生成してキャッシュする。これにより
複数プレーヤーからの並行呼び出しでも注入・ready 解決は 1 回に収束する。

**実装ファイル**: `app/utils/video-playback/youtube-api-loader.ts`

```typescript
const IFRAME_API_SRC = 'https://www.youtube.com/iframe_api'

let loadPromise: Promise<typeof YT> | null = null

export function ensureApiLoaded(): Promise<typeof YT> {
  if (loadPromise) {
    return loadPromise
  }

  loadPromise = new Promise<typeof YT>((resolve) => {
    if (window.YT && window.YT.Player) {
      resolve(window.YT)
      return
    }

    const prev = window.onYouTubeIframeAPIReady
    window.onYouTubeIframeAPIReady = () => {
      prev?.()
      resolve(window.YT)
    }

    if (!document.querySelector(`script[src="${IFRAME_API_SRC}"]`)) {
      const script = document.createElement('script')
      script.src = IFRAME_API_SRC
      document.head.appendChild(script)
    }
  })

  return loadPromise
}
```

### 2. 二重注入の防止 🔵

**信頼性**: 🔵 *architecture.md（初回1回だけ注入）*

`document.querySelector` で既存の API スクリプトの有無を確認し、存在する場合は再注入しない。
既存の `window.onYouTubeIframeAPIReady` があれば chain（`prev?.()`）して上書きによる取りこぼしを防ぐ。

### 3. CSR ガードと型 🔵

**信頼性**: 🔵 *REQ-401（ブラウザ専用 API は CSR 限定）*

`window` / `document` を前提とするため、利用は client 側に限定する（呼び出し元アダプタが
`import.meta.client` / `onMounted` 内で呼ぶ）。`typeof YT` の型は `@types/youtube` 相当の
グローバル宣言、または最小の自前 `global.d.ts`（`window.YT` / `window.onYouTubeIframeAPIReady`）で
補う。型補完の方針は Phase 2 のアダプタ実装と整合させる。

### テストケース1: 初回呼び出しで script 注入 + ready で resolve 🔵

**信頼性**: 🔵 *REQ-101 / REQ-401*
**Given**: `window.YT` 未定義、API スクリプト未注入のモック環境
**When**: `ensureApiLoaded()` を呼び、テストが `window.onYouTubeIframeAPIReady()` を発火させる
**Then**: `iframe_api` の script が 1 回 `document.head` へ追加され、Promise が `window.YT` で resolve する

### テストケース2: 2 回目以降は再注入せず同一 Promise 🔵

**信頼性**: 🔵 *architecture.md（複数プレーヤーでも1回）*
**Given**: 1 回目の呼び出しで Promise 生成済み
**When**: `ensureApiLoaded()` を再度呼ぶ
**Then**: script は追加されず（注入回数は 1 のまま）、1 回目と同一の Promise インスタンスが返る

- ESLint 規約: セミコロンなし / no comma dangle / 1tbs を厳守。
