## タスク概要

YouTube URL から動画 ID（11 文字の英数 + `-_`）を抽出する純関数 `extractYouTubeId(url): string | null`
を実装する。抽出不可な URL（非 YouTube・空文字・ID 抽出失敗）の場合は `null` を返す。
これは EDGE-002（無効な YouTube URL を再生開始前に検証）の基盤であり、YouTubeAdapter が
プレーヤー初期化前にこの関数で URL を検証して `youtube-invalid-url` エラーを生成する経路で使われる。

純関数（副作用なし・DOM 非依存）なので CSR 制約の対象外で、vitest で単体検証する。

## 実装詳細

### 1. URL 形式パターンと ID 抽出 🔵

**信頼性**: 🔵 *EDGE-002 / interfaces.ts シグネチャ*

各種 YouTube URL 形式に対応する。ID は 11 文字の `[A-Za-z0-9_-]`。マッチしない場合は `null`。
対応形式: `watch?v=ID` / `youtu.be/ID` / `embed/ID` / `shorts/ID`。クエリやフラグメントが
後続しても先頭 11 文字の ID 部分のみを抽出する。例外は投げず、検証は呼び出し側（アダプタ）が
返り値の `null` で判定する。

**実装ファイル**: `app/utils/video-playback/extract-youtube-id.ts`

```typescript
const YOUTUBE_ID_PATTERN = /(?:youtube\.com\/(?:watch\?(?:.*&)?v=|embed\/|shorts\/)|youtu\.be\/)([A-Za-z0-9_-]{11})(?:[?&#/].*)?$/

export function extractYouTubeId(url: string): string | null {
  if (!url) {
    return null
  }
  const match = url.match(YOUTUBE_ID_PATTERN)
  return match ? match[1] : null
}
```
