## 実装詳細

### 1. props 受け取りとライフサイクル結線 🔵

**信頼性**: 🔵 *architecture.md §公開形態（親が player 生成・コンポーネントは attach/detach）/ ADR-010*

`player` を props で受け取り、再生面コンテナ `ref` を `onMounted` で `player.attach()` に渡す。
`onBeforeUnmount` で `player.detach()`。`state` は `player.state`（Readonly<Ref>）を参照し算出
プロパティで表示へ変換する。`.client.vue` のため SSR では描画されず（ADR-010）、`ClientOnly` は使わない。

**実装ファイル**: `app/components/VideoPlayer.client.vue`

```vue
<script setup lang="ts">
import { computed, onBeforeUnmount, onMounted, ref } from 'vue'
import type { UseVideoPlayerReturn } from '~/types/video-playback'
import { PLAYBACK_RATES } from '~/types/video-playback'

const props = defineProps<{ player: UseVideoPlayerReturn }>()

const playerEl = ref<HTMLElement | null>(null)
const state = props.player.state
const controls = props.player.controls

onMounted(async () => {
  if (playerEl.value) await props.player.attach(playerEl.value)
})

onBeforeUnmount(() => {
  props.player.detach()
})
</script>
```

### 2. 標準コントロール UI（Nuxt UI, REQ-008） 🔵

**信頼性**: 🔵 *REQ-008 / REQ-202 / interfaces.ts VideoPlayerControls*

- 再生/一時停止トグル: `status === 'playing'` で `controls.pause()`、それ以外で `controls.play()`。
- シークバー: 値 = `currentTimeMs / durationMs`（durationMs が null の間は無効化）。ドラッグ/クリックで
  ms に逆算し `controls.seekToMs(ms)`（クランプは composable/アダプタ側）。
- 時刻表示: `formatMs(currentTimeMs)` / `formatMs(durationMs)` を `mm:ss` で整形（ms → 表示用の純関数）。
- 速度選択: `PLAYBACK_RATES` のセレクタ（`USelect` 等）で `controls.setPlaybackRate(rate)`。

```typescript
const isPlaying = computed(() => state.value.status === 'playing')

function toggle() {
  if (isPlaying.value) controls.pause()
  else controls.play()
}

function onSeek(ratio: number) {
  if (state.value.durationMs == null) return
  controls.seekToMs(Math.round(ratio * state.value.durationMs))
}

function formatMs(ms: number | null): string {
  if (ms == null) return '--:--'
  const total = Math.floor(ms / 1000)
  const mm = String(Math.floor(total / 60)).padStart(2, '0')
  const ss = String(total % 60).padStart(2, '0')
  return `${mm}:${ss}`
}
```
