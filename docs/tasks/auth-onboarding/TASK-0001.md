## 実装詳細
### 1. パッケージ追加 🔵
**信頼性**: 🔵 *architecture.md §技術的制約 (互換性制約)*
`@nuxtjs/i18n` と `@sentry/nuxt` を `pnpm add` する。両モジュールは現在未インストール (`package.json` 実測。modules は `@nuxt/eslint` / `@nuxt/test-utils/module` / `@nuxt/ui` / `@nuxtjs/supabase` の 4 つのみ)。Zod は ^4.4.3 で導入済のため追加しない。
**実装ファイル**: `package.json` (pnpm により自動更新)
```bash
pnpm add @nuxtjs/i18n @sentry/nuxt
```

### 2. nuxt.config.ts 変更 🔵
**信頼性**: 🔵 *architecture.md §モジュール設定変更 (nuxt.config.ts) 表の 5 項目 + error-handling.md §7.2 / §8.2*
既存 `nuxt.config.ts` に対し、architecture.md の変更表 5 項目を反映する。
- `routeRules: { '/': { prerender: true } }` を **削除** (静的 HTML に認証前提が焼き付くのを防ぐ、ADR-010 D6)
- `supabase` に `redirect: false` を追加 (内蔵リダイレクト無効化、ADR-008 D3)。`redirectOptions` の `login: '/login'` / `callback: '/confirm'` は維持し、`exclude: []` を追加 (ADR-008 D3 / ADR-010 D5)。`types: '~/types/supabase.ts'` は維持
- `modules` に `@nuxtjs/i18n` を追加し i18n 設定を記述
- `modules` に `@sentry/nuxt/module` を追加し sentry 設定を記述
**実装ファイル**: `nuxt.config.ts`
```ts
export default defineNuxtConfig({
  modules: [
    '@nuxt/eslint',
    '@nuxt/test-utils/module',
    '@nuxt/ui',
    '@nuxtjs/supabase',
    '@nuxtjs/i18n',
    '@sentry/nuxt/module'
  ],
  // routeRules の '/' prerender は削除 (ADR-010 D6)
  supabase: {
    redirect: false,
    redirectOptions: {
      login: '/login',
      callback: '/confirm',
      exclude: []
    },
    types: '~/types/supabase.ts'
  },
  i18n: {
    locales: [
      { code: 'ja', file: 'ja.json', name: '日本語' },
      { code: 'en', file: 'en.json', name: 'English' }
    ],
    defaultLocale: 'ja',
    strategy: 'no_prefix',
    detectBrowserLanguage: false,
    langDir: 'locales/'
  },
  sentry: {
    dsn: process.env.NUXT_PUBLIC_SENTRY_DSN,
    environment: process.env.NUXT_PUBLIC_ENV ?? 'development',
    tracesSampleRate: 0,
    replaysSessionSampleRate: 0,
    replaysOnErrorSampleRate: 0
  }
})
```

### 3. .env.example 追記 🔵
**信頼性**: 🔵 *error-handling.md §8.3 (NUXT_PUBLIC_SENTRY_DSN / NUXT_PUBLIC_ENV)*
`.env.example` (git 管理) に Sentry 用の環境変数を追記する。DSN は public key のため空で記載し、`NUXT_PUBLIC_ENV` は `development` をデフォルトとする。
**実装ファイル**: `.env.example`
```
NUXT_PUBLIC_SENTRY_DSN=
NUXT_PUBLIC_ENV=development
```

## 注意事項
- Sentry DSN は public key のため `.env.example` に空で記載してよい。Supabase secret はローカルに置かない方針 (memory `feedback_strict_secret_policy`、シェル env / CI Secrets でのみ渡す)。
- Nuxt UI v4 は `@nuxtjs/i18n` 統合済 (error-handling.md §7.5)。別途設定は不要だが、実装時に `@nuxt/ui` 公式ドキュメントで再確認すること。
- prd デプロイ環境では `NUXT_PUBLIC_ENV=production` を設定する。source map 自動アップロード用の `SENTRY_AUTH_TOKEN` はデプロイ環境構築時に CI へ設定する (本タスクの範囲外)。
