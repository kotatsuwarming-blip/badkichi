## タスク概要
認証前の 2 page を実装する。`/login` は Google OAuth ボタンを表示し、押下で `useLogin().login(redirect)` を呼ぶ (REQ-001、page から `supabase.auth` を直接叩かない REQ-406)。layout は `auth`。`/confirm` は data-foundation TASK-0016 の最小スタブを本実装に置換する。セッション確立を `<USkeleton>` で待機表示し (REQ-203 / NFR-202)、確立後に `navigateTo(route.query.redirect ?? '/')` で遷移する (REQ-104)。Auth エラー時は `useLogin.notice` を `<UAlert>` で表示し、「ログイン画面に戻る」ボタンを提示する (EDGE-002)。`/confirm` は public path で middleware 判定対象外であり、page 内で遷移を行う。

## 実装詳細
### 1. login.vue 🔵
**信頼性**: 🔵 *REQ-001 + dataflow.md §2 + ADR-011 D1*
Google OAuth ログインボタン (`<UButton>`) を表示する。押下で `useLogin().login(redirect)` を呼ぶ。redirect は `route.query.redirect` を渡す (未認証で保護ページへアクセスし `/login?redirect=...` に着地したケースの運搬、EDGE-001。redirect を引数で渡すか useLogin 内部で `useRoute()` を読むかは interfaces.ts UseLoginReturn の注記どおり実装判断)。`definePageMeta({ layout: 'auth' })` を付与。送信中は `useLogin.pending` でボタン disabled (二重送信防止)。
**実装ファイル**: `app/pages/login.vue`

### 2. confirm.vue (本実装、スタブ置換) 🔵
**信頼性**: 🔵 *REQ-002/104/203 + dataflow.md §2 + EDGE-002 (既存スタブ置換)*
data-foundation TASK-0016 の最小スタブ (`useSupabaseUser` を watch して `/` へ navigate するだけ) を本実装に置換する。セッション確立を待機し、確立中は `<USkeleton>` を表示 (REQ-203)。確立後は `navigateTo(route.query.redirect ?? '/')` で遷移 (REQ-104。middleware の §1 判定で Group 有無に応じて最終的に `/onboarding` or 目的地へ振り分けられる)。Auth エラー時 (ネットワークエラー等) は `useLogin.notice` を `<UAlert>` で表示し、「ログイン画面に戻る」ボタン (→ `/login`) を提示 (EDGE-002)。`definePageMeta({ layout: 'auth' })` を付与。`/confirm` は public path で middleware 判定対象外 (architecture.md §画面構成)。
**実装ファイル**: `app/pages/confirm.vue`

## 注意事項
- `/confirm` はスタブ置換であることが分かる差分 commit にする (note.md §注意事項 / architecture.md §ディレクトリ構造「data-foundation TASK-0016 のスタブを本実装に置換」)。
- redirect クエリの運搬チェーンは EDGE-001 (`/join/[code]` 未ログイン → `/login?redirect=...` → OAuth → `/confirm?redirect=...` → 元の `/join/[code]` → `/`) 全体で機能させる。`/confirm` は `route.query.redirect` を読んで遷移する。
- `/confirm` は public path (middleware 判定対象外)。遷移判断は page 内で行い、最終振り分けは遷移先で middleware §1 判定に委ねる。
- `/login` で Group 所属済ユーザは middleware (§1 public path 側) が `/` へ振り分ける。page 側では追加判定不要。
