## タスク概要
招待リンク着地画面を実装する (REQ-005/105/106/107/108)。`/join/[code]` は public path で、middleware は未ログインでも通過させる。未ログインの場合は **page 内で** `navigateTo('/login?redirect=/join/[code]')` する (ADR-008 D1 の例外、REQ-108)。ログイン済の場合は `useJoinGroup().join(code)` を呼び (code は route params)、成功時 `navigateTo('/')`、失敗時は `useJoinGroup.notice` を `<UAlert>` で永続表示する (`ALREADY_IN_GROUP` / `INVITATION_NOT_FOUND_BY_LINK` / `INVITATION_EXPIRED`、REQ-105/106/107)。DB メッセージ `invitation_not_found` → `INVITATION_NOT_FOUND_BY_LINK` の明示変換は `useJoinGroup` 内に閉じる。layout は無指定で `default.vue` を継承 (public path だがレイアウト分岐とは独立、ADR-011 D1)。

## 実装詳細
### 1. join/[code].vue 🔵
**信頼性**: 🔵 *REQ-005/108 + dataflow.md §4 + ADR-008 D1 (例外) + EDGE-001/005*
招待コードは route params (`code`) から取得する。`/join/[code]` は public path のため middleware は未ログインでも通過させる (architecture.md §画面構成 / dataflow.md §1)。
- **未ログイン** (`useSupabaseUser()` が null) → page 内で `navigateTo('/login?redirect=/join/[code]')` (REQ-108 / ADR-008 D1 例外。これにより EDGE-001 のリダイレクトチェーンが成立)。
- **ログイン済** → `useJoinGroup().join(code)` を呼ぶ (pending=true)。
  - 成功 (`{ data: group_id, error: null }`) → `navigateTo('/')` (useJoinGroup が内部で `useCurrentGroup.refresh()` 済、dataflow.md §4)。
  - 失敗 → `useJoinGroup.notice` を `<UAlert>` で永続表示 (`ALREADY_IN_GROUP` (REQ-105) / `INVITATION_NOT_FOUND_BY_LINK` (REQ-107) / `INVITATION_EXPIRED` (REQ-106))。永続通知のため明示クリアまで残す (error-handling.md §6.1)。
- 処理中は `useJoinGroup.pending` で `<USkeleton>` / disabled を表示 (NFR-202)。

DB メッセージ `invitation_not_found` と App 識別子 `INVITATION_NOT_FOUND_BY_LINK` は文字列が異なるため、`useJoinGroup` 内で明示変換する (素朴な includes に頼らない、architecture.md §既存 API マッピング 注2)。page は context / 識別子を意識しない。layout は無指定で `default.vue` 継承。文言は locales 経由 (NFR-204)。
**実装ファイル**: `app/pages/join/[code].vue`

## 注意事項
- `/join/[code]` は public path だが、未認証リダイレクトは **page 内で** 行う (ADR-008 D1 の例外。middleware では通過させる)。
- リダイレクトチェーン EDGE-001: `/join/[code]` 未ログイン → `/login?redirect=/join/[code]` → Google OAuth → `/confirm?redirect=/join/[code]` → セッション確立 → `/join/[code]` に戻る → join 成功 → `/`。全体が機能することが受入対象 (TASK-0020)。
- 招待コードの変な文字 (空白 / 特殊文字 / 極端な長さ) は DB 側でマッチせず `invitation_not_found` → `INVITATION_NOT_FOUND_BY_LINK` (EDGE-005/106。新規識別子は追加しない)。
- レイアウトは `default.vue` (public path だがレイアウト分岐とは独立、ADR-011 D1)。
