## 実装詳細
### 1. テスト移動 🔵
**信頼性**: 🔵 *ADR-012 D5 + §影響 (既存テストファイルの移動) 表*
`app/utils/rule-engine/__tests__/` 配下の 4 ファイルを `tests/unit/utils/rule-engine/` へ移動する。移動に伴い、対象モジュールへの import を `~/` (= `app/`) 経由のパスへ修正する (ADR-012 D5 import path ルール)。
**実装ファイル**: 移動先 `tests/unit/utils/rule-engine/{apply-override,apply-rally,create-initial-state,determine-set-winner}.test.ts`

| 移動元 | 移動先 |
|--------|--------|
| `app/utils/rule-engine/__tests__/apply-override.test.ts` | `tests/unit/utils/rule-engine/apply-override.test.ts` |
| `app/utils/rule-engine/__tests__/apply-rally.test.ts` | `tests/unit/utils/rule-engine/apply-rally.test.ts` |
| `app/utils/rule-engine/__tests__/create-initial-state.test.ts` | `tests/unit/utils/rule-engine/create-initial-state.test.ts` |
| `app/utils/rule-engine/__tests__/determine-set-winner.test.ts` | `tests/unit/utils/rule-engine/determine-set-winner.test.ts` |

import 例 (相対 `../foo` → `~/utils/rule-engine/foo`):
```ts
// 移動前: import { applyRally } from '../apply-rally'
// 移動後:
import { applyRally } from '~/utils/rule-engine/apply-rally'
```

### 2. vitest.config.ts include 変更 🔵
**信頼性**: 🔵 *ADR-012 D5 + §影響*
現状 `vitest.config.ts` は `include` を明示しておらず、Vitest デフォルトの glob で `app/utils/rule-engine/__tests__/*.test.ts` を拾っている。include を `tests/unit/**/*.test.ts` に明示し、移動後の配置のみを対象にする。`exclude` の `**/*.integration.test.ts` は維持する (integration は別 config)。`vitest.integration.config.ts` は触らない。
**実装ファイル**: `vitest.config.ts`
```ts
import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    passWithNoTests: true,
    include: ['tests/unit/**/*.test.ts'],
    exclude: [
      '**/node_modules/**',
      '**/dist/**',
      '**/.{idea,git,cache,output,temp}/**',
      '**/{karma,rollup,webpack,vite,vitest,jest,ava,babel,nyc,cypress,tsup,build,eslint,prettier}.config.*',
      '**/*.integration.test.ts'
    ]
  }
})
```
