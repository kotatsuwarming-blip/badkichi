## 実装詳細
### 1. auth.global.ts 🔵
**信頼性**: 🔵 *dataflow.md §1 (フローチャート) + ADR-008 D1-D8 (実装イメージ) + architecture.md §認証 middleware*
`defineNuxtRouteMiddleware(async (to) => { ... })` で実装。`PUBLIC_PATHS = ['/login', '/confirm']` + `to.path.startsWith('/join/')` で public 判定。`GROUP_OPTIONAL_PATHS = ['/onboarding', '/groups/new']` を未所属許可 path とする。public なら `/login` かつ `user.value` の場合のみ `useCurrentGroup()` で所属確認し所属済なら `/` へ、それ以外は return (通す)。非 public は `!user.value` で `/login?redirect=...`、ログイン済は `useCurrentGroup()` を解決し、未所属 + 非許可 path で `/onboarding`、所属済 + `/onboarding` で `/`。`/join/**` の未認証リダイレクトは middleware ではなく page 内で行う (ADR-008 D1 例外、TASK-0018)。
**実装ファイル**: `app/middleware/auth.global.ts`
```ts
// app/middleware/auth.global.ts (ADR-008 D1 / dataflow.md §1)
export default defineNuxtRouteMiddleware(async (to) => {
  const PUBLIC_PATHS = ['/login', '/confirm']
  const isPublicPath = PUBLIC_PATHS.includes(to.path) || to.path.startsWith('/join/')
  // ログイン済 + Group 未所属でも到達してよい path
  const GROUP_OPTIONAL_PATHS = ['/onboarding', '/groups/new']

  const user = useSupabaseUser()

  if (isPublicPath) {
    if (to.path === '/login' && user.value) {
      const { data: currentGroup } = await useCurrentGroup()
      if (currentGroup.value) return navigateTo('/') // REQ-103
    }
    return // public として通す
  }

  if (!user.value) {
    return navigateTo(`/login?redirect=${encodeURIComponent(to.fullPath)}`) // REQ-101/108
  }

  const { data: currentGroup } = await useCurrentGroup()
  if (!currentGroup.value && !GROUP_OPTIONAL_PATHS.includes(to.path)) {
    return navigateTo('/onboarding') // REQ-102
  }
  if (currentGroup.value && to.path === '/onboarding') {
    return navigateTo('/') // REQ-103
  }
})
```
> 同一キー `'current-group'` の `useAsyncData` キャッシュを page と共有し 1 ナビゲーション 1 クエリを保証 (ADR-008 D4 / NFR-002)。middleware 内で `try-catch` は不要、クエリエラーは throw → `error.vue` → Sentry (ADR-008 D7)。isomorphic 原則 (D6): `serverSupabaseClient` / `window` / `document` は使わない。

## 注意事項
- `/join/**` は public path であり middleware では未認証リダイレクトしない。未認証時は page 内で `/login` へリダイレクトする (ADR-008 D1 例外、TASK-0018 join/[code].vue で実装)。
- `/login` での所属済 → `/` は public 分岐側 (図上部 `PubLogin`) で処理する。認証済ブランチでは `/onboarding` のみ判定する (dataflow.md §1)。
- `useCurrentGroup` は固定キー `'current-group'` のキャッシュを page と共有する。middleware で別クエリを直書きしないこと (NFR-002 / ADR-008 D4)。
- isomorphic 制約 (D6): `serverSupabaseClient` / `window` / `document` 禁止。`useSupabaseUser` / `useCurrentGroup` / `navigateTo` のみ。
- テストは ADR-008 D8 の表を分岐カバレッジとして実装する。8 行目「未認証 + /login → 通過」はテストケース2 に集約済 (代表化)。
