## 実装詳細
### 1. useListInvitations 🔵
**信頼性**: 🔵 *dataflow.md §5 + interfaces.ts Invitation / UseListInvitationsReturn + architecture.md §既存 API マッピング*
`useAsyncData('invitations-list:' + groupId, handler)` で実装する (group 別固定キー)。handler 内で `from('group_invitations').select('id, code, created_at, expires_at').eq('group_id', groupId).is('deleted_at', null)` を実行 (MVP は無効化なしだがソフトデリート前提のため `deleted_at is null` で除外、interfaces.ts Invitation 注)。`Invitation` は `Pick<Row, 'id' | 'code' | 'created_at' | 'expires_at'>`。状態 (有効/期限切れ) は DB 列ではなく `expires_at < now()` で UI 側が算出する (status 列は存在しない)。クエリエラーは throw → `error.vue`。
**実装ファイル**: `app/composables/useListInvitations.ts`
```ts
// app/composables/useListInvitations.ts
export function useListInvitations(groupId: string): UseListInvitationsReturn {
  const supabase = useSupabaseClient<Database>()
  return useAsyncData(`invitations-list:${groupId}`, async () => {
    const { data, error } = await supabase
      .from('group_invitations')
      .select('id, code, created_at, expires_at')
      .eq('group_id', groupId)
      .is('deleted_at', null)
    if (error) throw error
    return data ?? []
  })
}
```

### 2. useGenerateInvitation 🔵
**信頼性**: 🔵 *dataflow.md §5 (sequence) + interfaces.ts UseGenerateInvitationReturn + architecture.md §既存 API マッピング + error-handling.md §6.5*
`rpc('generate_invitation_code', { target_group_id })` を呼ぶ。`useToastErrors()` の `showError` と `useToast()` (成功 toast 用) を取得。発行成功時は `useListInvitations(groupId).refresh()` を呼び (D5-4) 一覧を自動更新し、成功 toast (「招待リンクを発行しました」) を出す。`not_a_member` / `invitation_code_collision_after_retry` は `showError(error)` で一過性 toast に流す (REQ-110 / EDGE-008)。`pending` は try/finally で制御。`{ data: code, error }` (ActionResult) を返す。`refresh` の取得は同一 group キーの `useListInvitations` を介して行う (同一キー `'invitations-list:{groupId}'` 共有)。
**実装ファイル**: `app/composables/useGenerateInvitation.ts`
```ts
// app/composables/useGenerateInvitation.ts
export function useGenerateInvitation(): UseGenerateInvitationReturn {
  const supabase = useSupabaseClient<Database>()
  const { showError } = useToastErrors()
  const toast = useToast()
  const pending = ref(false)

  async function generate(targetGroupId: string): Promise<ActionResult<string>> {
    pending.value = true
    const { data, error } = await supabase.rpc('generate_invitation_code', {
      target_group_id: targetGroupId
    })
    if (error) {
      showError(error) // not_a_member / invitation_code_collision_after_retry
    } else {
      await useListInvitations(targetGroupId).refresh() // 同一キーで一覧更新 (D5-4)
      toast.add({ title: '招待リンクを発行しました' })
    }
    pending.value = false
    return { data, error }
  }

  return { generate, pending }
}
```
> 状態列は無く `expires_at < now()` 派生算出 (interfaces.ts Invitation 注)。成功文言・コピー完了文言は `locales/ja.json` に置く (NFR-204)。`useListInvitations` と `useGenerateInvitation` で同一 `useAsyncData` キーを共有することで refresh が一覧に反映される (実装時に composable 間でキーが一致することを確認)。

- `group_invitations` に `status` 列は無い。有効/期限切れは `expires_at < now()` の派生値で UI が算出する (interfaces.ts Invitation 注)。DB 列を探さない。
