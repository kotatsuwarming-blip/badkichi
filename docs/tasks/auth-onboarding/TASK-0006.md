## 実装詳細
### 1. group-name schema 🔵
**信頼性**: 🔵 *NFR-201 + EDGE-101〜105*
Group 名のバリデーションスキーマを実装する。trim 後の文字数で判定し、1 文字未満 (空) と 50 文字超を弾く。空白のみ入力は trim 後 0 文字となり弾かれる。trim を先に適用し、min/max は trim 後の値に対して効かせる。
**実装ファイル**: `app/schemas/group-name.ts`
```ts
import { z } from 'zod'

export const groupNameSchema = z
  .string()
  .trim()
  .min(1, { message: 'invalid_group_name' })
  .max(50, { message: 'invalid_group_name' })

export type GroupName = z.infer<typeof groupNameSchema>
```
> 注: `trim().min(1)` により「空白のみ → trim 後 0 文字 → min(1) 違反」が成立するため、別途 refine を追加せずとも EDGE-105 (空白のみ不可) を満たせる。実装時に Zod の挙動を確認し、必要なら明示 refine を補う。message は locale キーと整合させる (NFR-204、表示は呼び出し側で `t()`)。
