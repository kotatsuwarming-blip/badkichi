## 実装詳細
### 1. useCurrentGroup 🔵
**信頼性**: 🔵 *architecture.md §既存 API マッピング (クエリ実測) + interfaces.ts CurrentGroup + ADR-008 D4 + ADR-006*
`useAsyncData('current-group', handler)` の固定キーで実装する。handler 内で `useSupabaseUser().value?.sub` を uid とし、`from('group_members').select('group_id, groups(id, name)').eq('user_id', uid).maybeSingle()` を実行。`.maybeSingle()` は 0 行で `data: null` / `error: null` を返すため、未所属を例外なく null として扱える (ADR-006 で 1 user = 1 group が保証されるため複数行は発生しない)。クエリエラー (`error`) はそのまま throw させ `error.vue` フォールバックに委ねる (architecture.md §既存 API マッピング)。
**実装ファイル**: `app/composables/useCurrentGroup.ts`
```ts
// app/composables/useCurrentGroup.ts
export function useCurrentGroup(): UseCurrentGroupReturn {
  const supabase = useSupabaseClient<Database>()
  const user = useSupabaseUser()

  return useAsyncData('current-group', async () => {
    const uid = user.value?.sub
    if (!uid) return null
    const { data, error } = await supabase
      .from('group_members')
      .select('group_id, groups(id, name)')
      .eq('user_id', uid)
      .maybeSingle()
    if (error) throw error
    return data
  })
}
```
> `groups` embed の null 許容は supabase 生成型 (`app/types/supabase.ts`) の出力に従う (interfaces.ts CurrentGroup 🟡 注: FK 必須なら non-null になる可能性。生成型を見て `| null` を外すか決める)。同一キー `'current-group'` を middleware / page で共有することで重複クエリを防止 (NFR-002)。
