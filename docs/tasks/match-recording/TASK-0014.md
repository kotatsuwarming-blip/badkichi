## タスク概要

記録操作の4コンポーネントを実装する（ui-design.md §コンポーネント分割）。いずれも `useRecordingSession` の
アクションを props/inject で受け、自身は session を生成しない（page が所有）。全文言 i18n。

- **ShotButton.vue**: 「打った」大ボタン + **Space バインド**（PC）+ ショット数表示（`currentRally.shots.length`）。
  押下で `recordShot()`。動画未ロード時は無効（EDGE-001 は session 側で no-op だが、ボタンも `disabled` で抑止、REQ-202）。
- **UndoButton.vue**: 「↩ 取り消し」+ **Backspace バインド**（PC）+ **文脈ラベル**（`undoLabelKey`）。押下で `undoLast()`。
  `undoLabelKey===null`（取り消し対象なし）のとき `disabled`（no-op、REQ-110）。
- **RallyControls.vue**: 「チームA得点」「チームB得点」「レット」「スキップ」。それぞれ `recordPoint('A'/'B')` /
  `recordLet()` / `skipRally()`（REQ-006/102/103）。セット決着済 / スキップ保留中などの活性制御を session 状態に従う。
- **PositionControls.vue**: 「A入替」「B入替」（`recordOverride('A'/'B')`、REQ-105）+ 「次のセットへ」（`advanceToNextSet()`、
  **決着時=`setWinner!==null` のときのみ活性**、REQ-107）。

**細かいショートカット（J/K/L 等）は作らない**（ui-design.md、Space/Backspace のみ）。キーボードバインドは window
リスナを `onMounted`/`onUnmounted` で対管理し、input フォーカス中は無視する（誤爆防止）。スマホは大ボタン親指リーチ。

新規 DB スキーマ・composable は作らない。

## 実装詳細

### 1. ShotButton.vue（Space + 大ボタン + ショット数） 🔵
**信頼性**: 🔵 *ui-design.md §インタラクション（打った）/ REQ-005 / REQ-202 / NFR-201*

`recordShot`（関数）/ `shotCount`（number）/ `disabled`（boolean、未ロード等）を props で受ける。Space キーで
`recordShot()`（input フォーカス中は無視）。スマホは幅いっぱい最大ボタン、PC は中サイズ + 「Space」ヒント。

**実装ファイル**: `app/components/recording/ShotButton.vue`

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from 'vue'

const props = defineProps<{
  recordShot: () => void | Promise<void>
  shotCount: number
  disabled: boolean
}>()

const { t } = useI18n()

function onKey(e: KeyboardEvent): void {
  // 【input フォーカス中は無視】: 誤爆防止 🔵
  const tag = (e.target as HTMLElement)?.tagName
  if (tag === 'INPUT' || tag === 'TEXTAREA') return
  if (e.code === 'Space' && !props.disabled) {
    e.preventDefault()
    props.recordShot()
  }
}
onMounted(() => window.addEventListener('keydown', onKey))
onUnmounted(() => window.removeEventListener('keydown', onKey))
</script>

<template>
  <UButton
    size="xl"
    class="w-full lg:w-auto"
    :disabled="disabled"
    :label="t('recording.controls.shot')"
    @click="recordShot()"
  />
  <span class="ml-2 text-sm">{{ t('recording.controls.shotCount', { n: shotCount }) }}</span>
</template>
```

### 2. UndoButton.vue（Backspace + 文脈ラベル） 🔵
**信頼性**: 🔵 *ui-design.md §統一「取り消し」/ REQ-110*

`undoLast`（関数）/ `undoLabelKey`（`string | null`）を props で受ける。`undoLabelKey===null` のとき `disabled`
（no-op、REQ-110）。ラベルは `undoLabelKey` を `t()` で解決して「↩ 直近操作」を文脈表示。Backspace バインド（input
フォーカス中は無視 = 文字削除を妨げない）。

```vue
<script setup lang="ts">
const props = defineProps<{
  undoLast: () => void | Promise<void>
  undoLabelKey: string | null
}>()
const { t } = useI18n()

function onKey(e: KeyboardEvent): void {
  const tag = (e.target as HTMLElement)?.tagName
  if (tag === 'INPUT' || tag === 'TEXTAREA') return  // 文字削除を妨げない 🔵
  if (e.key === 'Backspace' && props.undoLabelKey) {
    e.preventDefault()
    props.undoLast()
  }
}
onMounted(() => window.addEventListener('keydown', onKey))
onUnmounted(() => window.removeEventListener('keydown', onKey))
</script>

<template>
  <UButton
    icon="i-lucide-undo-2"
    variant="soft"
    :disabled="undoLabelKey === null"
    :label="undoLabelKey ? t('recording.controls.undoWith', { target: t(undoLabelKey) }) : t('recording.controls.undo')"
    @click="undoLast()"
  />
</template>
```
