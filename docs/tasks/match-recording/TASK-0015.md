## タスク概要

記録済みラリーの履歴一覧 `app/components/recording/RallyHistory.vue` を実装する（REQ-009 / ui-design.md §レイアウト）。
`RallyHistoryItem[]`（interfaces.ts、`useSetRallies` 由来）を props で受け、各行に**ラリー番号 / サーバー（選手名）/
得点結果 / ショット数**を表示する。

- **未確定の明示**（EDGE-003）: `isPointConfirmed=false` の行は**黄バッジ + 「未確定」ラベル**で明示する。
  `isLet=true` は「レット」、`pointWinner` 確定済は「A得点 / B得点」を表示する。
- **ジャンプ**（NFR-203）: 各行の `[▶]` ボタンで該当ラリー先頭（`videoStartTimestampMs`）へ動画シーク。シークは
  VideoPane（TASK-0013）が公開する `seekToMs` を**親（page）経由**で呼ぶため、本コンポーネントは `seek(ms)` を **emit**
  または props 関数で受ける（自身でプレーヤーを持たない、REQ-402/404）。

サーバー名は roster（playerId → 名前）で解決。`videoStartTimestampMs` は履歴 item に含めて受ける（read 射影に追加、
本タスクで `RallyHistoryItem` に `videoStartTimestampMs` を補完するか、別 prop で受ける）。空配列のときは空状態。
全文言 i18n。

新規 DB スキーマ・composable は作らない（`useSetRallies` は実装済を利用）。

## 実装詳細

### 1. props 契約と結果ラベルの導出 🔵
**信頼性**: 🔵 *interfaces.ts RallyHistoryItem / REQ-009 / EDGE-003*

`items`（`RallyHistoryItem[]` + 各 item に `videoStartTimestampMs`）/ `roster` を受ける。各行の結果ラベルは純粋な
分岐：`isPointConfirmed===false` → 「未確定」（黄バッジ）/ `isLet===true` → 「レット」/ それ以外 → `pointWinner` で
「A得点」「B得点」。サーバー名は roster 解決。これらは**表示計算のみ**で副作用なし。

**実装ファイル**: `app/components/recording/RallyHistory.vue`

```vue
<script setup lang="ts">
import type { RallyHistoryItem } from '~/types/match-recording'
import type { PlayerId, Team } from '~/utils/rule-engine/types'

// videoStartTimestampMs を含む拡張（read 射影に追加）🔵 NFR-203
type HistoryRow = RallyHistoryItem & { videoStartTimestampMs: number | null }

const props = defineProps<{
  items: HistoryRow[]
  roster: { playerId: PlayerId, name: string, team: Team }[]
}>()

const emit = defineEmits<{ seek: [ms: number] }>()
const { t } = useI18n()

const nameOf = (id: PlayerId) => props.roster.find(r => r.playerId === id)?.name ?? id

// 【結果ラベル導出（純分岐）】🔵 EDGE-003
function resultLabel(row: HistoryRow): string {
  if (!row.isPointConfirmed) return t('recording.history.unconfirmed') // 未確定（黄）
  if (row.isLet) return t('recording.history.let')
  return row.pointWinner === 'A' ? t('recording.history.pointA') : t('recording.history.pointB')
}
const isUnconfirmed = (row: HistoryRow) => !row.isPointConfirmed
</script>
```

### 2. ジャンプ（seek emit） 🔵
**信頼性**: 🔵 *NFR-203 / useVideoPlayer.controls.seekToMs / REQ-402/404*

`[▶]` ボタンで `videoStartTimestampMs` が非 null のとき `emit('seek', ms)`。本コンポーネントは**プレーヤーを持たない**ため
emit のみ（page が VideoPane の `seekToMs` を呼ぶ）。null（行生成前など）は無効化。

```vue
<script setup lang="ts">
function onJump(row: HistoryRow): void {
  if (row.videoStartTimestampMs !== null) emit('seek', row.videoStartTimestampMs) // 🔵 NFR-203
}
</script>
```

### 3. テンプレート（一覧 + 黄バッジ + 空状態 + レスポンシブ） 🔵
**信頼性**: 🔵 *ui-design.md §レイアウト（RallyHistory）/ NFR-201 Nuxt UI v4 / EDGE-003 / REQ-405*

各行：`#番号` / サーバー名 / 結果ラベル（未確定は `<UBadge color="warning">`）/ 「Nショット」/ `[▶]`。`items` 空は
プレースホルダ（`t('recording.history.empty')`）。スマホは折りたたみ可（ui-design.md「ラリー履歴 ▼」）。

```vue
<template>
  <div class="rally-history">
    <ul v-if="items.length" class="divide-y">
      <li v-for="row in items" :key="row.rallyNumber" class="flex items-center gap-2 py-1">
        <span class="font-mono">#{{ row.rallyNumber }}</span>
        <span>{{ nameOf(row.serverPlayerId) }}</span>
        <UBadge v-if="isUnconfirmed(row)" color="warning" :label="t('recording.history.unconfirmed')" />
        <span v-else>{{ resultLabel(row) }}</span>
        <span class="text-sm text-gray-500">{{ t('recording.history.shotCount', { n: row.shotCount }) }}</span>
        <UButton
          icon="i-lucide-play"
          variant="ghost"
          size="xs"
          :disabled="row.videoStartTimestampMs === null"
          :aria-label="t('recording.history.jump')"
          @click="onJump(row)"
        />
      </li>
    </ul>
    <p v-else class="text-sm text-gray-500">{{ t('recording.history.empty') }}</p>
  </div>
</template>
```

## 注意事項
- 本コンポーネントは**プレーヤーを持たない**。seek は emit のみ（page が VideoPane の `seekToMs` を呼ぶ、REQ-402/404）。
- 未確定（`isPointConfirmed=false`）は**色 + テキスト併用**で明示（色のみに依存しない、EDGE-003）。
- 結果ラベルの分岐順は「未確定 → レット → 得点」。`pointWinner` は確定済のときのみ参照（null 安全）。

- `RallyHistoryItem` に `videoStartTimestampMs` を補完して受ける（read 射影の拡張。射影元 `useSetRallies` の列追加は TASK-0005 で吸収）。
