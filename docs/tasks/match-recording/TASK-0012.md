## タスク概要

`GameState.positions` をコート図（ネット付き・上下2チーム）で可視化する表示専用コンポーネント
`app/components/recording/CourtDiagram.vue` を実装する（ui-design.md §コート図仕様）。

- **向き**: `cameraNearTeam` のチームを**手前（下）**、相手を**奥（上）**に描画。`null` の場合は A を手前の既定とする。
- **配置**: 各チームの half を左右に分割し、`positions.teamA.left/right` / `positions.teamB.left/right` の選手チップを置く。選手名は roster（playerId → 名前）で解決。
- **強調**: サーバー（`GameState.server`）= `◎`（塗り/色）、レシーバー（`GameState.receiver`）= 枠線 + `→`。
- **override 反映**: `applyOverride` 後の `positions` をそのまま描画するため、入替で左右チップが視覚的に入れ替わる（EDGE-008）。

本コンポーネントは `gameState`（+ roster + cameraNearTeam）を props で受け、**自身は session を呼ばない**（page が
`useRecordingSession` を所有し props で渡す、ui-design.md §コンポーネント分割）。表示のみで副作用なし。全文言は i18n。

**左右ミラー補正**（奥チームはカメラ視点で左右が反転して見える）は MVP では「left/right を素直にラベル表示 + コート図で
対応づけ」を基本とし、**厳密なミラー補正は実装時に動画と突き合わせて調整 🟡**（[[project_override_ux]] のプロトタイプ
と併せて検証）。

新規 DB スキーマ・composable は作らない。

## 実装詳細

### 1. props 契約と手前/奥の振り分けロジック 🔵
**信頼性**: 🔵 *ui-design.md §コート図仕様 / REQ-002 / rule-engine GameState*

`gameState`（`GameState | null`）/ `roster`（`{ playerId, name, team }[]`）/ `cameraNearTeam`（`Team | null`）を受ける。
手前チーム = `cameraNearTeam ?? 'A'`、奥チーム = その相手。表示用に near/far の positions を computed で算出する。
選手名は `roster` から playerId で解決（見つからなければ playerId をそのまま）。これは**純粋な表示計算**で副作用なし。

**実装ファイル**: `app/components/recording/CourtDiagram.vue`

```vue
<script setup lang="ts">
import type { GameState, Team, PlayerId } from '~/utils/rule-engine/types'

const props = defineProps<{
  gameState: GameState | null
  roster: { playerId: PlayerId, name: string, team: Team }[]
  cameraNearTeam: Team | null
}>()

const { t } = useI18n()

// 【手前/奥の振り分け】: cameraNearTeam を手前。null は A 既定 🔵 ui-design §向き
const nearTeam = computed<Team>(() => props.cameraNearTeam ?? 'A')
const farTeam = computed<Team>(() => (nearTeam.value === 'A' ? 'B' : 'A'))

// 【選手名解決】: playerId → name（roster）🔵
const nameOf = (id: PlayerId): string =>
  props.roster.find(r => r.playerId === id)?.name ?? id

// 【near/far の positions】🔵 rule-engine positions
const teamKey = (team: Team) => (team === 'A' ? 'teamA' : 'teamB') as const
const nearPositions = computed(() => props.gameState?.positions[teamKey(nearTeam.value)] ?? null)
const farPositions = computed(() => props.gameState?.positions[teamKey(farTeam.value)] ?? null)
</script>
```

### 2. サーバー / レシーバー強調と override 反映 🔵
**信頼性**: 🔵 *ui-design.md §強調・override 反映 / REQ-008 / REQ-105 / EDGE-008*

各チップが `gameState.server` / `gameState.receiver` と一致するかで強調クラスを切り替える computed/関数を持つ。
override は engine 側で `positions` が更新されるため、本コンポーネントは**新 positions を再描画するだけ**で左右入替が
反映される（追加ロジック不要、EDGE-008）。サーバー = `◎` + 塗り、レシーバー = 枠線 + `→`。

```vue
<script setup lang="ts">
const isServer = (id: PlayerId): boolean => props.gameState?.server === id
const isReceiver = (id: PlayerId): boolean => props.gameState?.receiver === id
</script>
```

### 3. テンプレート（ネット付き 2チーム + 空状態 + レスポンシブ） 🔵
**信頼性**: 🔵 *ui-design.md §レイアウト（コート図）/ NFR-201 Nuxt UI v4 / REQ-405*

奥（上）→ ネット → 手前（下）の縦並び。各チームを left/right の2セルに分割。`gameState===null` のときは
プレースホルダ（`t('recording.court.notStarted')`）。幅は `w-full` + `max-w` + アスペクト比で縮小（モバイル）。
ラベル（手前/奥・チーム名）は i18n。

```vue
<template>
  <div class="court-diagram w-full max-w-sm mx-auto" role="img" :aria-label="t('recording.court.ariaLabel')">
    <template v-if="gameState && farPositions && nearPositions">
      <!-- 奥チーム（上）-->
      <div class="flex">
        <CourtCell :name="nameOf(farPositions.left)" :server="isServer(farPositions.left)" :receiver="isReceiver(farPositions.left)" />
        <CourtCell :name="nameOf(farPositions.right)" :server="isServer(farPositions.right)" :receiver="isReceiver(farPositions.right)" />
      </div>
      <div class="net border-t-2 border-dashed" :aria-label="t('recording.court.net')" />
      <!-- 手前チーム（下）-->
      <div class="flex">
        <CourtCell :name="nameOf(nearPositions.left)" :server="isServer(nearPositions.left)" :receiver="isReceiver(nearPositions.left)" />
        <CourtCell :name="nameOf(nearPositions.right)" :server="isServer(nearPositions.right)" :receiver="isReceiver(nearPositions.right)" />
      </div>
    </template>
    <p v-else class="text-center text-sm text-gray-500">{{ t('recording.court.notStarted') }}</p>
  </div>
</template>
```

> 注: `CourtCell` は本コンポーネント内のローカル小要素（インライン or 同ディレクトリの軽量サブ）。`◎` / `→` /
> 枠線は `server` / `receiver` props で切替。厳密な**左右ミラー補正は実装時に動画と突き合わせて調整 🟡**。
