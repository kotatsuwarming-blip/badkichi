## タスク概要

スコア表示ヘッダと動画ペインの2コンポーネントを実装する。

- **ScoreHeader.vue**（`app/components/recording/ScoreHeader.vue`）: 試合名 / セット番号 / スコア（`gameState.score`）/
  サーブ権チーム / サーバー・レシーバー（**テキスト**、選手名は roster 解決）をリアルタイム表示（REQ-008）。コート図
  （TASK-0012）と役割を分担し、本コンポーネントは**文字情報のみ**。`gameState===null` のときは空状態。
- **VideoPane.vue**（`app/components/recording/VideoPane.vue`）: `useVideoPlayer` をラップし、`attach`/`detach` のライフ
  サイクル管理 + 再生コントロール（再生/一時停止/シーク/速度）を提供。さらに**痕跡オーバーレイスロット**（タイムライン
  上にショットの ms マーク、NFR-202）を持つ。`getCurrentTimeMs` を **親（page）経由で session へ渡せるよう公開**する
  （`defineExpose` / emit、ui-design.md §コンポーネント分割）。

VideoPane は本ユニットで**唯一 `useVideoPlayer` を直接持つ**コンポーネント（ui-design.md）。ドメイン概念（ショット/ラリー）
は持ち込まず、痕跡マークは props で受けた ms 配列を描くだけ（依存方向 match-recording → video-playback、REQ-404）。
全文言 i18n。`local` 動画の再選択（REQ-108）は page が File を `VideoSource` に渡す形で、VideoPane は `needsReselect`
状態の表示と再選択 UI のスロット/emit を提供する。

新規 DB スキーマ・composable は作らない（`useVideoPlayer` は実装済を利用）。

## 実装詳細

### 1. ScoreHeader.vue（テキスト表示） 🔵
**信頼性**: 🔵 *ui-design.md §レイアウト（ScoreHeader）/ REQ-008 / rule-engine GameState*

`gameState` / `roster` / `setNumber` / `matchName` を props で受け、`score.teamA - score.teamB`、サーブ権
（`servingTeam`）、サーバー名（`server` を roster 解決）、レシーバー名（`receiver`）をテキストで描く。`gameState===null`
は `0 - 0` 相当のプレースホルダ。コート図と重複する**図形は描かない**（役割分担、ui-design.md）。

**実装ファイル**: `app/components/recording/ScoreHeader.vue`

```vue
<script setup lang="ts">
import type { GameState, Team, PlayerId } from '~/utils/rule-engine/types'

const props = defineProps<{
  gameState: GameState | null
  roster: { playerId: PlayerId, name: string, team: Team }[]
  setNumber: number | null
  matchName: string | null
}>()

const { t } = useI18n()
const nameOf = (id: PlayerId) => props.roster.find(r => r.playerId === id)?.name ?? id
const scoreText = computed(() => {
  const s = props.gameState?.score
  return s ? `${s.teamA} - ${s.teamB}` : '0 - 0'
})
const serverName = computed(() => (props.gameState ? nameOf(props.gameState.server) : ''))
const receiverName = computed(() => (props.gameState ? nameOf(props.gameState.receiver) : ''))
</script>
```

### 2. VideoPane.vue — useVideoPlayer ラップ + ライフサイクル + getCurrentTimeMs 公開 🔵
**信頼性**: 🔵 *ui-design.md §コンポーネント分割 / useVideoPlayer（state/controls/attach/detach）/ REQ-004/404 / architecture.md*

`source`（`VideoSource`）を props で受け `useVideoPlayer(source)` を生成。テンプレートの container ref に対し
`onMounted` で `attach(el)`、`onUnmounted` で `detach()`。再生コントロールは `controls.play/pause/seekToMs/setPlaybackRate`
へ委譲。`controls.getCurrentTimeMs` を `defineExpose` で親へ公開（page が session に注入、ui-design.md）。ドメイン概念は
持ち込まない（REQ-404）。

```vue
<script setup lang="ts">
import { onMounted, onUnmounted, ref } from 'vue'
import type { VideoSource, PlaybackRate } from '~/types/video-playback'

const props = defineProps<{
  source: VideoSource
  /** 痕跡用ショット ms 配列（ドメイン概念は持たず ms のみ）🔵 NFR-202 / REQ-404 */
  shotMarksMs: number[]
}>()

const emit = defineEmits<{ reselect: [file: File] }>()
const { t } = useI18n()

// 【唯一 useVideoPlayer を持つ層】🔵 ui-design.md
const { state, controls, attach, detach } = useVideoPlayer(props.source)
const container = ref<HTMLElement | null>(null)

onMounted(() => { if (container.value) attach(container.value) })
onUnmounted(() => detach())

// 【親へ getCurrentTimeMs を公開】: page → session 注入用 🔵 ui-design.md
defineExpose({ getCurrentTimeMs: controls.getCurrentTimeMs, seekToMs: controls.seekToMs })
</script>
```

### 3. 痕跡オーバーレイ + 再生コントロール + needsReselect 🔵
**信頼性**: 🔵 *NFR-202 / video-playback REQ-009/406 / REQ-108 / EDGE-007 / ui-design.md §レイアウト（痕跡 ┊）*

タイムライン（`durationMs` 基準）上に `shotMarksMs` を割合配置で重ねる（痕跡 ┊）。`state.needsReselect`（local で
オブジェクト URL 喪失）のとき再選択 UI（ファイル input）を出し、選択した File を `emit('reselect', file)`（page が
`VideoSource` を作り直す、REQ-108）。再生/一時停止/速度ボタンは `state.status` / `state.rate` を見て描く。

```vue
<template>
  <div class="video-pane">
    <div ref="container" class="video-container aspect-video w-full bg-black" />

    <!-- 痕跡オーバーレイ（ms マーク）🔵 NFR-202 -->
    <div class="timeline relative h-2 bg-gray-200" :aria-label="t('recording.video.timeline')">
      <span
        v-for="(ms, i) in shotMarksMs"
        :key="i"
        class="shot-mark absolute top-0 w-px h-full bg-amber-500"
        :style="{ left: state.durationMs ? `${(ms / state.durationMs) * 100}%` : '0%' }"
      />
    </div>

    <!-- 再生コントロール 🔵 REQ-004 -->
    <div class="controls flex items-center gap-2">
      <UButton :icon="state.status === 'playing' ? 'i-lucide-pause' : 'i-lucide-play'"
               :aria-label="t('recording.video.playPause')"
               @click="state.status === 'playing' ? controls.pause() : controls.play()" />
      <USelect :model-value="state.rate" :items="rateItems" @update:model-value="controls.setPlaybackRate($event as PlaybackRate)" />
    </div>

    <!-- local 再選択（REQ-108 / EDGE-007）-->
    <div v-if="state.needsReselect" class="reselect">
      <p>{{ t('recording.video.reselectPrompt') }}</p>
      <input type="file" accept="video/*" @change="onReselect">
    </div>
  </div>
</template>
```

- VideoPane は**唯一 `useVideoPlayer` を直接持つ**層。他コンポーネントは props/session 経由（ui-design.md / REQ-402）。
