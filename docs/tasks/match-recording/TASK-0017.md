## タスク概要

録画画面 `app/pages/groups/[id]/matches/[matchId]/record.vue` を **CSR**（REQ-408）で実装し、Phase 1〜3 で実装済みの composable 群とコンポーネント群を結線する **統合ページ** を完成させる。本タスクは新規ロジックを足すのではなく、「session の所有」「VideoSource 構築」「getCurrentTimeMs 注入」「全コンポーネント配線」「レスポンシブ・レイアウト」をオーケストレーションする薄い page を作ることが責務（ui-design.md「record.vue（page・CSR・orchestration）」）。

page が担うこと（architecture.md「ページ / コンポーネント層」）:

1. **動画ソース（`VideoSource`）の構築と `useVideoPlayer` の所有**。`useMatchForRecording(matchId)` で match を読み、`videoSourceType` が `youtube` なら URL から、`local` なら**ファイル再選択 UI**（方式A、REQ-108 / EDGE-007）で供給された `File` から `VideoSource` を構築する。`matches.video_source_url` は local ではファイル名ラベルのみで、page は再選択された File を `LocalSource` に渡す。
2. **`useRecordingSession(matchId, { getCurrentTimeMs })` への `getCurrentTimeMs` 注入**。`VideoPane`（= `useVideoPlayer` を持つ）の `controls.getCurrentTimeMs` を session に注入する（architecture.md / ui-design.md「`VideoPane` のみ `useVideoPlayer` を直接持ち、`getCurrentTimeMs` を page 経由で session に注入」）。
3. **Nuxt UI v4 による記録 UI の描画 + 全コンポーネント配線**。`ScoreHeader` / `VideoPane` / `CourtDiagram` / `ShotButton` / `UndoButton` / `RallyControls` / `PositionControls` / `RallyHistory` / `SetSetupForm` に session の状態 / アクションを props（または provide/inject）で渡す（ui-design.md「全コンポーネントは `useRecordingSession` の状態 / アクションを props/inject で受ける」）。

レイアウトは **レスポンシブ**（ui-design.md モックアップ準拠）:
- **`lg` 以上 = 2カラム**: 上に `ScoreHeader`、左に `VideoPane`、右に `CourtDiagram`、下段に `ShotButton`+`UndoButton` / `RallyControls` / `PositionControls`、最下部に `RallyHistory`。
- **`lg` 未満 = 1カラム縦積み**: VideoPane → CourtDiagram → ShotButton（幅いっぱい最大）→ UndoButton → RallyControls → PositionControls → 次のセットへ → RallyHistory。
- Nuxt UI のブレークポイント（`lg`）で切替。matches.vue / player 管理の既存レスポンシブ作法（`UContainer` + Tailwind の `lg:` プレフィックス）を踏襲。

Group 未所属時は本画面に到達せず、既存の `auth.global.ts` middleware が `/onboarding` へ誘導する（REQ-204）。**本タスクで middleware は変更しない**（既存資産の消費のみ）。

## 実装詳細

### 1. CSR 初期化と match 読込・VideoSource 構築 🔵
**信頼性**: 🔵 *REQ-408（CSR）+ REQ-001/004（match 読込→VideoSource）+ dev/video-playback.vue の buildSource パターン + useMatchForRecording（TASK-0004）*

ページは video API（HTML5 / YouTube IFrame）がブラウザ専用のため CSR で初期化する（ADR-010 / REQ-408）。`useMatchForRecording(matchId)` の Read 結果（`videoSourceType` / `videoSourceUrl` / `roster`）から `VideoSource` を組み立てる。youtube は URL を直接、local は再選択 File を渡す（dev/video-playback.vue の `buildSource()` と同型）。

**実装ファイル**: `app/pages/groups/[id]/matches/[matchId]/record.vue`

```vue
<script setup lang="ts">
import { computed, ref, shallowRef } from 'vue'
import { useRoute } from 'vue-router'
import { useI18n } from 'vue-i18n'
import { useMatchForRecording } from '~/composables/useMatchForRecording'
import { useRecordingSession } from '~/composables/useRecordingSession'
import { useToastErrors } from '~/composables/useToastErrors'
import type { VideoSource } from '~/types/video-playback'

// 動画 API はブラウザ専用のため CSR 限定（REQ-408 / ADR-010）
definePageMeta({ ssr: false })

const route = useRoute()
const { t } = useI18n()
const matchId = computed(() => route.params.matchId as string)

// Read: match → VideoSource 材料 + 4選手ロスター（composable 経由、REQ-402）
const { data: match, pending: matchPending, error: matchError } = useMatchForRecording(matchId.value)
const { showError } = useToastErrors()

// local 再選択 File（方式A、REQ-108 / EDGE-007）。再読込で失効するため毎回供給
const reselectedFile = ref<File | null>(null)
const needsReselect = computed(() =>
  match.value?.videoSourceType === 'local' && reselectedFile.value === null)

function buildSource(): VideoSource | null {
  if (!match.value) return null
  if (match.value.videoSourceType === 'youtube') {
    return match.value.videoSourceUrl ? { type: 'youtube', url: match.value.videoSourceUrl } : null
  }
  // local: matches.video_source_url はファイル名ラベルのみ。再選択 File を供給
  return reselectedFile.value ? { type: 'local', file: reselectedFile.value } : null
}
</script>
```

### 2. useVideoPlayer 所有 → getCurrentTimeMs 注入 → session 結線 🔵
**信頼性**: 🔵 *architecture.md「getCurrentTimeMs 注入」+ ui-design.md「VideoPane のみ useVideoPlayer を直接持つ」+ useVideoPlayer.ts controls.getCurrentTimeMs + dev/video-playback.vue の player 所有パターン*

page は `useVideoPlayer(source)` を所有し（`VideoPane` に渡して attach/detach させる）、`controls.getCurrentTimeMs`（同期・未ロード時 null）を `useRecordingSession` に注入する。session が「打った」時にこの時計を呼んで ms を得る（dataflow.md 機能2）。注入により session はフェイク時計で単体テスト可能（architecture.md「テスト容易性」）。

```vue
<script setup lang="ts">
// ...続き
import { useVideoPlayer } from '~/composables/useVideoPlayer'

const player = shallowRef<ReturnType<typeof useVideoPlayer> | null>(null)
const playerKey = ref(0)

// ソース確定（youtube or local 再選択）時に player を生成 / 再生成
function startPlayback(): void {
  const source = buildSource()
  if (!source) return
  player.value = useVideoPlayer(source)
  playerKey.value++
}
function onReselectFile(file: File): void {
  reselectedFile.value = file
  startPlayback() // 方式A: 新 File で player 再生成（EDGE-007）
}

// getCurrentTimeMs を session に注入（未ロード時 null → session が記録抑止 REQ-202/EDGE-001）
const session = useRecordingSession(matchId.value, {
  getCurrentTimeMs: () => player.value?.controls.getCurrentTimeMs() ?? null
})
</script>
```

### 3. 9コンポーネントの配線（props / inject） 🔵
