## タスク概要

match-recording 画面で使う **全文言** を `i18n/locales/ja.json` と `i18n/locales/en.json` に追加する（REQ-405 / NFR-301）。TASK-0017（record.vue）+ Phase 3 の各コンポーネント（ScoreHeader / VideoPane / CourtDiagram / ShotButton / UndoButton / RallyControls / PositionControls / RallyHistory / SetSetupForm）が参照する i18n キーを ja / en で**キー構造一致**させて定義する。キー構造一致は `scripts/check-i18n-keys.mjs` の CI チェック対象（auth-onboarding / player-management 踏襲）。

ロジック・分岐は無く、ロケール JSON の追記と CI チェック通過の確認のみのため **DIRECT** タスク（direct-setup → direct-verify）。新規 composable / コンポーネント / DB 変更は無い。

対象文言の範囲（ui-design.md レイアウトより）:
- **ボタン**: 打った（Space）/ 取り消し（↩）/ チームA得点 / チームB得点 / レット / スキップ / A入替 / B入替 / 次のセットへ / 戻る / 統計
- **ラベル**: スコア / セット番号 / サーバー / レシーバー / ショット数 / 再生速度
- **コート図**: 手前（カメラ手前チーム）/ 奥 / ネット / 左 / 右 / チームA / チームB
- **履歴**: ラリー番号 / 得点結果（A得点 / B得点 / レット / スキップ・未確定）/ ショット数（◯打）/ ジャンプ
- **取り消し文脈ラベル**: 直近操作の対象（「ショットを取り消す」「得点を取り消す」「レットを取り消す」「左右入替を取り消す」「取り消せる操作がありません」）
- **セットアップ**: 目標点 / デュース有無 / デュース上限点 / 先攻チーム / カメラ手前チーム / 4選手の左右立ち位置 / 開始
- **エラー文言**: 立ち位置重複（EDGE-002）/ 必須未入力 / 楽観書込失敗（再試行）/ セット決着後の追加拒否（EDGE-006）など（既存 `errors.*` で足りない match-recording 固有のもの）

## 注意事項
- **キー構造一致が CI ゲート**（NFR-301）。ja / en のどちらかにキーを足したら必ず両方に足す。`scripts/check-i18n-keys.mjs` を pre-commit / CI 双方で通す。
- 既存共通文言（`errors.*` の汎用キー、`common.*`）を**再定義しない**。match-recording 固有のもののみ追加する。
- JSON は CLAUDE.md の規約（no comma dangle）に従う。整形崩れで lint が落ちないようにする。
- 文言の最終キー名は**参照側（TASK-0017 / 各コンポーネント）を正**とする。設計上の想定キー（`record.*`）と参照側が食い違う場合は参照側に合わせて実体を定義する（本タスクは「実体を埋める」役割）。
- 取り消し文脈ラベル（ui-design.md「文脈ラベルで対象を明示」）は undo 対象（shot / point / let / override / 空）の5種を必ず網羅する。
- DB / API / マイグレーション変更は行わない。
