## タスク概要

セット設定 + 初期立ち位置入力フォーム `app/components/recording/SetSetupForm.vue` を実装する（REQ-002/003 /
ui-design.md §コンポーネント分割）。セット未作成状態（REQ-201）や「次のセットへ」遷移時に表示する（モーダル or
セクション）。

- **セット設定**: 目標点（`targetPoints`）/ デュース有無（`enableDeuce`）/ デュース上限点（`deucePointCap`）/ 先攻
  （`firstServingTeam`）/ カメラ手前チーム（`cameraNearTeamAtStart`）を入力 → `SetSetupInput`（REQ-002）。
- **初期立ち位置**: 4選手それぞれの team × left/right を入力（4行）→ `SetPositionInput[]`（REQ-003）。roster（4選手）を
  選択肢に、各選手に team と position を割り当てる。
- **Zod 検証**: スキーマで型/必須を検証。`(team, position)` の**重複を拒否**（`set_player_positions` の
  `UNIQUE(set_id, team, position)` を UI 段階で先取り、EDGE-002）。**4選手すべての位置が未割当のものを拒否**（4行必須）。
  検証 NG は `<UFormField>` の inline error（EDGE-009）。

確定で `emit('submit', { setup, positions })`（親 = page が `configureAndStartSet` を呼ぶ）。先攻の既定は
`advanceToNextSet` 由来の前勝者（props で `defaultFirstServingTeam` を受け取り初期選択）。全文言 i18n。

本コンポーネントは session を呼ばず、検証済みの入力を emit するのみ（DB 書き込みは session、REQ-402）。新規 DB
スキーマは作らない。Zod スキーマは `app/schemas/` 配下に新設（player-management の `playerNameSchema` 前例）。

## 実装詳細

### 1. Zod スキーマ（set-setup） 🔵
**信頼性**: 🔵 *interfaces.ts SetSetupInput・SetPositionInput / REQ-002/003 / EDGE-002 / set_player_positions UNIQUE*

`app/schemas/set-setup.ts` に設定 + 立ち位置のスキーマを定義（`playerNameSchema` 前例）。`targetPoints` / `deucePointCap`
は正の整数、`firstServingTeam` / `cameraNearTeamAtStart` は `'A'|'B'`（後者は null 許容）。立ち位置は長さ4、各 playerId が
roster に含まれ、`(team, position)` の 4 スロットが**重複なく全て埋まる**ことを `.refine` で検証（EDGE-002）。

**実装ファイル**: `app/schemas/set-setup.ts`

```typescript
import { z } from 'zod'

export const setPositionSchema = z.object({
  playerId: z.string().min(1),
  team: z.enum(['A', 'B']),
  position: z.enum(['left', 'right'])
})

export const setSetupSchema = z.object({
  setup: z.object({
    setNumber: z.number().int().positive(),
    targetPoints: z.number().int().positive(),
    enableDeuce: z.boolean(),
    deucePointCap: z.number().int().positive(),
    firstServingTeam: z.enum(['A', 'B']),
    cameraNearTeamAtStart: z.enum(['A', 'B']).nullable()
  }),
  positions: z.array(setPositionSchema).length(4)
}).refine(
  // 【(team, position) 重複拒否 + 4スロット充足】🔵 EDGE-002 / UNIQUE(set_id, team, position)
  ({ positions }) => {
    const slots = new Set(positions.map(p => `${p.team}:${p.position}`))
    return slots.size === 4 // A:left/A:right/B:left/B:right が重複なく揃う
  },
  { message: 'duplicateSlot', path: ['positions'] }
)
```

### 2. フォーム state と先攻既定 / デュース条件表示 🔵
**信頼性**: 🔵 *REQ-002 / REQ-107（前勝者 carry）/ ui-design.md*

`roster`（4選手）/ `setNumber` / `defaultFirstServingTeam`（前勝者、`Team | null`）を props で受ける。`firstServingTeam` の
初期値は `defaultFirstServingTeam ?? 'A'`。`deucePointCap` の入力は `enableDeuce===true` のときのみ活性（条件表示）。
立ち位置は4選手それぞれに team/position を割り当てる UI（USelect 等）。

**実装ファイル**: `app/components/recording/SetSetupForm.vue`

```vue
<script setup lang="ts">
import { setSetupSchema } from '~/schemas/set-setup'
import type { SetSetupInput, SetPositionInput } from '~/types/match-recording'
import type { Team, PlayerId } from '~/utils/rule-engine/types'

const props = defineProps<{
  roster: { playerId: PlayerId, name: string, team: Team }[]
  setNumber: number
  defaultFirstServingTeam: Team | null
}>()

const emit = defineEmits<{ submit: [payload: { setup: SetSetupInput, positions: SetPositionInput[] }] }>()
const { t } = useI18n()

// 【設定 state（既定値）】🔵 interfaces.ts 既定（21 / true / 30）
const targetPoints = ref(21)
const enableDeuce = ref(true)
const deucePointCap = ref(30)
const firstServingTeam = ref<Team>(props.defaultFirstServingTeam ?? 'A') // 前勝者 carry 🔵 REQ-107
const cameraNearTeamAtStart = ref<Team | null>('A')

// 【立ち位置 state】: 4選手の team/position 割当 🔵 REQ-003
const positions = ref<SetPositionInput[]>(
  props.roster.map(r => ({ playerId: r.playerId, team: r.team, position: 'left' as const }))
)

const formError = ref<string | null>(null)
</script>
```

### 3. 検証 + submit（inline error / EDGE-002） 🔵
**信頼性**: 🔵 *EDGE-002 / EDGE-009 / error-handling §6① / REQ-402*

submit で `setSetupSchema.safeParse` を実行。失敗（重複スロット・4行未充足・必須欠落）なら `<UFormField>` の inline
error にメッセージを出し**emit しない**（EDGE-009 / 無駄な insert を発生させない）。成功なら `emit('submit', parsed.data)`
（親 page が `configureAndStartSet` を呼び DB 同期書き込み）。

```vue
<script setup lang="ts">
function onSubmit(): void {
  const setup: SetSetupInput = {
    setNumber: props.setNumber,
    targetPoints: targetPoints.value,
    enableDeuce: enableDeuce.value,
    deucePointCap: deucePointCap.value,
    firstServingTeam: firstServingTeam.value,
    cameraNearTeamAtStart: cameraNearTeamAtStart.value
  }
  const parsed = setSetupSchema.safeParse({ setup, positions: positions.value })
  if (!parsed.success) {
    // 【inline error】: 重複スロット等を表示し emit しない 🔵 EDGE-002/009
    formError.value = t(`recording.setup.errors.${parsed.error.issues[0].message}`)
    return
  }
  formError.value = null
  emit('submit', parsed.data) // 親が configureAndStartSet（DB 書き込みは session）🔵 REQ-402
}
</script>
```

### 4. テンプレート（設定 + 立ち位置 4行 + 条件表示） 🔵
**信頼性**: 🔵 *ui-design.md §コンポーネント分割（SetSetupForm）/ NFR-201 Nuxt UI v4 / REQ-405*

`<UForm>` 内に設定フィールド（目標点 `UInput[type=number]` / デュース `USwitch` / 上限点（`enableDeuce` 時のみ）/
先攻 `URadioGroup` / カメラ手前 `URadioGroup`）+ 立ち位置4行（選手ごとに team/position の `USelect`）。`(team,position)`
重複や4行エラーは `formError` を該当 `<UFormField :error>` に表示。確定ボタンは `pending` 中 disabled（pending は親管理）。

```vue
<template>
  <UForm :state="{ targetPoints, positions }" @submit.prevent="onSubmit">
    <UFormField :label="t('recording.setup.targetPoints')" name="targetPoints">
      <UInput v-model.number="targetPoints" type="number" min="1" />
    </UFormField>
    <UFormField :label="t('recording.setup.enableDeuce')" name="enableDeuce">
      <USwitch v-model="enableDeuce" />
    </UFormField>
    <UFormField v-if="enableDeuce" :label="t('recording.setup.deucePointCap')" name="deucePointCap">
      <UInput v-model.number="deucePointCap" type="number" min="1" />
    </UFormField>
    <UFormField :label="t('recording.setup.firstServingTeam')" name="firstServingTeam">
      <URadioGroup v-model="firstServingTeam" :items="teamItems" />
    </UFormField>
    <UFormField :label="t('recording.setup.cameraNearTeam')" name="cameraNearTeamAtStart">
      <URadioGroup v-model="cameraNearTeamAtStart" :items="teamNullableItems" />
    </UFormField>

    <!-- 立ち位置 4行 -->
    <UFormField :label="t('recording.setup.positions')" name="positions" :error="formError ?? undefined">
      <div v-for="(p, i) in positions" :key="p.playerId" class="flex gap-2 items-center">
        <span>{{ roster[i]?.name }}</span>
        <USelect v-model="p.team" :items="teamItems" />
        <USelect v-model="p.position" :items="sideItems" />
      </div>
    </UFormField>

    <UButton type="submit" :label="t('recording.setup.start')" />
  </UForm>
</template>
```
