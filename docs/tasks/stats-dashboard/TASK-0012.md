## タスク概要

ラリー長（ショット数）を区間（ビン）に集約し、**ビン別の本数（棒）+ サーブ側勝率（線）**のコンボチャートを vue-echarts で描画する読み取り専用コンポーネント。x 軸は `RALLY_LENGTH_BINS`（1〜3 / 4〜7 / 8〜12 / 13+）。棒は本数（第1軸）、線は勝率（第2軸 0〜100%）。棒をクリックで **複数選択可**（和集合）にし、選択されたビンキー配列を `emit('selectBins', binKeys[])` でクロスフィルタへ通知する（REQ-010）。

ショット数 0 のラリーはラリー長分析から除外（EDGE-102）。これは上位 RPC / util（`toRallyLengthBins`）で除外済みの `RallyLengthBin[]` を props で受け取る前提とし、本コンポーネントは描画 + 複数選択 emit に専念する。CSR 限定（REQ-404）のため `<ClientOnly>` でラップする。

## 実装詳細

### 1. props / emits 契約 🔵
**信頼性**: 🔵 *interfaces.ts（RallyLengthBin / ShotBin）/ ヒアリング2026-06-09*

**実装ファイル**: `app/components/stats/StatsRallyLengthChart.vue`

```typescript
import type { RallyLengthBin } from '~/types/stats-dashboard'
import { RALLY_LENGTH_BINS } from '~/types/stats-dashboard'

const props = defineProps<{
  bins: RallyLengthBin[]              // toRallyLengthBins() の出力（shot 0 除外済み）
  selectedBinKeys?: string[]          // 親（useStatsFilter）の現在選択（双方向表示用）
}>()

const emit = defineEmits<{
  selectBins: [binKeys: string[]]     // トグル後の選択集合（和集合の元）
}>()
```

### 2. コンボチャート（棒=本数 / 線=勝率 第2軸） 🔵
**信頼性**: 🔵 *REQ-005 / ヒアリング2026-06-09 / TASK-0006 シリーズ化 util*

- `to-rally-length-series.ts`（TASK-0006）で `RallyLengthBin[]` → echarts シリーズ（棒 = `rallies`、線 = `serveWinRate`）へ整形。本コンポーネントは整形結果を `option` に渡す。
- 2 つの y 軸: 左 = 本数（整数, 0 始まり）、右 = 勝率（0〜100% or 0〜1）。`GridComponent` は TASK-0001 で登録済。
- `serveWinRate === null`（区間内 0 件）は線の欠損点（`null`）として連結しない 🔵 *interfaces.ts RallyLengthBin*。

### 3. ビンの複数選択 + トグル + emit 🔵
**信頼性**: 🔵 *REQ-010 / ヒアリング2026-06-09（複数選択・和集合）*

- 棒クリックで該当ビンの `key` を選択集合へトグル（既選択なら外す / 未選択なら足す）。
- トグル後の `string[]`（例 `['1-3','4-7']`）を `emit('selectBins', keys)`。和集合→範囲変換（`binsToRanges`）はクロスフィルタ側（useStatsFilter / filter-rallies）が担う 🔵 *interfaces.ts*。
- `props.selectedBinKeys` を視覚的にハイライト（選択中バーの色変え）して双方向に同期 🟡。

### 4. shot 0 除外の前提（EDGE-102） 🔵
**信頼性**: 🔵 *EDGE-102 / interfaces.ts（shot_count=0 は除外済み）*

- shot_count = 0 のラリーは `stats_rally_length` RPC / `toRallyLengthBins` で既に除外されている。本チャートはラリー長分析専用で 0 本を表示しない（テーブルには別途出る = TASK-0013 の責務）🔵。

### 5. `<ClientOnly>` ラップ 🔵
**信頼性**: 🔵 *REQ-406 / REQ-404 / ADR-010*

## 注意事項
- **集約・除外は util / RPC の責務**: ビン集約（`toRallyLengthBins`）と shot 0 除外（EDGE-102）は TASK-0006 / RPC 側。本コンポーネントは描画 + 選択 emit のみ（REQ-407）🔵。
- **複数選択は和集合**: 選んだビンの OR（例 1〜3 + 4〜7 = 1〜7）。範囲化（`binsToRanges`）はフィルタ側で行う（ヒアリング2026-06-09）🔵。
- **欠損の扱い**: 勝率 null は線で連結しない（0% と混同しない）🔵。
- **2 軸厳守**: 本数（左軸）と勝率（右軸）を同一軸に乗せない 🔵。
- **CSR 限定**: `<ClientOnly>` 必須（REQ-404 / ADR-010）🔵。
