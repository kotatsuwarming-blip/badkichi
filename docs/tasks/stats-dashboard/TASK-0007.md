## タスク概要

per-match の **クライアント側クロスフィルタ**を実装する純関数。読み込み済みの `RallyRow[]` を `StatsFilter`（選手 / ペア × 役割 / ラリー長ビン）で絞り込む（往復なし、REQ-010）。

- **`filterRallies(rows, filter, roster?): RallyRow[]`**:
  - **選手フィルタ**: `filter.role` に応じ、`serve` なら `server_player_id`、`receive` なら `receiver_player_id` が `filter.playerId` に一致する行を残す。`role` 未指定なら server / receiver いずれか一致。
  - **ペアフィルタ**: `roster`（`pairA: [id,id]` / `pairB: [id,id]`）でペアが所属する側（A / B）を判定し、`role` 連動でラリーを残す（`serve` = ペアが serving 側 = `serving_team` がペアの所属側 / `receive` = 受け側 = 相手が serving 側）。
  - **ラリー長ビンフィルタ**: `filter.shotBinKeys`（複数選択）の和集合範囲に `shot_count` が入る行を残す。`shot_count = 0` はビンに含めない（EDGE-102、テーブルには出るが長さフィルタ適用時は除外）。
  - **複合**: 上記は AND で連鎖適用。

**チーム A/B はフィルタの軸にしない**（集計・絞り込みのキーは選手 / ペア = `player_id`）。A/B は serve/receive 判定の内部利用のみ（ヒアリング2026-06-09）。

## 実装詳細

### 1. filterRallies（純関数・クロスフィルタ） 🔵
**信頼性**: 🔵 *interfaces.ts §純関数ヘルパー / StatsFilter / REQ-010 / REQ-012 / EDGE-102 / ヒアリング2026-06-09*

ペアの所属側判定は呼び出し側が与える `roster`（per-match のペア構成）に基づく。`roster` 未指定でペアフィルタが指定された場合は所属判定不能のため絞り込みをスキップ（防御的、空にしない）。

**実装ファイル**: `app/utils/stats-dashboard/filter-rallies.ts`

```typescript
/**
 * 【機能概要】: per-match のクライアント側クロスフィルタ。RallyRow[] を選手/ペア×役割/ラリー長ビンで絞る。
 * 【実装方針】: チーム A/B は軸にしない（player_id ベース）。A/B は serve/receive 判定の内部利用のみ。
 *             ラリー長ビンは binsToRanges（TASK-0006）で和集合範囲へ変換。shot_count=0 は長さ除外（EDGE-102）。
 * 🔵 interfaces.ts §純関数ヘルパー / StatsFilter / RallyRow / REQ-010 / REQ-012 / ヒアリング2026-06-09
 */
import type { StatsFilter, RallyRow, Team } from '~/types/stats-dashboard'
import { binsToRanges } from '~/utils/stats-dashboard/rally-length-bins'

interface Roster {
  pairA: [string, string]
  pairB: [string, string]
}

/** ペア（無向 2 選手）が roster のどちら側に属すか（一致しなければ null） */
function pairSide(pair: { player1Id: string, player2Id: string }, roster: Roster): Team | null {
  const set = new Set([pair.player1Id, pair.player2Id])
  if (roster.pairA.every(p => set.has(p))) return 'A'
  if (roster.pairB.every(p => set.has(p))) return 'B'
  return null
}

export function filterRallies(
  rows: RallyRow[],
  filter: StatsFilter,
  roster?: Roster
): RallyRow[] {
  let result = rows

  // 【選手フィルタ × role】: serve=server_player_id / receive=receiver_player_id / role 未指定は両方
  if (filter.playerId) {
    const pid = filter.playerId
    result = result.filter((r) => {
      if (filter.role === 'serve') return r.server_player_id === pid
      if (filter.role === 'receive') return r.receiver_player_id === pid
      return r.server_player_id === pid || r.receiver_player_id === pid
    })
  }

  // 【ペアフィルタ × role】: roster で所属側を判定、serve=ペアが serving 側 / receive=受け側
  if (filter.pair && roster) {
    const side = pairSide(filter.pair, roster)
    if (side) {
      result = result.filter((r) => {
        if (filter.role === 'serve') return r.serving_team === side
        if (filter.role === 'receive') return r.serving_team !== side
        return true // role 未指定: ペアが関与する全ラリー（serve/receive どちらも）
      })
    }
  }

  // 【ラリー長ビン和集合】: shot_count が選択範囲に入る行のみ。shot_count=0 は除外（EDGE-102）
  if (filter.shotBinKeys.length > 0) {
    const ranges = binsToRanges(filter.shotBinKeys)
    result = result.filter(r =>
      r.shot_count > 0
      && ranges.some(rg => r.shot_count >= rg.min && (rg.max === null || r.shot_count <= rg.max))
    )
  }

  return result
}
```

## 注意事項
- **チーム A/B は軸にしない**（player_id ベース）。A/B は「ペアが serving 側か受け側か」を判定する内部利用に限る（ヒアリング2026-06-09）。
- ペアフィルタは per-match 限定（`roster` を呼び出し側が与える）。Group 横断はサーバー側（TASK-0010 の `stats_rallies` 引数）で評価する（本関数の責務外）。
- `shot_count = 0` はラリー長ビンに含めない（EDGE-102）。ただしビン未指定時はテーブルに残す（除外はラリー長フィルタ適用時のみ）。
- ビン → 範囲変換は TASK-0006 の `binsToRanges` を再利用し、範囲ロジックを二重実装しない。
- `roster` 未指定でペアフィルタ指定時は所属判定不能のため絞り込みをスキップ（空配列にしない＝防御的）。
