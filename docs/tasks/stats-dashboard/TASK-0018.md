## タスク概要

record（録画）画面・試合一覧から stats（統計）画面への導線、および Group 横断統計への導線を整備し、
stats 画面から record 画面への戻り導線を加える。あわせて `stats.*` の i18n 文言を ja/en で整合させ、
不足キーを補完する。

REQ-008（record ↔ stats 相互導線）と REQ-002（Group 横断ダッシュボード `/groups/[id]/stats` への到達）
を満たすため、既存の matches 一覧（`app/pages/groups/[id]/matches/index.vue`）の録画導線パターン
（`UButton :to=".../record"`）に倣い、記録あり / 完了試合に対して「統計を見る」導線を一覧側に追加する。
stats 画面側には「記録に戻る」導線を置き、相互に行き来できる回遊を成立させる。

新規 DB スキーマ・新規 RPC は無い（読み取り専用既存 RPC を消費するページ群への導線整備）。本タスクは
回遊導線と文言整合に閉じ、集計ロジック・チャート描画は先行タスク（Phase 2/3）の成果物を利用する。

## 実装詳細

### 1. 試合一覧 → 統計の導線（記録あり / 完了試合）🔵
**信頼性**: 🔵 *REQ-008 / 既存 matches 一覧の録画導線パターン（app/pages/groups/[id]/matches/index.vue L184-193 の `UButton :to=".../record"`）*

既存の matches 一覧は各行に「録画」ボタン（`:to="/groups/${route.params.id}/matches/${m.id}/record"`）を
持ち、`m.recordingStatus`（`done` / `recording`）でバッジ表示を分岐している。同じ行に「統計を見る」ボタンを
追加し、**記録あり（`recordingStatus === 'recording'` または `'done'`）** の試合に対してのみ表示する。
リンク先は `/groups/${route.params.id}/matches/${m.id}/stats`。未記録（バッジなし）の試合では非表示にして、
空ダッシュボードへの誘導を避ける（REQ-201 の空状態は stats 側で担保するが、導線自体を出さない方が回遊が素直）。

**実装ファイル**: `app/pages/groups/[id]/matches/index.vue`（既存・追記）

```vue
<UButton
  v-if="m.recordingStatus === 'recording' || m.recordingStatus === 'done'"
  color="primary"
  variant="ghost"
  size="sm"
  icon="i-lucide-bar-chart-3"
  :to="`/groups/${route.params.id}/matches/${m.id}/stats`"
  :aria-label="t('stats.viewStats')"
  :label="t('stats.viewStats')"
/>
```

> 注: 表示条件キーは既存 `MatchListItem.recordingStatus` を流用する（新規取得は不要）。`done` のみに
> 絞るか `recording` も含めるかは「記録あり」= 1 件でもラリーがある状態を指すため両方を含める。

**信頼性**: 🔵 *REQ-008（`[← 記録に戻る]` 相当）/ PRD §5.4*

試合単位 stats ページ（`app/pages/groups/[id]/matches/[matchId]/stats.vue`）のヘッダに「記録に戻る」

## 注意事項
- **既存パターン踏襲（REQ-008）**: 「統計を見る」導線は既存 matches 一覧の録画ボタン（`UButton :to=".../record"`）と同じ書式で追加し、行のボタン群のスタイル（`color`/`variant`/`size`）を揃える。独自の遷移実装（`navigateTo` 手書き等）は避け、`:to` で宣言的に書く。
- **ja / en キー一致（i18n）**: `stats.*` は ja と en の**キー集合を完全一致**させる。片側のみのキーは vue-i18n の警告 / 表示崩れの原因になる。完了前に ja・en の差分が 0 であることを確認する。
- **先行タスクの文言を壊さない**: Phase 2/3 で既に `stats.*`（title・空状態・母数併記等）が追加済みなら、本タスクは**追記**に徹し既存キーを上書きしない。
- **読み取り専用の境界（REQ-401）**: 本タスクは導線・文言のみ。録画系テーブルへの書き込みや新規 RPC を一切追加しない。
- **依存方向（REQ-405 / ADR-002）**: stats → video-playback の一方向は維持。導線整備で video-playback にドメイン概念を持ち込まない。
- **CSR 限定（REQ-404 / ADR-010）**: stats ページはチャートを `<ClientOnly>` で描画する前提のため、戻り導線等のヘッダ要素は SSR でも崩れないレイアウトに留める。
