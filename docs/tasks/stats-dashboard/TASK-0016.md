## タスク概要

試合単位ダッシュボード `/groups/[id]/matches/[matchId]/stats` を実装する。`useMatchStats`（集計）+ `useMatchRallies`（ラリー行）+ `useStatsFilter`（クロスフィルタ状態）を結線し、`StatsRateChart` / `StatsRallyLengthChart` / `StatsRallyTable` / `StatsVideoPane` / `StatsEmptyState` を配置する。

クロスフィルタは **per-match のクライアント適用**（`useStatsFilter.apply(rows)` = `filter-rallies`、サーバー往復なし）。チャート選択 → フィルタ更新 → テーブル連動絞り込み → 行選択 → `StatsVideoPane.seekToMs` の一連を同一画面で完結させる（dataflow.md 機能1〜3）。確定ラリー 0 件は `StatsEmptyState`、ラリー未記録は別 variant で表示（REQ-103/201）。record ↔ stats の相互導線（戻る/記録へ, REQ-008）を置く。レイアウトが収まらない場合はタブ/折りたたみ等の代替を検討（NFR-203）。

## 実装詳細

### 1. ルート + composable 結線 🔵
**信頼性**: 🔵 *REQ-001 / 既存 record.vue（route.params.matchId / id）/ interfaces.ts*

**実装ファイル**: `app/pages/groups/[id]/matches/[matchId]/stats.vue`

```typescript
import { computed, ref } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()
const matchId = route.params.matchId as string
const groupId = route.params.id as string

const { data: stats, pending: statsPending, error: statsError } = useMatchStats(matchId)
const { data: rallies, pending: ralliesPending } = useMatchRallies(matchId)
const { filter, setFilter, clear, apply } = useStatsFilter()

// per-match: クライアント絞り込み（filter 変化に追従, 往復なし）
const filteredRallies = computed(() => apply(rallies.value ?? []))

// 選手/ペア表示切替（REQ-004）
const mode = ref<'player' | 'pair'>('player')
```

### 2. クロスフィルタ（チャート → テーブル, per-match） 🔵
**信頼性**: 🔵 *REQ-010 / dataflow.md 機能2 / architecture.md パフォーマンス（per-match はクライアント）*

- `StatsRateChart` の `@select`（{playerId|pair, role}）→ `setFilter(...)`。
- `StatsRallyLengthChart` の `@selectBins`（binKeys[]）→ `setFilter({ shotBinKeys })`。
- テーブルは `filteredRallies`（= `apply(rallies)`）を受け取り連動。フィルタ解除（`clear` / 同一選択トグル）で全件へ戻る（TC-010-02）🔵。
- per-match は **サーバー往復なし**でクライアント計算（`filter-rallies`）🔵 *architecture.md*。

### 3. ラリー再生（テーブル → プレーヤー, 同一試合） 🔵
**信頼性**: 🔵 *REQ-007/011 / dataflow.md 機能3*

```typescript
const videoPane = ref<{ seekToMs: (ms: number) => void } | null>(null)

function onSelectRally(rally: RallyRow): void {
  if (rally.video_start_timestamp_ms == null) return // EDGE-103（テーブル側でも非リンク）
  videoPane.value?.seekToMs(rally.video_start_timestamp_ms)
}
```

- 試合単位は単一ソース（`source` は match の動画から構築）。同一試合内なので `seekToMs` のみ（ソース切替は不要, REQ-104 は TASK-0017 の範疇）🔵。
- ラリー区切りマーカー = `filteredRallies` の非 null な `video_start_timestamp_ms` を `StatsVideoPane :rally-markers-ms` に渡す 🟡。

### 4. 空状態 + ローディング 🔵
**信頼性**: 🔵 *REQ-103/201 / interfaces.ts StatsAggregate.isEmpty / dataflow.md 機能1 ステップ5*

- `statsPending` / `ralliesPending` 中はスケルトン/ローディング（NFR-001）。
- `stats.value?.isEmpty`（確定ラリー0件）で `StatsEmptyState`。ラリー行も 0 件なら `variant='not-recorded'`、確定のみ0件（レット/未確定はある）なら `variant='no-data'`（EDGE-101）🔵。
- `statsError` はトースト（既存 `useNoticeErrors` パターン）にフォールバックし、画面を壊さない 🔵 *dataflow.md エラーハンドリング*。

### 5. 相互導線 + レイアウト 🔵
**信頼性**: 🔵 *REQ-008 / NFR-202/203*

- 「記録に戻る」= `/groups/[id]/matches/[matchId]/record` への `NuxtLink`（`stats.nav.toRecord`, TASK-0015）。record 側 → stats 導線は TASK-0019 / record 画面側で対応 🔵。
- レイアウト: チャート + テーブル + プレーヤー共存。画面に収まらない場合はタブ / 折りたたみ / セクション分割で代替（NFR-203）🟡。

## 注意事項
- **per-match はクライアント絞り込み**: `apply(rows)` で往復なし（架空の再フェッチを足さない）。サーバー側フィルタは Group 横断（TASK-0017）の話 🔵 *architecture.md*。
- **テーブルは全ライブラリー、チャートは確定のみ**: テーブルはレット/未確定も表示（結果列で区別）、チャート集計は確定のみ（RPC 側除外, REQ-101）。整合に注意 🔵。
- **EDGE-103 二重ガード**: テーブル側で非リンク + ページ側 onSelectRally でも null ガード（再生不可）🔵。
- **空状態の variant 判定はページ責務**: `isEmpty` と `rallies.length` から no-data / not-recorded を出し分け（TASK-0015 に variant を渡す）🔵。
- **CSR 限定**: チャートは `<ClientOnly>`（子コンポーネント内）。ページ自体も Supabase クライアント取得は CSR（ADR-010）🔵。
- **route param**: `matchId` / `id` は既存 record.vue と同じ取り方（`route.params.matchId` / `route.params.id`）🔵。
