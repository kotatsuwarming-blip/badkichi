## タスク概要

ショット数粒度の RPC 行を **区間（ビン）へ集約**し、複数ビン選択を **OR 範囲**へ変換する純関数ユーティリティを実装する。

- **`RALLY_LENGTH_BINS`**: 既定のビン定義。`interfaces.ts` から import 可能（`~/types/stats-dashboard` 経由で再 export）。境界は調整可能な定数として一元管理（`13+` は `max=null`＝上限なし）。
- **`toRallyLengthBins(rows: RallyLengthRow[], bins): RallyLengthBin[]`**: ショット数粒度（`shot_count` ごと）の RPC 行を区間へ集約。区間内の `rallies` を合計（本数＝棒）、区間内のサーブ側勝率（`Σserve_won / Σrallies`＝線）を算出。区間内 0 件のときは `serveWinRate = null`。
- **`binsToRanges(binKeys: string[], bins): ShotRange[]`**: 選択ビンキー → OR 結合の範囲配列。隣接ビンは 1 範囲へ結合してよい（`13+` は `max=null`）。
- **`to-rally-length-series.ts`**: ビン（`RallyLengthBin[]`）→ echarts 用の「本数（棒）+ サーブ側勝率（線）」シリーズへ整形。

`shot_count = 0` のラリーは RPC 側で既に除外済み（EDGE-102）。本ユーティリティは RPC が返したショット数粒度（`>= 1`）の行のみを扱う。

### 1. RALLY_LENGTH_BINS + toRallyLengthBins + binsToRanges 🔵
**信頼性**: 🔵 *interfaces.ts RALLY_LENGTH_BINS / RallyLengthBin / EDGE-102 / ヒアリング2026-06-09*

**実装ファイル**: `app/utils/stats-dashboard/rally-length-bins.ts`

```typescript
/**
 * 【機能概要】: ショット数粒度の RPC 行を区間（ビン）へ集約し、選択ビンを OR 範囲へ変換する純関数群。
 * 【実装方針】: ビン定義は types に一元化（RALLY_LENGTH_BINS）。集約は Σrallies / Σserve_won。
 *             区間内 0 件は serveWinRate=null。shot_count=0 は RPC 側で除外済（EDGE-102）。
 * 🔵 interfaces.ts RALLY_LENGTH_BINS / RallyLengthBin / ShotRange / ヒアリング2026-06-09
 */
import type { ShotBin, RallyLengthRow, RallyLengthBin, ShotRange } from '~/types/stats-dashboard'
import { RALLY_LENGTH_BINS } from '~/types/stats-dashboard'

export { RALLY_LENGTH_BINS }

/** shot_count が bin の [min, max]（max=null は上限なし）に入るか */
function inBin(shotCount: number, bin: ShotBin): boolean {
  return shotCount >= bin.min && (bin.max === null || shotCount <= bin.max)
}

/** ショット数粒度 → 区間集約（本数合計 + サーブ側勝率）。区間内 0 件は serveWinRate=null */
export function toRallyLengthBins(
  rows: RallyLengthRow[],
  bins: readonly ShotBin[] = RALLY_LENGTH_BINS
): RallyLengthBin[] {
  return bins.map((bin) => {
    const inside = rows.filter(r => inBin(r.shot_count, bin))
    const rallies = inside.reduce((s, r) => s + r.rallies, 0)
    const won = inside.reduce((s, r) => s + r.serve_won, 0)
    return {
      bin,
      rallies,
      serveWinRate: rallies > 0 ? won / rallies : null
    }
  })
}

/** 選択ビンキー → OR 結合の範囲配列（隣接ビンは結合） */
export function binsToRanges(
  binKeys: string[],
  bins: readonly ShotBin[] = RALLY_LENGTH_BINS
): ShotRange[] {
  // 【選択順を定義順に正規化】し min 昇順で隣接結合
  const selected = bins
    .filter(b => binKeys.includes(b.key))
    .sort((a, b) => a.min - b.min)
  const ranges: ShotRange[] = []
  for (const bin of selected) {
    const last = ranges[ranges.length - 1]
    // 【隣接結合】: 直前範囲の上限 +1 が次ビンの下限なら 1 範囲へ統合（max=null は上限なし）
    if (last && last.max !== null && last.max + 1 === bin.min) {
      last.max = bin.max
    } else {
      ranges.push({ min: bin.min, max: bin.max })
    }
  }
  return ranges
}
```

### 2. ビン → シリーズ整形（to-rally-length-series） 🔵
**信頼性**: 🔵 *api-endpoints.md §3（toRallyLengthSeries）/ REQ-005*

`RallyLengthBin[]` を echarts のコンボチャート（本数＝棒・勝率＝線）に渡せる形へ整形。`serveWinRate=null` の区間は線を欠損（`null`）として残す。

**実装ファイル**: `app/utils/stats-dashboard/to-rally-length-series.ts`

```typescript
/**
 * 【機能概要】: RallyLengthBin[] → echarts コンボシリーズ（labels / counts(棒) / winRates(線)）
 * 【実装方針】: 0 件区間の勝率は null のまま欠損として渡す（線が途切れる）。
 * 🔵 api-endpoints.md §3 / REQ-005 / ヒアリング2026-06-08
 */
import type { RallyLengthBin } from '~/types/stats-dashboard'

export interface RallyLengthSeries {
  labels: string[]
  counts: number[]
  winRates: (number | null)[]
}

export function toRallyLengthSeries(binsData: RallyLengthBin[]): RallyLengthSeries {
  return {
    labels: binsData.map(b => b.bin.label),
    counts: binsData.map(b => b.rallies),
    winRates: binsData.map(b => b.serveWinRate)
  }
}
```

## 注意事項
- ビン定義（境界）は `interfaces.ts` の `RALLY_LENGTH_BINS` を単一の真実とし、本ファイルでは **再 export** に留める（境界の二重管理を避ける）。
- `shot_count = 0` は RPC 側で除外済み（EDGE-102）。本関数に 0 除外ロジックを入れない（入力は `>= 1` 前提だが、防御的に `inBin` の `min >= 1` 定義で自然除外される）。
- 区間内 0 件は `serveWinRate = null`（0 除算回避）。`rallies = 0` でも返す（チャートで「0 本」を示せるよう棒は残す）。
- `binsToRanges` の隣接結合は OR 範囲を最小化する最適化であり、結合しなくても意味は同じ（テストは結合済みを期待）。
