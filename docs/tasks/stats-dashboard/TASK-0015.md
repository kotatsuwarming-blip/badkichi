## タスク概要

統計ダッシュボードの**空状態コンポーネント**（データなし / 未記録）と、stats 画面全体で使う **i18n `stats.*` 文言の初期追加**を行う。空状態は確定ラリー 0 件（未記録、または全件がレット/未確定で除外）のときにチャート・テーブルの代わりに表示し、チャートをエラーにしない（REQ-103 / EDGE-101）。

i18n は `i18n/locales/ja.json` / `en.json` に `stats.*` キーを追加する。画面タイトル・空状態文言・チャートラベル・母数表記（`{rate}%（n={n}）` 形式 NFR-201）・選手/ペア切替ラベル・結果ラベル（レット/未確定, TASK-0013 で使用）等、後続コンポーネント（TASK-0011〜0014, 0016, 0017）が参照する文言を一括で用意する。後続タスクは必要に応じてキーを追記する。

## 注意事項
- **生文字列禁止**: コンポーネントは文言を `t('stats.*')` で解決。Vue / util に日本語/英語の生文字列を埋めない（error-handling 原則5 / 既存 VideoPlayer 方針）🔵。
- **ja/en 構造一致**: 両 locale でキー構成を一致させる（片方欠落は実行時 fallback で気付きにくい）🔵。
- **母数表記の一元化**: `stats.rateWithCount` を TASK-0011 / 0016 / 0017 で共通利用し、NFR-201 の表記ゆれを防ぐ 🔵。
- **後続での追記前提**: 本タスクは初期セット。チャート/ページ実装（TASK-0011〜0017）で不足キーが出たら同 `stats.*` 名前空間へ追記する 🔵。
- **variant の出し分けは上位判定**: no-data / not-recorded の判定（確定0件 vs ラリー0件）はページ（TASK-0016）が `isEmpty` 等から行い props で渡す 🔵 *interfaces.ts StatsAggregate.isEmpty*。
