## タスク概要

ラリー履歴を Nuxt UI `UTable` で一覧表示する読み取り専用テーブル。列は **セット / ラリー番号・サーバー（選手名）・レシーバー（選手名）・結果（得点A/B・レット・未確定）・ショット数**。行クリックで `emit('select', rally)` を発火し、上位ページが埋め込みプレーヤーへシークさせる（REQ-007 / REQ-011）。

`video_start_timestamp_ms` が `null` の行は **非選択・非リンク**（ジャンプ不可, EDGE-103）。レット（`is_let`）・未確定（`is_point_confirmed=false` / `point_winner=null`）の行は結果列で視覚的に区別する。テーブルは全ライブラリー（レット・未確定含む）を表示し、絞り込みは上位 `useStatsFilter.apply`（per-match）/ サーバー側取得（group）で行われた結果の `RallyRow[]` を props で受け取る。

### 2. 列定義（UTable columns） 🔵
**信頼性**: 🔵 *REQ-006 / interfaces.ts RallyRow*

- セット/ラリー: `set_number` + `rally_number`（例 `S1-R12`）。
- サーバー / レシーバー: `playerName(server_player_id)` / `playerName(receiver_player_id)`（選手名で表示, A/B ラベルは使わない）🔵 *ヒアリング2026-06-09*。
- 結果: 後述ロジックで `得点A` / `得点B` / `レット` / `未確定` を判定（バッジ表示）。
- ショット数: `shot_count`。
- `showMatch` 時のみ `match_name` 列を先頭付近に追加（Group 横断）。

### 3. 結果列の判定（レット・未確定の区別） 🔵
**信頼性**: 🔵 *REQ-006 / interfaces.ts（is_let / is_point_confirmed / point_winner）*

```typescript
// 純関数として分離（REQ-407）
type RallyOutcome = 'pointA' | 'pointB' | 'let' | 'pending'
function rallyOutcome(r: RallyRow): RallyOutcome {
  if (r.is_let) return 'let'
  if (!r.is_point_confirmed || r.point_winner == null) return 'pending'
  return r.point_winner === 'A' ? 'pointA' : 'pointB'
}
```

- `let` / `pending` はバッジ色（neutral / warning 等）とラベルで視覚区別。文言は i18n（`stats.outcome.*`, TASK-0015）で解決 🔵 *error-handling 原則: 生文字列を埋めない*。

### 4. 行選択 + 非リンク行（EDGE-103） 🔵
**信頼性**: 🔵 *REQ-007 / REQ-011 / EDGE-103*

- 行クリックハンドラで `video_start_timestamp_ms == null` の行は `emit` しない。リンク/ホバー強調も無効化し、ジャンプ不可を視覚的に示す（dim / 「動画なし」表示）🔵。
- それ以外の行はクリック可（ホバー強調）で `emit('select', rally)`。

### 5. 全ライブラリー表示（絞り込みは上位） 🔵
**信頼性**: 🔵 *dataflow.md 機能1 ステップ4 / 機能2*

- 渡された `rallies` をそのまま描画する。クロスフィルタ済みかどうかはページ側（useStatsFilter.apply / サーバー側取得）の責務。本コンポーネントは絞り込まない 🔵。

## UI/UX要件
- **空状態**: `rallies` が空なら「該当ラリーなし」相当を表示（または上位 StatsEmptyState）。例外を投げない 🔵 *REQ-103*。
- **モバイル**: 横スクロール or カード型へ折り返す（NFR-202/203）。列が多い Group 横断（match_name 含む）でも破綻しない 🔵。
- **行ホバー**: 選択可能行はホバー強調、非リンク行（NULL）は強調・カーソルを無効化（操作可否を視覚化）🔵 *EDGE-103*。
- **結果の視覚区別**: 得点A/B・レット・未確定をバッジ色で区別（誤読防止）🔵。
- **アクセシビリティ**: 行は button/role 付与でキーボード選択可能に 🟡。

## 注意事項
- **読み取り専用**: テーブルは表示・選択 emit のみ。書き込みは一切行わない（REQ-401）🔵。
- **A/B ではなく選手名**: サーバー/レシーバーは選手名で表示。team A/B は内部判定（結果列の得点側）でのみ使う（ヒアリング2026-06-09）🔵。
- **NULL 行のジャンプ不可**: `video_start_timestamp_ms == null` は emit せず非リンク（EDGE-103）。`local` URL 失効は別途プレーヤー側で再選択（REQ-102 / TASK-0014）🔵。
- **絞り込みは上位**: クロスフィルタの適用はページ / useStatsFilter の責務。本コンポーネントは渡された行を描画する 🔵。
- **文言は i18n**: 結果ラベル（レット / 未確定）等は生文字列を埋めず `stats.*`（TASK-0015）で解決 🔵。
