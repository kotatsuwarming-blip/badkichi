## タスク概要

既存 video-playback の `VideoPlayer.client.vue` + `useVideoPlayer(source)` をラップした stats 用プレーヤーペイン。録画用 `VideoPane.vue` と同型で、**timeline スロットにラリー区切りマーカー**（shot マーカーの代わりにラリー開始 ms）を重ねる。親（ページ）が選択ラリーの `video_start_timestamp_ms` へジャンプできるよう `seekToMs` を `defineExpose` で公開する（REQ-007）。

Group 横断では別試合のラリー選択で動画ソースが変わるため、`source` が変わったら `VideoPlayer` を `:key` で再生成しプレーヤーを再 attach する（REQ-104）。`local` ソースで URL が失効している場合は VideoPlayer 内蔵の再選択 UI（`needsReselect`）に委ね、再選択を促す（REQ-102）。依存方向は stats-dashboard → video-playback の一方向で、video-playback にドメイン概念を持ち込まない（REQ-405 / ADR-002）。

## 実装詳細

### 1. props / expose 契約 🔵
**信頼性**: 🔵 *interfaces.ts StatsVideoPaneProps / REQ-007 / video-playback.ts*

**実装ファイル**: `app/components/stats/StatsVideoPane.vue`

```typescript
import { computed, ref, watch } from 'vue'
import type { VideoSource } from '~/types/video-playback'

const props = defineProps<{
  source: VideoSource
  rallyMarkersMs: number[]
}>()

const emit = defineEmits<{
  reselectFile: [file: File]   // VideoPlayer の reselect を中継（REQ-102）
  requestNewSource: []         // youtube load failed の中継
}>()

// source 変更で再生成するためのキー（REQ-104）
const sourceKey = computed(() => (props.source.type === 'youtube'
  ? `yt:${props.source.url}`
  : `local:${props.source.file.name}:${props.source.file.size}`))

// useVideoPlayer を source ごとに生成（:key 再マウントで再構築）
const player = ref(useVideoPlayer(props.source))

function seekToMs(ms: number): void {
  player.value.controls.seekToMs(ms)
}

defineExpose({ seekToMs })
```

> 注: `useVideoPlayer(source)` の再生成方法は既存 video-playback の利用パターンに合わせる。最も確実なのは `VideoPlayer` を `<template>` 側で `:key="sourceKey"` により再マウントし、それに合わせて player インスタンスも作り直す方式（VideoPlayer の onMounted で attach / onBeforeUnmount で detach が走る）🔵 *VideoPlayer.client.vue ライフサイクル*。

### 2. ラリー区切りマーカー（timeline スロット） 🔵
**信頼性**: 🔵 *REQ-007 / 既存 VideoPane.vue（shotMarkers）/ VideoPlayerSlotProps.durationMs*

- 既存 `VideoPane.vue` の `shotMarkers` と同じ要領で、`rallyMarkersMs` を `durationMs` で left%（`ms / durationMs`）に変換し timeline へ絶対配置 🔵。
- `durationMs` 未取得時はマーカーを描かない（`markerLeft` が null → 非表示）🔵 *VideoPane.vue 同型*。

```vue
<VideoPlayer
  :key="sourceKey"
  :player="player"
  @reselect-file="emit('reselectFile', $event)"
  @request-new-source="emit('requestNewSource')"
>
  <template #timeline="{ durationMs }">
    <span
      v-for="(ms, i) in rallyMarkersMs"
      :key="i"
      class="rally-marker"
      :style="markerLeft(ms, durationMs) ? { left: markerLeft(ms, durationMs) } : { display: 'none' }"
    />
  </template>
</VideoPlayer>
```

### 3. source 切替の再 attach（REQ-104） 🔵
**信頼性**: 🔵 *REQ-104 / dataflow.md 機能3 / VideoPlayer.client.vue onMounted attach*

- `source`（別試合のラリー再生）変更時は `:key="sourceKey"` で `VideoPlayer` を再マウントし、新ソースで再 attach される。`youtube` はソース切替、`local` は方式 A の再選択へ繋がる 🔵。
- 再生成時に古いプレーヤーは `onBeforeUnmount` で detach（iframe / objectURL 解放）される（VideoPlayer 既存実装）🔵。

### 4. local URL 失効時の再選択（REQ-102） 🔵
**信頼性**: 🔵 *REQ-102 / VideoPlayer.client.vue（needsReselect / reselectFile）*

- `local` で objectURL が失効している場合、VideoPlayer 内蔵の `needsReselect` UI が表示される。`reselectFile` イベントを上位へ中継し、上位が新 File で `source` を更新 → `:key` 再生成 → 再 attach する 🔵。
- 本コンポーネントは再選択 UI を自作しない（VideoPlayer に委譲, REQ-405 依存方向）🔵。

## 注意事項
- **依存方向（REQ-405 / ADR-002）**: stats-dashboard → video-playback の一方向。VideoPlayer / useVideoPlayer にラリー等のドメイン概念を持ち込まない。マーカーは汎用 timeline スロットへ ms 配列で渡すのみ 🔵。
- **再 attach の確実性（REQ-104）**: `:key` を source ごとにユニークにする（youtube=url、local=file 名+サイズ）。key が変わらないと別試合の動画に切り替わらない 🔵。
- **CSR 限定**: `VideoPlayer` は `.client.vue` で CSR 限定（ClientOnly 不要）。本ラッパも CSR 前提（REQ-404 / ADR-010）🔵。
- **objectURL リーク防止**: 再生成時の detach は VideoPlayer の `onBeforeUnmount` が担う。本コンポーネントで二重に解放しない 🔵。
- **既存 VideoPane.vue を雛形に**: shot マーカー → ラリーマーカーへ置換し、`shotMarkers` props を `rallyMarkersMs` に対応させる（同型）🔵。
