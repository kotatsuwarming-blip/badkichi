## タスク概要

試合単位の **集計 RPC** と **ラリー行取得** の Read composable を 2 本実装する。

- **`useMatchStats(matchId)`**: `useAsyncData` で `stats_player_rates` / `stats_pair_rates` / `stats_rally_length` を **`{ p_match_id }`** で並行取得し、utils（TASK-0005 の `toPlayerRate` / `toPairRate`、TASK-0006 の `RallyLengthRow` → `RallyLengthPoint`）で `StatsAggregate` を組む。`isEmpty`（確定ラリー 0 件）を判定（REQ-103）。選手名は `players` 取得でマスタ解決し `playerName` / `pairLabel` を埋める。戻り値は `UseStatsReturn`。
- **`useMatchRallies(matchId)`**: `stats_rallies` を **`{ p_match_id }`** で取得し `RallyRow[]` を返す（per-match クロスフィルタの元データ＝全件）。戻り値は `UseRalliesReturn`。

両者とも `useSupabaseClient<Database>()` + `client.rpc(...)` を使い、`useMatches.ts` の `useAsyncData` Read パターンを踏襲する。RLS は RPC の `SECURITY INVOKER`（`is_member_of(matches.group_id)` 経由）で担保。

## 実装詳細

### 1. useMatchStats composable 🔵
**信頼性**: 🔵 *api-endpoints.md §1-3 / interfaces.ts StatsAggregate / useMatches.ts Read パターン / REQ-003 / REQ-005 / REQ-103*

3 RPC を並行（`Promise.all`）取得。`players`（`id, name`）は別途取得して name マップを作り、`toPlayerRate(row, nameMap[id])` / `toPairRate(row, '田中 / 佐藤')` の name を解決。`isEmpty` は全 player/pair rate の母数合計が 0 かつ `rallyLength` が空のとき true。

**実装ファイル**: `app/composables/useMatchStats.ts`

```typescript
/**
 * 【機能概要】: 試合単位の集計 RPC（player/pair rates + rally_length）を StatsAggregate へ。
 * 【実装方針】: useMatches.ts 踏襲（useAsyncData 固定キー + camelCase）。集計は RPC（NFR-002）。
 *             選手名は players マスタで解決し playerName/pairLabel を埋める。isEmpty で空状態（REQ-103）。
 * 🔵 api-endpoints.md §1-3 / interfaces.ts StatsAggregate / REQ-003 / REQ-005 / REQ-103
 */
import type { Database } from '~/types/supabase'
import type {
  StatsAggregate, UseStatsReturn,
  PlayerRateRow, PairRateRow, RallyLengthRow, RallyLengthPoint
} from '~/types/stats-dashboard'
import { toPlayerRate, toPairRate } from '~/utils/stats-dashboard/compute-player-rate'

export function useMatchStats(matchId: string): UseStatsReturn {
  const client = useSupabaseClient<Database>()

  return useAsyncData<StatsAggregate>(`match-stats-${matchId}`, async () => {
    const arg = { p_match_id: matchId }
    const [playerRes, pairRes, lengthRes, playersRes] = await Promise.all([
      client.rpc('stats_player_rates', arg),
      client.rpc('stats_pair_rates', arg),
      client.rpc('stats_rally_length', arg),
      client.from('players').select('id, name')
    ])
    if (playerRes.error) throw playerRes.error
    if (pairRes.error) throw pairRes.error
    if (lengthRes.error) throw lengthRes.error
    if (playersRes.error) throw playersRes.error

    // 【名前解決】: players マスタ → id→name マップ
    const nameMap = new Map((playersRes.data ?? []).map(p => [p.id, p.name]))
    const playerRows = (playerRes.data ?? []) as PlayerRateRow[]
    const pairRows = (pairRes.data ?? []) as PairRateRow[]
    const lengthRows = (lengthRes.data ?? []) as RallyLengthRow[]

    const playerRates = playerRows.map(r => toPlayerRate(r, nameMap.get(r.player_id) ?? ''))
    const pairRates = pairRows.map(r =>
      toPairRate(r, `${nameMap.get(r.player1_id) ?? ''} / ${nameMap.get(r.player2_id) ?? ''}`)
    )
    const rallyLength: RallyLengthPoint[] = lengthRows.map(r => ({
      shotCount: r.shot_count,
      rallies: r.rallies,
      serveWinRate: r.rallies > 0 ? r.serve_won / r.rallies : null
    }))

    // 【空状態判定】: 確定ラリー 0 件 = 全 rate 母数 0 かつ rallyLength 空（REQ-103）
    const totalDenom = playerRates.reduce((s, p) => s + p.serve.denominator + p.receive.denominator, 0)
    const isEmpty = totalDenom === 0 && rallyLength.length === 0

    return { playerRates, pairRates, rallyLength, isEmpty }
  }) as unknown as UseStatsReturn
}
```

### 2. useMatchRallies composable 🔵
**信頼性**: 🔵 *api-endpoints.md §4 / interfaces.ts RallyRow / UseRalliesReturn / REQ-006*

`stats_rallies({ p_match_id })` で全ラリー行（レット・未確定含む）を取得。per-match のクロスフィルタはこの行に対しクライアント側で `filterRallies`（TASK-0007）を適用する（往復なし）。

**実装ファイル**: `app/composables/useMatchRallies.ts`

```typescript
/**
 * 【機能概要】: 試合単位のラリー行（stats_rallies）を RallyRow[] で取得（per-match クロスフィルタの元）。
 * 【実装方針】: useAsyncData + client.rpc。全ラリー（レット・未確定含む）。絞り込みはクライアント側。
 * 🔵 api-endpoints.md §4 / interfaces.ts RallyRow / UseRalliesReturn / REQ-006
 */
import type { Database } from '~/types/supabase'
import type { RallyRow, UseRalliesReturn } from '~/types/stats-dashboard'

export function useMatchRallies(matchId: string): UseRalliesReturn {
  const client = useSupabaseClient<Database>()

  return useAsyncData<RallyRow[]>(`match-rallies-${matchId}`, async () => {
    const { data, error } = await client.rpc('stats_rallies', { p_match_id: matchId })
    if (error) throw error
    return (data ?? []) as RallyRow[]
  }) as unknown as UseRalliesReturn
}
```

## 注意事項
- **composable test の auto-import mock パターン**: `tests/unit/composables/useMatches.test.ts` を参照。`vi.hoisted()` でモックを定義し `#imports` / `#supabase-client` / `#async-data` を差し替え、`useAsyncData` mock は `handler` を即時実行して AsyncState 互換（`data`/`pending`/`error`/`refresh`）を返す。本タスクでは `client.from` に加え `client.rpc` のモックが必要（[[project_match_management_tasks]] / [[project_match_recording_spec]]）。
- 集計（レット・未確定の除外、カウント）は RPC（SQL 側）の責務（REQ-101 / NFR-002）。composable は RPC 結果の整形・名前解決・isEmpty 判定に限定し、集計ロジックを二重実装しない。
- `playerName` / `pairLabel` は `players` マスタ（PostgREST `from('players')`）で解決（api-endpoints.md §PostgREST 補助）。集計 RPC は名前を返さない（id のみ）。
- RPC シグネチャは `app/types/supabase.ts`（gen-types CI で migration から自動再生成、[[project_gen_types_automation]]）に反映される。型キャスト（`as unknown as`）は型再生成までの暫定で、再生成後は除去を検討。
- 3 RPC は `Promise.all` で並行取得（NFR-001：3 秒以内の初期表示）。
