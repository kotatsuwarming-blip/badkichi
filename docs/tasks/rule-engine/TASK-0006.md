## タスク概要

サーバーのコート上の立ち位置（左/右）を決定する内部関数 `resolveServerPosition` を実装する。バドミントンダブルスのルールに基づき、サーブ権を持つチームのスコアの偶奇でサーバーの位置を決定する:

- スコアが偶数（0, 2, 4...）→ 右コート（right）
- スコアが奇数（1, 3, 5...）→ 左コート（left）

**配置先**: `app/utils/rule-engine/internal/resolve-server-position.ts`

## 実装詳細

### 関数シグネチャ

```typescript
import type { CourtSide } from '../types'

/**
 * サーブ権を持つチームのスコアに基づいて、サーバーのコート位置を決定する。
 *
 * @param servingTeamScore - サーブ権を持つチームの現在のスコア
 * @returns サーバーのコート位置（'left' | 'right'）
 */
export function resolveServerPosition(servingTeamScore: number): CourtSide
```

### ロジック

1. `servingTeamScore % 2 === 0` → `'right'` を返す
2. `servingTeamScore % 2 !== 0` → `'left'` を返す

### 関連要件
- REQ-003: サーバーポジションの決定ルール（偶数=右コート、奇数=左コート）
