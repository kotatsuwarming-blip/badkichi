## タスク概要

PositionOverride（選手の左右入れ替え）を適用する内部関数 `applyOverrides` を実装する。各ラリーにおいて、オーバーライドがある場合にチームの選手の左右ポジションをトグル（反転）する:

- 各オーバーライドは指定チームの左右選手を入れ替える（トグル）
- 同じチームへの2回のトグルは元に戻る
- 異なるチームへのオーバーライドは独立に処理される
- オーバーライドは `rallyNumber` 以降のラリーに適用される

**配置先**: `app/utils/rule-engine/internal/apply-overrides.ts`

## 実装詳細

### 関数シグネチャ

```typescript
import type { PositionOverride, TeamPositions, SetPlayerPosition } from '../types'

/**
 * 指定されたラリー番号までのオーバーライドを適用し、チームポジションを返す。
 *
 * @param initialPositions - セット開始時の選手立ち位置
 * @param overrides - 全オーバーライドの配列
 * @param currentRallyNumber - 現在のラリー番号
 * @returns オーバーライド適用後のチームポジション
 */
export function applyOverrides(
  initialPositions: SetPlayerPosition[],
  overrides: PositionOverride[],
  currentRallyNumber: number
): TeamPositions
```

### ロジック

1. `initialPositions` からチームA・チームBの初期ポジションを構築する
2. `overrides` の中から `rallyNumber <= currentRallyNumber` のものをフィルタリング
3. 各チームごとに該当するオーバーライドの回数をカウント
4. 回数が奇数のチームは左右を入れ替え、偶数のチームはそのまま
5. 結果の `TeamPositions` を返す

## 注意事項

- 本関数は `internal/` ディレクトリに配置し、公開APIからは直接エクスポートしない
- rule-engine は Nuxt/Vue に依存しない純 TypeScript モジュールである（REQ-402）
- `initialPositions` はダブルスの場合4人分（チームA 2人 + チームB 2人）が入る
- オーバーライドは「swapped/restored」の区別はなく、毎回トグルとして扱う（interfaces.ts コメント参照）
- `rallyNumber` がちょうど `currentRallyNumber` と一致するオーバーライドも適用対象に含める
