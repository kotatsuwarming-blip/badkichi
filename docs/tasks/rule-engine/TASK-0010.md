## 注意事項

- rule-engine は Nuxt/Vue に依存しない純 TypeScript モジュールである（REQ-402）
- `internal/` ディレクトリの関数は index.ts からは re-export しない（公開APIではない）
- パフォーマンステストは環境依存があるため、閾値に余裕を持たせること（例: 10ms ではなく 50ms で設定し、通常は 10ms 未満であることをログ出力）
- 統合テストでは実際のバドミントンの試合データに近いシナリオを使用し、現実的なテストとする
- セット遷移のテストでは、`computeRallyStates` → `determineSetWinner` → 新しい `SetConfig` → `computeNextServer` というフローを一連で確認する
