## 関数仕様

```typescript
export function applyRally(state: GameState, rally: RallyResult): GameState
```

### ロジック

```
1. レット判定
   isLet が true → state をそのまま返す

2. スコア更新
   pointWinner のチームに +1

3. サーブ権の決定
   得点したチームが次のサーブ権を持つ（REQ-002）

4. 位置の更新
   サーブ側が得点した場合（REQ-010）:
     → サーブ側の2人が左右入れ替わり
     → レシーブ側はそのまま
   レシーブ側が得点した場合（REQ-011）:
     → どちらのチームも入れ替わらない

5. サーバー / レシーバーの特定
   新サーブチームのスコア: 偶数=右、奇数=左の選手がサーバー（REQ-003）
   レシーバーは相手チームの対角の選手
```

## 注意事項

- この関数は純関数。受け取った state を変更せず、新しいオブジェクトを返す
- レシーブ側が得点しても、どちらのチームも左右は入れ替わらない（BWF公式ルール）
- サーバーの位置はサーブ側のスコアの偶奇で決まる（REQ-003）
