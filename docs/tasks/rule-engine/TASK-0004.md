## 実装詳細

### 関数仕様

```typescript
/**
 * 試合の勝者を判定する（3セットマッチ、先に2セット取ったチームが勝利）
 *
 * @param setResults - 各セットの結果の配列
 * @returns 勝者のチーム。まだ決着がついていない場合は null
 */
export function determineMatchWinner(setResults: SetResult[]): Team | null
```

### ロジック

1. setResults 配列をループし、各チームの勝利数をカウント
2. いずれかのチームの勝利数が 2 以上であれば、そのチームを勝者として返す
3. どちらも 2 勝に達していなければ `null` を返す

```
winsA = setResults で winner === 'A' の数
winsB = setResults で winner === 'B' の数

if (winsA >= 2) return 'A'
if (winsB >= 2) return 'B'
return null
```

- **本タスク全体が 🟡 黄信号である**。REQ-008 の「3セットマッチで先に2セット取ったチームが勝利」というルールは、PRD の `set_target_points: [21, 21, 15]` から推測されたものである。実装前にユーザへの確認を推奨する
