## 関数仕様

```typescript
export function createInitialState(
  config: SetConfig,
  initialPositions: SetPlayerPosition[]
): GameState
```

### ロジック

1. スコアを `{ teamA: 0, teamB: 0 }` で初期化
2. `config.firstServingTeam` からサーブ権チームを決定
3. サーブチームのスコアが 0（偶数）→ 右コートの選手がサーバー
4. レシーバーは相手チームの対角（右コートからサーブ → レシーバーは左コート）
5. 初期位置から TeamPositions を構築
