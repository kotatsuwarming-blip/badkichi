## 実装詳細

### 関数仕様

```typescript
/**
 * セットの勝者を判定する
 *
 * @param score - 現在のスコア
 * @param config - セットの設定（targetPoints, enableDeuce, deucePointCap）
 * @returns 勝者のチーム。まだ決着がついていない場合は null
 */
export function determineSetWinner(score: Score, config: SetConfig): Team | null

/**
 * セットが終了しているか判定する
 * determineSetWinner に委譲する
 *
 * @param score - 現在のスコア
 * @param config - セットの設定
 * @returns セットが終了していれば true
 */
export function isSetComplete(score: Score, config: SetConfig): boolean
```

### ロジック: デュース有効時（enableDeuce: true）

1. どちらかのスコアが `targetPoints` 以上であること
2. 2点差以上がついていること（`Math.abs(scoreA - scoreB) >= 2`）
3. **例外**: スコアの上限は `deucePointCap`（例: 30, 24, 20 など自由に設定可能）
4. キャップに達したスコアを持つチームが勝者（差が1点でも勝ち）

具体的な判定フロー:
```
cap = config.deucePointCap  // 例: 30, 24, 20 など

// キャップによるサドンデス勝利
if (scoreA === cap) return 'A'
if (scoreB === cap) return 'B'

// 通常勝利（targetPoints 以上 & 2点差以上）
if (scoreA >= targetPoints && scoreA - scoreB >= 2) return 'A'
if (scoreB >= targetPoints && scoreB - scoreA >= 2) return 'B'

// まだ決着がついていない
return null
```

### ロジック: デュース無効時（enableDeuce: false）

1. 先に `targetPoints` に到達したチームが勝者
2. 延長戦なし（1点差でも勝ち）

```
if (scoreA >= targetPoints) return 'A'
if (scoreB >= targetPoints) return 'B'
return null
```

### isSetComplete のロジック

```typescript
export function isSetComplete(score: Score, config: SetConfig): boolean {
  return determineSetWinner(score, config) !== null
}
```

## 注意事項

- キャップ値は `config.deucePointCap` で直接指定される（計算式ではない）。BWF 標準では targetPoints=21 → cap=30、targetPoints=15 → cap=24 だが、ユーザーが自由に設定可能
- `isSetComplete` は `determineSetWinner` に完全に委譲する。ロジックの重複を避けること
- config の `firstServingTeam` は本タスクでは使用しない（勝者判定にはスコアとデュースルールのみ必要）
- この関数は純関数であり、副作用を持たない（REQ-004）
