## 実装詳細

### 定義する型一覧（全13型）

`docs/design/rule-engine/interfaces.ts` から以下の型を移植する。フィールド名は TypeScript 規約に従い camelCase を使用する。

#### 基本型（4型）
| 型名 | 種別 | 信頼性 | 説明 |
|------|------|--------|------|
| `Team` | type alias | 🔵 | `'A' \| 'B'` チーム識別子 |
| `CourtSide` | type alias | 🔵 | `'left' \| 'right'` コート上の左右位置 |
| `PlayerId` | type alias | 🔵 | `string` 選手ID |
| `DeuceRule` | type alias | 🔵 | `'cap30' \| 'no_deuce'` デュースルール |

#### 入力型（4型）
| 型名 | 種別 | 信頼性 | 説明 |
|------|------|--------|------|
| `SetConfig` | interface | 🔵 | セットの設定（targetPoints, deuceRule, firstServingTeam） |
| `SetPlayerPosition` | interface | 🔵 | セット開始時の選手立ち位置 |
| `Rally` | interface | 🔵 | ラリー情報（rallyNumber, pointWinner, isLet） |
| `PositionOverride` | interface | 🔵 | 左右入れ替わりの記録（rallyNumber, team） |

#### 出力型（5型）
| 型名 | 種別 | 信頼性 | 説明 |
|------|------|--------|------|
| `RallyState` | interface | 🔵 | 各ラリーの計算結果 |
| `NextServerInfo` | interface | 🟡 | 次のサーバー情報 |
| `Score` | interface | 🔵 | スコア（teamA, teamB） |
| `TeamPositions` | interface | 🔵 | チームのポジション（左右の選手配置） |
| `SetResult` | interface | 🟡 | セット結果（winner） |

### 関連要件
- REQ-001〜009: サーバー推論・スコア計算・勝敗判定の全機能で使用
- REQ-101〜105: デュースルール・PositionOverride で使用
- REQ-401〜403: 制約要件（外部依存なし）

### 注意点
