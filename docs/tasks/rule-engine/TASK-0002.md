## 実装詳細

### 関数仕様

```typescript
/**
 * 現在のスコアを計算する
 * レット（isLet: true）はスコアに加算しない
 *
 * @param rallies - ラリー結果の配列
 * @returns 各チームのスコア
 */
export function computeScore(rallies: Rally[]): Score
```

### ロジック
1. ラリー配列をループし、`isLet` が `true` のラリーをスキップ
2. `pointWinner` が `'A'` の場合は teamA のスコアを +1
3. `pointWinner` が `'B'` の場合は teamB のスコアを +1
4. 結果を `{ teamA: number, teamB: number }` で返す

### 関連要件
- **REQ-005**: ラリー結果の配列からセットの現在スコアを計算する 🔵
- **REQ-006**: レットのラリーをスコアに加算しない 🔵

### テスト詳細

#### TC-006-01: レット1回
```typescript
const rallies = [
  { rallyNumber: 1, pointWinner: 'A', isLet: false },
  { rallyNumber: 2, pointWinner: null, isLet: true },
  { rallyNumber: 3, pointWinner: 'B', isLet: false },
]
expect(computeScore(rallies)).toEqual({ teamA: 1, teamB: 1 })
```

#### TC-006-02: レット連続（3回連続）
```typescript
const rallies = [
  { rallyNumber: 1, pointWinner: null, isLet: true },
  { rallyNumber: 2, pointWinner: null, isLet: true },
  { rallyNumber: 3, pointWinner: null, isLet: true },
]
expect(computeScore(rallies)).toEqual({ teamA: 0, teamB: 0 })
```

#### TC-006-03: レットと得点の交互
```typescript
const rallies = [
  { rallyNumber: 1, pointWinner: 'A', isLet: false },
  { rallyNumber: 2, pointWinner: null, isLet: true },
  { rallyNumber: 3, pointWinner: 'B', isLet: false },
  { rallyNumber: 4, pointWinner: null, isLet: true },
  { rallyNumber: 5, pointWinner: 'A', isLet: false },
]
expect(computeScore(rallies)).toEqual({ teamA: 2, teamB: 1 })
```

#### 追加-01: 空のラリー配列
```typescript
expect(computeScore([])).toEqual({ teamA: 0, teamB: 0 })
```

#### 追加-02: 全得点が片方のチーム
```typescript
const rallies = Array.from({ length: 5 }, (_, i) => ({
  rallyNumber: i + 1,
  pointWinner: 'A' as const,
  isLet: false,
}))
expect(computeScore(rallies)).toEqual({ teamA: 5, teamB: 0 })
```

## 注意事項

- `Rally` 型の `pointWinner` はレット時に `null` となる。`isLet: true` と `pointWinner: null` は常にセットで来る前提だが、防御的にコーディングすること
- この関数は純関数であり、副作用を持たない（REQ-004）
- architecture.md によると、computeRallyStates と computeNextServer がこの関数を内部で呼び出す
