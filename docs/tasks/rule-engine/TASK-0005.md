## 関数仕様

```typescript
export function applyOverride(state: GameState, team: Team): GameState
```

### ロジック

```
1. 指定チームの左右の選手を入れ替え
   { left: '田中', right: '鈴木' } → { left: '鈴木', right: '田中' }

2. サーバー/レシーバーを再特定
   サーブチームのスコア偶奇で決まる位置の選手がサーバー
   （Override でサーブチームの位置が変わった場合、サーバーも変わる）

3. 相手チームの位置はそのまま
```

## 注意事項

- Override はスコアやサーブ権には影響しない。位置のみ変更
- トグル方式: swapped / restored の区別なし（REQ-105）
- サーブチームを Override した場合、サーバーが変わる可能性がある（位置から決まるため）
