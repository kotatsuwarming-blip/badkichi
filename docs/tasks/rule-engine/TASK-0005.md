## タスク概要

サーブ権を持つチームを決定する内部関数 `resolveServingTeam` を実装する。各ラリーにおいて、どちらのチームがサーブ権を持つかを以下のルールに基づいて決定する:

- セット最初のラリー: `config.firstServingTeam` を使用
- レット（`isLet: true`）の後: サーブ権は変わらない（同じチームが継続）
- 得点の後: 得点したチーム（`pointWinner`）がサーブ権を取得

**配置先**: `app/utils/rule-engine/internal/resolve-serving-team.ts`

## 実装詳細

### 関数シグネチャ

```typescript
import type { Team, Rally, SetConfig } from '../types'

/**
 * 指定されたラリーにおいて、どちらのチームがサーブ権を持つかを決定する。
 *
 * @param config - セットの設定（firstServingTeam を参照）
 * @param rallies - 現在のラリーより前の全ラリー結果
 * @returns サーブ権を持つチーム
 */
export function resolveServingTeam(
  config: SetConfig,
  previousRallies: Rally[]
): Team
```

### ロジック

1. `previousRallies` が空の場合: `config.firstServingTeam` を返す
2. 直前のラリーが `isLet: true` の場合: さらに前のラリーまで遡って最後に得点が入ったラリーの `pointWinner` を返す（すべてレットの場合は `firstServingTeam`）
3. 直前のラリーの `pointWinner` がある場合: そのチームを返す

### 関連要件
- REQ-002: サーブ権の決定ルール
- REQ-006: レット時の処理（サーブ権は変わらない）
