## タスク概要

match-management ユニットの **型契約と入力バリデーションの基盤**を作る。すべての composable
（TASK-0003〜0006）と page/component（Phase 2）が共有するドメイン型 `app/types/match.ts` と、
試合フォームの Zod スキーマ `app/schemas/match-form.ts` を、`interfaces.ts §1 / §4` の契約および
DB の各制約（`matches_name_length_check` / 4 player NOT NULL / `matches_players_distinct_check`）と
**1:1 で一致**させて定義する。

`app/types/match.ts`: `VideoSourceType` / `MatchPlayerRef` / `MatchListItem` /
`CreateMatchInput` / `UpdateMatchInput`。`matches` / `players` の Row 型は TASK-0001 で再生成した
`~/types/supabase` を参照する（生成型を真とする）。

`app/schemas/match-form.ts`: 試合名（任意 trim 1〜50、空→null）/ 試合日付（必須 YYYY-MM-DD）/
`video_source_type`（enum）/ `video_source_url`（type 別検証・youtube は ID 抽出）/ 4 選手相異
（superRefine）。新規 API・新規エラーコードは作らない（player-management 同方針、メッセージは locale キー）。

### 1. ドメイン型 `app/types/match.ts` 🔵

**実装ファイル**: `app/types/match.ts`

```typescript
import type { Database } from '~/types/supabase'

/** 動画ソース種別。matches.video_source_type CHECK と 1:1。
 *  🔵 video_source_type CHECK IN ('youtube','local')。REQ-302: 将来拡張余地あり。 */
export type VideoSourceType = 'youtube' | 'local'

/** 一覧の 1 行で名前解決済みの選手参照 (PostgREST 埋め込み、EDGE-007)。🔵 */
export interface MatchPlayerRef {
  id: Database['public']['Tables']['players']['Row']['id']
  name: Database['public']['Tables']['players']['Row']['name']
}

/** 一覧・表示が使う matches の射影 (選手名解決済み)。
 *  🔵 REQ-001 / NFR-203。name 任意 (null→UI は対戦カード表示)。 */
export interface MatchListItem {
  id: Database['public']['Tables']['matches']['Row']['id']
  name: string | null
  matchDate: string // 🔵 REQ-008 'YYYY-MM-DD'
  teamA: [MatchPlayerRef, MatchPlayerRef]
  teamB: [MatchPlayerRef, MatchPlayerRef]
  videoSourceType: VideoSourceType
  videoSourceUrl: string // 🔵 NOT NULL: local=ファイル名ラベル / youtube=抽出後URL
}

/** 作成入力。group_id は composable が useCurrentGroup から付与。🔵 REQ-002 系。 */
export interface CreateMatchInput {
  name?: string | null
  matchDate: string
  teamAPlayer1Id: MatchPlayerRef['id']
  teamAPlayer2Id: MatchPlayerRef['id']
  teamBPlayer1Id: MatchPlayerRef['id']
  teamBPlayer2Id: MatchPlayerRef['id']
  videoSourceType: VideoSourceType
  videoSourceUrl: string
}

/** 編集入力。🔵 REQ-003 全項目編集可。形状は Create と同一。 */
export type UpdateMatchInput = CreateMatchInput
```

### 2. Zod スキーマ `app/schemas/match-form.ts` 🔵
**信頼性**: 🔵 *interfaces.ts §4 / matches CHECK 制約 / player-name.ts パターン / REQ-101・106・107・108・109*

`player-name.ts` と同方針（メッセージは locale キー、表示は呼び出し側で `t()`）。各検証は DB CHECK と一致：
- **試合名** `name`: `z.string().trim().min(1).max(50)` を任意化（空文字 / undefined → null）。
  `matches_name_length_check`（IS NULL OR 1〜50 字）と一致（REQ-108 / EDGE-011）。
- **試合日付** `matchDate`: 必須。`YYYY-MM-DD` 形式（REQ-008 / REQ-109 / EDGE-012）。
- **video_source_type**: `z.enum(['youtube','local'])`。
- **video_source_url**: superRefine で type 別検証。`local` は非空（REQ-106）。`youtube` は
  youtube.com / youtu.be URL または 11 桁動画 ID で検証し ID を抽出（REQ-107 / EDGE-004）。
- **4 選手相異**: superRefine で 4 player が全員別人かを送信前に検証（REQ-101 / EDGE-001、
  `matches_players_distinct_check` と一致）。

**実装ファイル**: `app/schemas/match-form.ts`

```typescript
import { z } from 'zod'

// youtube URL/ID → 動画ID抽出 (youtube.com / youtu.be / shorts / embed / 11桁ID)。EDGE-004。
const YT = /(?:youtube\.com\/(?:watch\?v=|embed\/|shorts\/)|youtu\.be\/)([A-Za-z0-9_-]{11})|^([A-Za-z0-9_-]{11})$/

// 試合名: 任意。trim 後 1〜50字、空は null へ。DB matches_name_length_check と一致 (REQ-108/EDGE-011)。
const matchName = z
  .string()
  .trim()
  .max(50, { message: 'invalid_match_name' })
  .nullish()
  .transform(v => (v == null || v === '' ? null : v))

// 試合日付: 必須。YYYY-MM-DD (REQ-008/109/EDGE-012)。
const matchDate = z
  .string()
  .regex(/^\d{4}-\d{2}-\d{2}$/, { message: 'invalid_match_date' })

export const matchFormSchema = z
  .object({
    name: matchName,
    matchDate,
    teamAPlayer1Id: z.string().uuid({ message: 'player_required' }),
    teamAPlayer2Id: z.string().uuid({ message: 'player_required' }),
    teamBPlayer1Id: z.string().uuid({ message: 'player_required' }),
    teamBPlayer2Id: z.string().uuid({ message: 'player_required' }),
    videoSourceType: z.enum(['youtube', 'local'], { message: 'invalid_video_source_type' }),
    videoSourceUrl: z.string().min(1, { message: 'video_source_required' })
  })
  .superRefine((v, ctx) => {
    // 4選手相異 (REQ-101 / EDGE-001)。matches_players_distinct_check と一致。
    const ids = [v.teamAPlayer1Id, v.teamAPlayer2Id, v.teamBPlayer1Id, v.teamBPlayer2Id]
    if (new Set(ids).size !== 4) {
      ctx.addIssue({ code: 'custom', message: 'players_must_be_distinct' })
    }
    // youtube は形式検証 + ID 抽出 (REQ-107 / EDGE-004)、local は非空のみ (REQ-106)。
    if (v.videoSourceType === 'youtube' && !YT.test(v.videoSourceUrl)) {
      ctx.addIssue({ code: 'custom', path: ['videoSourceUrl'], message: 'invalid_youtube_url' })
    }
  })

/** youtube URL/ID から 11桁動画 ID を抽出。非該当は null。EDGE-004。 */
export function extractYoutubeId(input: string): string | null {
  const m = YT.exec(input)
  return m ? (m[1] ?? m[2] ?? null) : null
}

export type MatchFormValues = z.infer<typeof matchFormSchema>
```

> 注: 動画 ID 抽出（`extractYoutubeId`）は composable / フォームが保存値を組み立てる際に使う。
> youtube の `videoSourceUrl` 保存値は「抽出後の動画 ID（または ID を含む正規化 URL）」とする
> （interfaces.ts §4 / REQ-107）。最終形（生 ID か URL か）は実装時に 1 つに固定し本ファイルに記録する。

> テスト方針: 最小境界値 + 分岐網羅のみ（冗長ケース禁止、ADR-012 / memory feedback_test_coverage）。

### テストケース1: 試合名 空入力 → null（任意、下限） 🔵
**信頼性**: 🔵 *REQ-108 / EDGE-011（未入力許容）*
**Given**: `name: ''`（他項目は valid） / **When**: `matchFormSchema.safeParse(...)` / **Then**: `success === true`、`data.name === null`

### テストケース2: 試合名 trim 後 50 字 OK / 51 字 NG（境界） 🔵
**信頼性**: 🔵 *REQ-108 / EDGE-011 / matches_name_length_check*

### テストケース4: youtube URL OK ＋ ID 抽出 🔵

**Given**: `videoSourceType: 'youtube'`, `videoSourceUrl: 'https://youtu.be/abcdefghijk'` /
**When**: safeParse + `extractYoutubeId` / **Then**: `success === true`、`extractYoutubeId(...) === 'abcdefghijk'`

### テストケース5: youtube 形式不正は拒否 🔵
**信頼性**: 🔵 *EDGE-004*
**Given**: `videoSourceType: 'youtube'`, `videoSourceUrl: 'not-a-url'` / **When**: safeParse / **Then**: `success === false`、`videoSourceUrl` パスに message `'invalid_youtube_url'`

### テストケース6: local は非空でOK（type 別分岐） 🔵
**信頼性**: 🔵 *REQ-106 / EDGE-003*
**Given**: `videoSourceType: 'local'`, `videoSourceUrl: 'match1.mp4'` / **When**: safeParse / **Then**: `success === true`（local は youtube 正規表現を適用しない）

### テストケース7: 4 選手に重複あり → 拒否 🔵
**信頼性**: 🔵 *REQ-101 / EDGE-001 / matches_players_distinct_check*
**Given**: 4 選手のうち 2 つが同一 UUID / **When**: safeParse / **Then**: `success === false`、message `'players_must_be_distinct'`

```typescript
import { describe, it, expect } from 'vitest'
import { matchFormSchema, extractYoutubeId } from '~/schemas/match-form'

const P1 = '11111111-1111-1111-1111-111111111111'
const P2 = '22222222-2222-2222-2222-222222222222'
const P3 = '33333333-3333-3333-3333-333333333333'
const P4 = '44444444-4444-4444-4444-444444444444'

const base = {
  name: 'XX練習会',
  matchDate: '2026-06-05',
  teamAPlayer1Id: P1, teamAPlayer2Id: P2,
  teamBPlayer1Id: P3, teamBPlayer2Id: P4,
  videoSourceType: 'local' as const,
  videoSourceUrl: 'match1.mp4'
}

describe('matchFormSchema', () => {
  it('TC1: 試合名 空 → null (任意)', () => {
    const r = matchFormSchema.safeParse({ ...base, name: '' })
    expect(r.success).toBe(true)
    if (r.success) expect(r.data.name).toBeNull()
  })

  it('TC2: 試合名 50字OK / 51字NG (境界)', () => {
    expect(matchFormSchema.safeParse({ ...base, name: 'a'.repeat(50) }).success).toBe(true)
    const ng = matchFormSchema.safeParse({ ...base, name: 'a'.repeat(51) })
    expect(ng.success).toBe(false)
    if (!ng.success) expect(ng.error.issues[0]?.message).toBe('invalid_match_name')
  })

  it('TC3: 試合日付 未入力/形式不正は拒否 (必須)', () => {
    expect(matchFormSchema.safeParse({ ...base, matchDate: '' }).success).toBe(false)
    expect(matchFormSchema.safeParse({ ...base, matchDate: '2026/06/05' }).success).toBe(false)
  })

  it('TC4: youtube URL OK + ID 抽出', () => {
    const v = { ...base, videoSourceType: 'youtube' as const, videoSourceUrl: 'https://youtu.be/abcdefghijk' }
    expect(matchFormSchema.safeParse(v).success).toBe(true)
    expect(extractYoutubeId(v.videoSourceUrl)).toBe('abcdefghijk')
  })

  it('TC5: youtube 形式不正は拒否', () => {
    const r = matchFormSchema.safeParse({ ...base, videoSourceType: 'youtube', videoSourceUrl: 'not-a-url' })
    expect(r.success).toBe(false)
    if (!r.success) expect(r.error.issues.some(i => i.message === 'invalid_youtube_url')).toBe(true)
  })

  it('TC6: local 非空でOK (type 別分岐)', () => {
    expect(matchFormSchema.safeParse({ ...base, videoSourceType: 'local', videoSourceUrl: 'match1.mp4' }).success).toBe(true)
  })

  it('TC7: 4選手に重複ありは拒否', () => {
    const r = matchFormSchema.safeParse({ ...base, teamBPlayer2Id: P1 })
    expect(r.success).toBe(false)
    if (!r.success) expect(r.error.issues.some(i => i.message === 'players_must_be_distinct')).toBe(true)
  })
})
```

## 注意事項
- `MatchListItem.id` / `MatchPlayerRef.id` 等は **生成型を真**とし、ハードコードの `string` を書かない
  （`Database['public']['Tables'][...]['Row']` を参照）。`name`（任意・null 化後）/ `matchDate`（YYYY-MM-DD 文字列）
  のようなドメイン射影フィールドのみ明示型で表現する。
- Zod の `message` は文言そのものではなく **locale キー**（表示は呼び出し側で `t()`、player-name.ts 同方針）。
- DB CHECK は trim 後の `char_length` を見るため、`name` の Zod も `.trim()` を `max` の前に置く。
- youtube の保存値（生 ID か正規化 URL か）を 1 つに固定し、`extractYoutubeId` の戻りと整合させて本ファイルに記録する。
- `videoSourceType` 別の `videoSourceUrl` 検証は superRefine（type に依存する条件分岐）で行い、`local` に youtube 正規表現を適用しない。
