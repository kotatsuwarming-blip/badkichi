## タスク概要

試合の**追加 / 編集を一覧画面上で行う `<UModal>` フォーム**コンポーネント
`app/components/matches/MatchFormModal.vue` を実装する。専用ページは作らず、一覧（TASK-0009）から
モーダルを開いて操作する（ヒアリング2026-06-05 / NFR-201）。player-management の `PlayerFormModal`
パターンを踏襲し、`mode`（`'create' | 'edit'`）prop で挙動を分岐、`edit` 時は対象 `match` を prop で
受けてフォームをプリフィルする。

フォーム項目（architecture.md §UI）:
- **試合名**（任意 / `<UInput>`、空は null 化、REQ-007）
- **試合日付**（既定＝本日 / `<UInput type="date">` 等、REQ-008 / REQ-109、EDGE-012）
- **4 選手**（`<USelectMenu>` × 4、選択肢は `usePlayers`（TASK-0002）未削除ロスター。**各枠は他枠で
  選択済の player を選択肢から除外**＝NFR-202 / EDGE-001、REQ-006）
- **動画ソース**（`<URadioGroup>` `youtube | local` + 条件付きフィールド。`local` はファイル選択で
  `file.name` を取得して `videoSourceUrl` にセット（REQ-106）、`youtube` は URL テキスト入力（REQ-107））

検証は `matchFormSchema`（TASK-0004 `match-form.ts`、Zod v4）で行い、エラーは `<UFormField>` の inline
に表示する（EDGE-009）。保存は `mode` に応じて `useCreateMatch`（TASK-0005）/ `useUpdateMatch`

`useToastErrors`（TASK-0007 文言経路）で toast 表示する（EDGE-010）。`pending` 中はボタンを
`loading` / `disabled` にして二重送信を防止する。全文言は i18n 経由（NFR-301）。

新規 DB スキーマ・API・エラーコードは作らない。

## 実装詳細

### 1. props / emits 契約 🔵
**信頼性**: 🔵 *architecture.md §UI / dataflow.md 機能2・機能3 / interfaces.ts §1 入力型*

`mode` で create / edit を分岐。`edit` 時のみ `match`（`MatchListItem` 相当）を受けプリフィルする。
親（TASK-0009）が `v-model:open` でモーダル開閉を制御し、`saved` を受けて閉じ + refresh する。

**実装ファイル**: `app/components/matches/MatchFormModal.vue`

```vue
<script setup lang="ts">
import { matchFormSchema } from '~/schemas/match-form'
import type { MatchListItem, CreateMatchInput, UpdateMatchInput, VideoSourceType } from '~/types/match'

const props = defineProps<{
  mode: 'create' | 'edit'
  match?: MatchListItem      // edit 時のプリフィル対象（create 時は undefined）
  open: boolean              // 親が v-model:open で開閉制御
}>()

const emit = defineEmits<{
  'update:open': [value: boolean]
  saved: []                  // 保存成功 → 親がモーダル閉じ + useMatches().refresh()
}>()

const { t } = useI18n()
</script>
```

### 2. フォーム state とプリフィル / 既定値 🔵
**信頼性**: 🔵 *REQ-007 / REQ-008 / REQ-109 / dataflow.md 機能3 プリフィル / interfaces.ts CreateMatchInput*

`name`（任意）・`matchDate`（既定＝本日 `YYYY-MM-DD`）・4 選手 id・`videoSourceType`（既定 `youtube`）・
`videoSourceUrl`。create 時は既定値、edit 時は `props.match` で初期化（teamA/teamB の id 配列を 4 枠へ
展開）。モーダルを開くたび（`mode` / `match` 変化時）にリセットする。

```vue
<script setup lang="ts">
const name = ref<string>('')
const matchDate = ref<string>('')          // YYYY-MM-DD
const teamAPlayer1Id = ref<string | null>(null)
const teamAPlayer2Id = ref<string | null>(null)
const teamBPlayer1Id = ref<string | null>(null)
const teamBPlayer2Id = ref<string | null>(null)
const videoSourceType = ref<VideoSourceType>('youtube')
const videoSourceUrl = ref<string>('')      // youtube=URL / local=file.name

function todayIso(): string {
  return new Date().toISOString().slice(0, 10)   // 既定=本日（REQ-008）
}

function resetForm() {
  if (props.mode === 'edit' && props.match) {
    const m = props.match
    name.value = m.name ?? ''
    matchDate.value = m.matchDate
    teamAPlayer1Id.value = m.teamA[0].id
    teamAPlayer2Id.value = m.teamA[1].id
    teamBPlayer1Id.value = m.teamB[0].id
    teamBPlayer2Id.value = m.teamB[1].id
    videoSourceType.value = m.videoSourceType
    videoSourceUrl.value = m.videoSourceUrl
  } else {
    name.value = ''
    matchDate.value = todayIso()
    teamAPlayer1Id.value = teamAPlayer2Id.value = null
    teamBPlayer1Id.value = teamBPlayer2Id.value = null
    videoSourceType.value = 'youtube'
    videoSourceUrl.value = ''
  }
}
watch(() => [props.open, props.match, props.mode], () => {
  if (props.open) resetForm()
})
</script>
```

### 3. 選手選択肢（他枠除外・NFR-202） 🔵
**信頼性**: 🔵 *NFR-202 / REQ-006 / EDGE-001 / architecture.md §UI（各枠は他枠選択済 player を除外）*

選択肢は `usePlayers()` の未削除ロスター。各枠の `items` は、**他 3 枠で既に選択された player を除外**
した集合を返す computed にする（自枠の現在値は残す）。これにより UI 段階で 4 選手重複（REQ-101 /
EDGE-001）を防ぎ、最終的な相異は `matchFormSchema` の refine が二重に保証する。

```vue
<script setup lang="ts">
const { data: players } = usePlayers()   // 未削除ロスター（REQ-006）

// 自枠以外で選択済の id を除外した選択肢を返す
function itemsExcluding(self: Ref<string | null>) {
  return computed(() => {
    const taken = new Set(
      [teamAPlayer1Id, teamAPlayer2Id, teamBPlayer1Id, teamBPlayer2Id]
        .filter(r => r !== self)
        .map(r => r.value)
        .filter((v): v is string => v != null)
    )
    return (players.value ?? [])
      .filter(p => !taken.has(p.id))
      .map(p => ({ value: p.id, label: p.name }))
  })
}
const itemsA1 = itemsExcluding(teamAPlayer1Id)
const itemsA2 = itemsExcluding(teamAPlayer2Id)
const itemsB1 = itemsExcluding(teamBPlayer1Id)
const itemsB2 = itemsExcluding(teamBPlayer2Id)
</script>
```

### 4. 動画ソース切替（条件付きフィールド） 🔵
**信頼性**: 🔵 *REQ-106 / REQ-107 / EDGE-003 / EDGE-004 / architecture.md §UI*

`<URadioGroup>` で `videoSourceType` を選び、`youtube` のときは URL テキスト入力、`local` のときは
ファイル選択を表示する。`local` はファイル選択時に `file.name` を `videoSourceUrl` にセットする
（OS パスは保持しない、REQ-106）。種別切替時は `videoSourceUrl` をクリアして取り違えを防ぐ。

```vue
<script setup lang="ts">
const videoSourceItems = computed(() =>
  (['youtube', 'local'] as const).map(v => ({
    value: v,
    label: t(`matches.videoSourceOptions.${v}`)
  }))
)

watch(videoSourceType, () => { videoSourceUrl.value = '' })   // 切替で取り違え防止

function onFileSelect(event: Event) {
  const file = (event.target as HTMLInputElement).files?.[0]
  if (file) videoSourceUrl.value = file.name   // 元ファイル名ラベル（REQ-106）
}
</script>
```

### 5. 検証（inline）と保存ハンドラ 🔵
**信頼性**: 🔵 *EDGE-009 / EDGE-001 / 003 / 004 / 011 / 012 / dataflow.md 機能2 / interfaces.ts §4 matchFormSchema*

保存時にまず `matchFormSchema.safeParse(...)` で検証。失敗なら issue を path 別に `<UFormField>` の
inline error（`t('errors.<message>')`）へ割り当て、**composable を呼ばない**（EDGE-009）。成功なら
mode に応じて `createMatch` / `updateMatch` を呼び、`error` が無ければ `emit('saved')`、あれば
`showError`（toast、EDGE-010）。

```vue
<script setup lang="ts">
const { createMatch, pending: createPending } = useCreateMatch()
const { updateMatch, pending: updatePending } = useUpdateMatch()
const { showError } = useToastErrors()
const pending = computed(() => createPending.value || updatePending.value)

// path → inline メッセージ（UFormField :error 用）
const fieldErrors = ref<Record<string, string>>({})

async function onSubmit() {
  fieldErrors.value = {}
  const parsed = matchFormSchema.safeParse({
    name: name.value,
    matchDate: matchDate.value,
    teamAPlayer1Id: teamAPlayer1Id.value,
    teamAPlayer2Id: teamAPlayer2Id.value,
    teamBPlayer1Id: teamBPlayer1Id.value,
    teamBPlayer2Id: teamBPlayer2Id.value,
    videoSourceType: videoSourceType.value,
    videoSourceUrl: videoSourceUrl.value
  })
  if (!parsed.success) {
    for (const issue of parsed.error.issues) {
      const key = String(issue.path[0] ?? 'form')
      fieldErrors.value[key] = t(`errors.${issue.message}`)   // inline（EDGE-009）
    }
    return                                                    // composable を呼ばない
  }

  let error: unknown
  if (props.mode === 'edit' && props.match) {
    ;({ error } = await updateMatch(props.match.id, parsed.data as UpdateMatchInput))
  } else {
    ;({ error } = await createMatch(parsed.data as CreateMatchInput))
  }
  if (error) {
    showError(error)            // RLS / distinct CHECK / 通信 → toast（EDGE-010）
    return
  }
  emit('saved')                 // 成功 → 親が閉じ + refresh
}
</script>
```

### 6. テンプレート（UModal + UForm + UFormField） 🔵
**信頼性**: 🔵 *NFR-201 Nuxt UI v4 / PlayerFormModal パターン / EDGE-009*

`<UModal v-model:open>` 内に `<UForm>`。試合名 / 試合日付 / 4 選手 USelectMenu / 動画ソース URadioGroup +
条件付きフィールドをそれぞれ `<UFormField :error>` で囲む。保存ボタンは `:loading="pending"`
`:disabled="pending"`。タイトルは mode で `modalCreateTitle` / `modalEditTitle` を出し分ける。全文言 `t()`。

```vue
<template>
  <UModal :open="open" @update:open="emit('update:open', $event)">
    <template #content>
      <UForm :state="{}" @submit.prevent="onSubmit">
        <h2 class="text-lg font-semibold mb-4">
          {{ mode === 'edit' ? t('matches.modalEditTitle') : t('matches.modalCreateTitle') }}
        </h2>

        <UFormField :label="t('matches.nameLabel')" name="name" :error="fieldErrors.name">
          <UInput v-model="name" :placeholder="t('matches.namePlaceholder')" />
        </UFormField>

        <UFormField :label="t('matches.matchDateLabel')" name="matchDate"
          :error="fieldErrors.matchDate" class="mt-4">
          <UInput v-model="matchDate" type="date" />
        </UFormField>

        <!-- team A / team B の 4 枠 USelectMenu（他枠除外 items）-->
        <UFormField :label="t('matches.teamALabel')" name="teamA" :error="fieldErrors.form" class="mt-4">
          <USelectMenu v-model="teamAPlayer1Id" :items="itemsA1" :placeholder="t('matches.playerSlotPlaceholder')" />
          <USelectMenu v-model="teamAPlayer2Id" :items="itemsA2" :placeholder="t('matches.playerSlotPlaceholder')" class="mt-2" />
        </UFormField>
        <UFormField :label="t('matches.teamBLabel')" name="teamB" class="mt-4">
          <USelectMenu v-model="teamBPlayer1Id" :items="itemsB1" :placeholder="t('matches.playerSlotPlaceholder')" />
          <USelectMenu v-model="teamBPlayer2Id" :items="itemsB2" :placeholder="t('matches.playerSlotPlaceholder')" class="mt-2" />
        </UFormField>

        <UFormField :label="t('matches.videoSourceLabel')" name="videoSourceType" class="mt-4">
          <URadioGroup v-model="videoSourceType" :items="videoSourceItems" />
        </UFormField>
        <UFormField v-if="videoSourceType === 'youtube'" :label="t('matches.youtubeUrlLabel')"
          name="videoSourceUrl" :error="fieldErrors.videoSourceUrl" class="mt-2">
          <UInput v-model="videoSourceUrl" :placeholder="t('matches.youtubeUrlPlaceholder')" />
        </UFormField>
        <UFormField v-else :label="t('matches.localFileLabel')"
          name="videoSourceUrl" :error="fieldErrors.videoSourceUrl" class="mt-2">
          <input type="file" accept="video/*" @change="onFileSelect" />
          <p v-if="videoSourceUrl" class="text-sm text-gray-500 mt-1">{{ videoSourceUrl }}</p>
        </UFormField>

        <div class="mt-6 flex justify-end gap-2">
          <UButton color="neutral" variant="ghost" :label="t('matches.cancel')"
            :disabled="pending" @click="emit('update:open', false)" />
          <UButton type="submit" :label="t('matches.save')" :loading="pending" :disabled="pending" />
        </div>
      </UForm>
    </template>
  </UModal>
</template>
```

## 注意事項
- 検証 NG 時は **composable を呼ばない**（無駄な insert / update を発生させない、EDGE-009）。
- 検証エラーの inline 表示は `t('errors.' + issue.message)`。`message` 値は TASK-0007 の `errors.*` キー /
  TASK-0004 の Zod message と**完全一致**させること（表記ゆれ厳禁）。
- `useCreateMatch` / `useUpdateMatch` は **Supabase native `{ data, error }`** を返す。`error` truthy を
  失敗分岐に使い、表示はチャネル（toast / inline）を見る（ADR-007 §補遺 / interfaces.ts §2）。
- 選手選択肢は **`usePlayers`（未削除ロスター）を再利用**（NFR-202 / REQ-006）。一覧の名前解決
  （EDGE-007 で削除済 player も表示）は `useMatches` 側の責務であり、本モーダルの選択肢には未削除のみ出す。
- `local` の `videoSourceUrl` は **`file.name`（元ファイル名ラベル）**。OS パス・実体は保持しない（REQ-106 /
  video-playback 方式A）。種別切替で `videoSourceUrl` をクリアして取り違えを防ぐ。
- supabase を直叩きしない（必ず composable 経由、REQ-403）。
- モーダル開閉は親が `v-model:open` 制御。`saved` 後の **閉じる責務は親**（本コンポーネントは emit のみ）。
- テストは happy-dom + i18n mock（`t` はキーをそのまま返す）。`matchFormSchema` は実物を使い、
  Nuxt UI は最小スタブ。冗長ケースを作らない（NFR-303 / feedback_test_coverage）。
