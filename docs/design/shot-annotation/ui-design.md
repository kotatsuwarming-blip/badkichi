## 画面の基本構造 🔵

- ルート: `/groups/[id]/matches/[matchId]/annotate`。PC 優先（キーボードが主役）+ スマホ対応
- 上部にモードバー（クイック / 種別 / 打点 + モード別進捗チップ）。モードは任意順・途中離脱可（REQ-003）
- 下部にラリー/ショット一覧（任意位置へ戻って上書き = 訂正の主手段、REQ-108）

```
┌──────────────────────────────────────────────────────────┐
│ [← 試合]  練習試合 vs ○○  [クイック 60%][種別 0%][打点 0%] │ AnnotationModeBar
├───────────────────────────────┬──────────────────────────┤
│                               │                          │
│        動画 / 静止フレーム      │   モード別入力パネル       │
│        (AnnotationVideoPane)  │   (QuickPass/TypePass/   │
│                               │    PositionPass Panel)   │
├───────────────────────────────┴──────────────────────────┤
│ ラリー一覧: #1 ✓✓─ │ #2 ✓── │ #3(レット·skip) │ #4 ──…    │ AnnotationRallyList
└──────────────────────────────────────────────────────────┘
```

- ラリー一覧の ✓ はモード別注釈済みマーク（クイック/種別/打点の3点）。レットはグレー表示で巡回対象外（REQ-106） 🔵

## モード1: クイックパス 🔵

**関連**: REQ-004 / 005 / 006 / 102

```
│  ▶ ループ再生中 [−1s ◀━●━▶ +2.5s]  ラリー #12  │
├───────────────────────────────────────────────┤
│  決まり方は?                                    │
│  [イン(床)] [アウト] [ネット] [越えず]           │
│  [身体] [サーブフォルト] [不明]                  │
│                                               │
│  (in/out 選択時) 落下点をタップ:                 │
│  ┌─────────────────┐  ← ライン外領域込みコート図  │
│  │ ░░░░░░░░░░░░░░░ │     ░ = アウト領域          │
│  │ ░┌───────────┐░ │                            │
│  │ ░│    B側     │░ │  タップ→ land_x/y 保存     │
│  │ ░╞═══════════╡░ │  ライン外なら side/back/both │
│  │ ░│    A側     │░ │  を自動導出                 │
│  │ ░└───────────┘░ │  [座標スキップ → サブ選択]   │
│  │ ░░░░░░░░░░░░░░░ │                            │
│  └─────────────────┘                            │
│  決定打(自動特定: #12-4 スマッシュ?) 種別: [パレット]│
│  ⚠ 導出勝者がpoint_winnerと矛盾 (あれば表示)      │
```

- end_reason 入力 → (in/out なら落下点) → 決定打種別 → **自動で次のラリーへ**。
  ボタンはキーボード対応。キー割当の初期値 = `1=イン 2=アウト 3=ネット 4=越えず 5=不明
  6=身体 7=サーブフォルト`（頻度順）。試用後に調整（design-interview D6） 🔵
- ループは非対称窓（前1秒/後2.5秒）。決着イベントが最終打の後に起きるため（REQ-004）

## モード2: 種別パス 🔵

**関連**: REQ-007 / 008 / 103 / 104 / 109

```
│  ▶ 連続再生 1.0x [0.5][0.75][1.0][1.25][1.5]     │
│  hand記録: [ON] ← パス単位トグル (REQ-104)        │
├───────────────────────────────────────────────┤
│  ラリー #5   ● ● ● ○ ○ ○ ○   (3/7 入力済み)      │
│                                               │
│  1クリア 2スマッシュ 3カット 4リバカ 5ドロップ      │
│  6ドライブ 7プッシュ 8ハーフ 9ヘアピン 0ロブ        │
│  Qロングレシーブ Wドライブレシーブ Eショートレシーブ  │
│  (Shift+キー = バックハンド)                      │
│                                               │
│  ※直前がスマッシュ → Q/W/E をハイライト表示        │
│  [このラリーをやり直す]  [↩ 直前を取り消し]        │
```

- **順番マッチング**: ラリー内 k 回目の打鍵 = k 番目のショット。押すタイミングの精度は不要 🔵
- ラリー境界で自動一時停止（●の埋まり具合を確認して続行）。ラリー間は自動スキップ 🔵
- 1打目はサーブ自動確定 → S/L/D の三択だけ提示（REQ-109） 🔵
- キー割当は常に固定。文脈ハイライトは色/枠のみ（REQ-103） 🔵

## モード3: 打点パス 🔵

**関連**: REQ-009 / 010 / 011 / 012 / 101

### ローカル動画（紙芝居 + サムネ帯）

```
│  ショット #5-3  (打者: 自動確定 or 二択)           │
├───────────────────────────────────────────────┤
│  ┌────┬────┬────┬────┬────┐  サムネ帯 (±0.5s)    │
│  │ -0.4│-0.2│ 0 │+0.2│+0.4│  ← 正しい打球フレーム │
│  └────┴────┴──▲─┴────┴────┘     をクリック       │
│         (選択フレームを拡大表示)                    │
│  ┌─────────────────┐                            │
│  │   コート図        │  打点をタップ → hit_x/y     │
│  │  (±50cm精度でOK  │  マーカーは大きめの円         │
│  │   のトーン)       │  (NFR-202)                 │
│  └─────────────────┘                            │
│  打者: [田中] [佐藤] ← 二択のときだけ表示 (REQ-012) │
│  → 自動で次のショットへ (先読み済みで即時)          │
```

- 初回に **OffsetCalibrator**: 冒頭数ショットでフレームを手動で合わせ → 平均遅延を適用（REQ-010） 🔵
- フレーム選択で `annotated_timestamp_ms` 保存（押下時刻は不変） 🔵

### YouTube（スローループ）

- サムネ帯なし。窓 = 前1.2秒/後0.3秒のスローループ（0.25〜0.5x）→ Space で一時停止 →
  コート図タップ。`annotated_timestamp_ms` は保存しない（REQ-101） 🔵
- モードは `matches.video_source_type` で自動切替（TC-101） 🔵

## インタラクション / ショートカット 🔵

| 操作 | PC | スマホ | 備考 |
|---|---|---|---|
| 種別入力 | 1-0 / Q W E | パレットタップ | キー固定（筋肉記憶） |
| バックハンド | Shift+種別キー | 長押し | hand トグル ON 時のみ書込 |
| サーブ三択 | S / L / D | チップ | 1打目のみ |
| end_reason | 1-7 | ボタン | クイックパス |
| フレーム選択 | ←/→ で微調整 + Enter | サムネタップ | ローカルのみ |
| ループ一時停止 | Space | タップ | |
| 直前1段 undo | Backspace | ↩ ボタン | REQ-108 |
| 任意位置へ戻る | ラリー一覧クリック | 同左 | 上書き = 訂正の主手段 |

## スマホ（1カラム） 🟡

- モードバー → 動画 → 入力パネル → ラリー一覧の縦積み。種別パレットは4列グリッド。
- 打点入力はコート図を幅いっぱいに表示。縦フリック等の拡張ジェスチャは MVP では入れない
  （high/low 撤回済みのため用途がない）。
- 代行作業（作者）は PC 前提。スマホは閲覧+軽微修正ができれば十分 🟡

## 進捗と分担 🔵

- モードバーの進捗チップ = `useAnnotationProgress`（null 有無から導出、レット除外）
- 「続きから」ボタン = 次の未注釈位置へジャンプ（セット/ラリー単位の再開、REQ-013）
- チーム分担はセット単位の運用ルール（機能は作らない。EDGE-001 = last-write-wins）

## 品質サマリー

- 🔵: モード構造・入力フロー・キーマップ・コート図・サムネ帯・進捗（要件で確定済みの具体化）
- 🟡: end_reason のキー割当・スマホの細部レイアウト・パレットの視覚デザイン（プロトタイプで検証）
- 🔴: 0件
