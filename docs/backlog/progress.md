# 開発ループの進捗と学び

`/next-task` の各周と `/refill-queue` の各回が、終わりに 1 項目を追記する。次の周は最初にこれを読む。
タスクのキューと inbox は GitHub Issues (ラベル `loop:task` / `loop:inbox`、2026-11-23 に queue.json から移行)。
書くのは「何をしたか」ではなく「次の周が同じところで詰まらないための注意」。PR 番号と日付を付ける。

書式: `- YYYY-MM-DD <タスク ID> PR #n — <学び 1〜3 行>`
