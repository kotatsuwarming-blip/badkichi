# 開発ループの進捗と学び

`/next-task` の各周が、終わりに 1 項目を追記する。次の周は最初にこれを読む。
書くのは「何をしたか」ではなく「次の周が同じところで詰まらないための注意」。PR 番号と日付を付ける。

書式: `- YYYY-MM-DD <タスク ID> PR #n — <学び 1〜3 行>`

## 記録

- 2026-11-23 ADR-020-A2 PR #92 — 1 周目。`/next-task` はセッション開始後に追加したコマンドだったため Skill として読めず、手順を手動実行した。新しいセッションで起動すれば読める。rallies にはラリー終了時刻の列が無い (最終ショットで代替) ので、下書き JSON の `end_ms` はショット行生成にしか使わない。rallies のサーブ関連列は NOT NULL で、予測が欠けたときの既定値が要る (REQ-008)。要件定義の 🟡 (補完) は 7 件、設計で値を確定する。
