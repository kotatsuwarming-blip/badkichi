# singles-support ユーザストーリー

**作成日**: 2026-08-28
**関連**: [requirements.md](requirements.md) / [acceptance-criteria.md](acceptance-criteria.md)

## ストーリー1: シングルスの試合を登録する

- **である** チームの記録係 **として**
- **私は** シングルスの試合を「選手 A vs 選手 B」の 2 人だけで登録したい
- **そうすることで** ダブルスの 4 枠を無理に埋めたり保存に失敗したりせず（U-04）、練習試合や個人戦を正しく残せる

対応要件: REQ-001 / REQ-002 / REQ-003 / REQ-101 / REQ-201

## ストーリー2: シングルスの試合を記録する

- **である** 記録係 **として**
- **私は** シングルスでもダブルスと同じ操作（打った／得点／レット／スキップ／取り消し）で記録したい
- **そうすることで** 形式ごとに操作を覚え直す必要がなく、コート図のサーバー位置（偶数=右/奇数=左）を見ながら迷わず記録できる

対応要件: REQ-004 / REQ-005 / REQ-104 / REQ-106 / REQ-107 / REQ-109

## ストーリー3: シングルスの注釈を素早く終える

- **である** 分析担当 **として**
- **私は** シングルスの種別パスで「誰が打ったか」を毎回聞かれずに進みたい
- **そうすることで** 打者が自明なシングルスでは 3 打目以降の入力が 1 キーで済み、長いラリーの注釈負荷が下がる

対応要件: REQ-108

## ストーリー4: シングルスの成績を選手別に見る

- **である** コーチ **として**
- **私は** シングルス試合のサーブ／レシーブ得点率やショット統計を選手別に見たい
- **そうすることで** ペアに依存しない個人の傾向（サーブ位置別の得点率など）を把握できる

対応要件: REQ-006 / REQ-110 / EDGE-103 / EDGE-104

## ストーリー5: 既存のダブルスに影響を出さない

- **である** 既存ユーザー **として**
- **私は** これまでに登録したダブルスの試合・記録・統計が今までどおり動いてほしい
- **そうすることで** 機能追加を理由にデータの見え方や操作が変わる不安なく使い続けられる

対応要件: REQ-203 / REQ-401 / REQ-405 / REQ-406

## ストーリー6: 一覧で形式を見分ける

- **である** チームメンバー **として**
- **私は** 試合一覧でどれがシングルスでどれがダブルスか一目で分かるようにしたい
- **そうすることで** 目的の試合（個人戦／ペア戦）をすぐに開ける

対応要件: REQ-007 / EDGE-201
