## REQ-001: 試合一覧表示 🔵

**信頼性**: 🔵 *matches_select RLS + idx_matches_group_id*

### Given（前提条件）
- Group 所属ユーザーがログイン済み
- 当該 Group に未削除の試合が複数、別 Group にも試合が存在する

### When（実行条件）
- `/groups/[id]/matches` を開く

### Then（期待結果）
- 当該 Group の未削除試合のみが「試合名（未入力時は対戦カード）」+「試合日付（日付のみ）」で表示される
- 試合日付の降順（新しい順、同日は created_at）で並ぶ
- 別 Group の試合・削除済み試合は表示されない

### テストケース

#### 正常系
- [ ] **TC-001-01**: 未削除試合 N 件 → N 行表示（試合日付の新しい順） 🔵 *NFR-203*
- [ ] **TC-001-02**: 削除済み（`deleted_at IS NOT NULL`）試合 → 非表示 🔵 *EDGE-006*

#### 異常系
- [ ] **TC-001-E01**: 他 Group の試合は RLS で取得されない 🔵 *NFR-101*

## REQ-002 / REQ-006: 試合の新規作成（4選手 + 動画ソース）🔵

**信頼性**: 🔵 *matches_insert RLS + matches テーブル定義 + ヒアリング2026-06-02*

### Given（前提条件）
- Group 所属ユーザー、選択可能 player が 4 人以上

### When（実行条件）
- 試合名（任意）・試合日付を入力し、team A × 2 / team B × 2 を選択し、動画ソースを指定して保存

### Then（期待結果）
- matches に 1 行 insert され（name / match_date 含む）、一覧に追加される

### テストケース

#### 正常系
- [ ] **TC-002-01**: 試合名あり + 試合日付 + 4 選手 + local 動画 → 作成成功、`video_source_type='local'` + 元ファイル名ラベル保存 🔵 *REQ-002/106*
- [ ] **TC-002-02**: 試合名あり + 試合日付 + 4 選手 + youtube URL → 作成成功、`video_source_type='youtube'` + URL 保存 🔵 *REQ-107*
- [ ] **TC-002-03**: 試合名 未入力 + 試合日付 + 4 選手 + 動画 → 作成成功（一覧では対戦カード表示） 🔵 *REQ-007 / EDGE-011*

#### 異常系（条件付要件）
- [ ] **TC-002-E01**: 4 選手に同一 player を含む → 拒否（重複エラー） 🔵 *REQ-101 / EDGE-001 / 6-way CHECK*
- [ ] **TC-002-E02**: 選手スロット未選択あり → 拒否 🔵 *REQ-102 / EDGE-002*
- [ ] **TC-002-E03**: 動画ソース未指定（local 未選択 / youtube URL 空） → 拒否 🔵 *REQ-103 / EDGE-003*
- [ ] **TC-002-E04**: 他 Group の player を指定 → 選択肢に出ず、送信時も複合 FK で拒否 🔵 *REQ-406 / EDGE-008*
- [ ] **TC-002-E05**: 試合日付 未入力 → 拒否 🔵 *REQ-109 / EDGE-012*
- [ ] **TC-002-E06**: 試合名 trim 後 51 字 → 拒否 / 50 字 → 許可 🔵 *REQ-108 / EDGE-011*

#### 境界値 / データ整合
- [ ] **TC-002-B01**: 既存と同一カード（同 4 選手・同動画）を作成 → 成功し 2 行表示 🔵 *REQ-104 / EDGE-005*
- [ ] **TC-002-B02**: 同一 match_date の試合が複数 → 一覧で created_at 降順に安定ソート 🔵 *NFR-203 / EDGE-013*

## REQ-003: 試合の編集（全項目）🔵

**信頼性**: 🔵 *ヒアリング2026-06-02（全項目編集可）+ matches_update RLS*

### Given（前提条件）
- 既存の未削除試合がある

### When（実行条件）
- 4 選手構成・動画ソースを変更して保存

### Then（期待結果）
- matches 行が update され、一覧に反映される

### テストケース

#### 正常系
- [ ] **TC-003-01**: 選手 1 名を別 player に差し替え → 更新成功 🔵
- [ ] **TC-003-02**: 動画ソースを local→youtube に変更 → 更新成功 🔵

#### 異常系
- [ ] **TC-003-E01**: 更新後の 4 選手が重複 → 拒否 🔵 *REQ-101*
- [ ] **TC-003-E02**: スロットを空にして更新 → 拒否 🔵 *REQ-102*

## REQ-004 / REQ-105: 試合の確認ダイアログ付きソフト削除 🔵

**信頼性**: 🔵 *ヒアリング2026-06-02（確認ダイアログ付きソフト削除）*

### Given（前提条件）
- 既存の未削除試合がある

### When（実行条件）
- 削除を選び、確認ダイアログで承認

### Then（期待結果）
- `deleted_at` が設定され（ソフト削除）、一覧から消える。物理削除はされない

### テストケース

#### 正常系
- [ ] **TC-004-01**: 削除選択 → 確認ダイアログ表示 → 承認 → 一覧から消える 🔵
- [ ] **TC-004-02**: 確認ダイアログでキャンセル → 削除されない 🔵

#### 異常系
- [ ] **TC-004-E01**: 物理 DELETE は行われない（`deleted_at` UPDATE のみ） 🔵 *REQ-402 / DELETE ポリシー無し*
