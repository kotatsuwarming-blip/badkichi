# shot-value ユーザストーリー

**作成日**: 2026-09-16

## ストーリー1: 球種ごとの強みと課題を1つの数字で知る

- **である** チームで練習方針を考える選手 **として**
- **私は** 自分の各球種が得点にどれだけ効いているか/失点のもとになっているかを1つの数字（収支）で見たい
- **そうすることで** 「スマッシュは黒字、ロブは赤字」のように強み・課題を根拠を持って言え、練習の優先順位を決められる

対応: REQ-001〜003, REQ-005。川島氏の「強みはショット種別で見たい（スマッシュで得点 / スマッシュレシーブで失点）」
（usability-test-01 2026-06-16）への直接回答。

## ストーリー2: 赤字の「理由」まで分解する

- **である** 同上の選手 **として**
- **私は** 赤字球種の内訳（自滅型か、甘い球を決められる型か、布石として稼げていないのか）を見たい
- **そうすることで** 同じ「ロブが弱い」でも、ミスを減らす練習か、質を上げる練習かを選べる

対応: REQ-005（5 役割の積み上げ内訳）。単なる球種構成比・ミス率（探針 D）では出ない情報。

## ストーリー3: コートのどこが強い/弱いかを一目で見る

- **である** ダブルスのペア/コーチ **として**
- **私は** コート図で「どこから打つ球が黒字/赤字か」を見て、気になるゾーン（複数可）に絞った内訳を見たい
- **そうすることで** 「後ろに下げられると収支が落ちる」等の位置の課題を発見し、その理由（球種）まで掘れる

対応: REQ-004（3×3 複数選択・行一括）、REQ-101。「どの場所で失点したか」（川島氏）の発展形。

## ストーリー4: 強みと弱みを1箇所で見る

- **である** stats 画面の利用者 **として**
- **私は** 収支・ミスした打点・決められた落下点を1つのタブで続けて見たい
- **そうすることで** タブを往復せず「強み・課題」の全体像を掴める

対応: REQ-201（タブ統合）。
