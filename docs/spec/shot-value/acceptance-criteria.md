# shot-value 受け入れ基準

**作成日**: 2026-09-16

## 採点規則（単体テスト）

- [ ] ミス決着 5 打の検算例（requirements.md）で、5 ショットの役割と点が表どおりになる
- [ ] エース決着 5 打の検算例で同上
- [ ] service_fault はサーブに −1 のみで、誰も加点されない
- [ ] 1 打決着（サーブミス）: サーブ −1 のみ。2 打決着（レシーブミス）: レシーブ −1・サーブ +w・遡りなし
- [ ] 3 打未満のラリーで遡り先が無くてもエラーにならない（EDGE-001）
- [ ] end_reason が null / unknown のラリーは分母にも入らない（REQ-102）
- [ ] hit_player_id null のショットが打順位置を消費しつつ選手集計から除外される（REQ-104）
- [ ] shot_type null が unknown 区分に集計される（REQ-103）
- [ ] 役割は 1 ショットに 1 つ（排他）
- [ ] 重み定数（w, b1, b2）を変えると再取得なしで表示が変わる（REQ-002/401）
- [ ] SV100・稼いだ/失った成分・95%CI の計算が検算例と一致する（REQ-003/006）

## 画面（コンポーネント/ブラウザ確認）

- [ ] 3×3 セルの複数選択・解除・行ラベル一括選択が動く（REQ-004）
- [ ] 未選択時はコート全体の集計が表示される
- [ ] 合計が「稼いだ − 失った = 収支」の等式 + 平易文で表示される（REQ-003）
- [ ] 内訳行: 5 役割の積み上げ + 凡例 + ホバー数値 + 行末収支±CI + n 降順（REQ-005/006）
- [ ] n < 5 の行が薄表示 + 「本数不足」（REQ-007）
- [ ] ゾーン選択中、座標なしショット・camera_near_team null ラリーが除外され母数に反映（REQ-101）
- [ ] 選択ゾーン 0 件で空状態表示（EDGE-003）
- [ ] ミラーが選手視点（shot-stats REQ-105 と同一）で、注釈スタジオの実座標と向きが一致する

## タブ改組

- [ ] タブが「サーブ周り / 強み・課題 / ラリー展開」の 3 つになる（REQ-201）
- [ ] 「強み・課題」内が SV 画面 → ミスした打点 → 決められた落下点 の順
- [ ] 旧「強み分析」「弱点分析」タブと placeholder 文言（shotStats.strengths.note）が消える
- [ ] 試合単位 / Group 横断の両 stats 画面で動く
- [ ] シングルス試合で動作し、注記が選手単位文言になる（REQ-203）
- [ ] フィルタ（打者・セット・hand + グローバル）で全表示が連動する（REQ-202）
- [ ] i18n: ja / en 両方のキーが揃う（check-i18n-keys が通る）

## 非機能

- [ ] ゾーン選択の切替で RPC が再実行されない（NFR-001）
- [ ] 母数併記・注釈率バッジが表示される（REQ-402）
- [ ] pnpm lint / typecheck / vitest 全 green
