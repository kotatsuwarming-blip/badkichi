# stats-miss-out-detail 要件定義書

**作成日**: 2026-09-28
**作業規模**: 小〜中（1 PR。RPC 2 本の CREATE OR REPLACE + チャート 3 箇所）
**位置づけ**: shot-stats 探針群の表示改善（ヒアリング 2026-09-28）。
**依存単位**: shot-stats（配球ヒートマップ F / 弱点マップ / レシーブ詳細）

## 概要

1. **ミスした打点マップの深掘り**: セルをホバー/クリックすると、そのセルからのミスの
   球種内訳と決着種別（ネットか・アウトか）を表示する。セルの数字は本数でなく
   **全ミス中の割合（%）** にする。
2. **アウト位置リング（11 枠）**: 配球ヒートマップとサーブ周りの返球コース図で、
   アウトの落下位置を相手半面を取り囲む **11 個の小枠**（左 3・右 3・奥 3・奥角 2）で
   本数表示する。アウトと分かる色分け（赤系）。
3. **スコープ外**: ネットに掛かった位置（高さ・左右）は記録機能が無いため割愛
   🔵 *ヒアリング 2026-09-28（ユーザ明示）*。

## 機能要件（EARS記法）

### ① ミスした打点の内訳と割合

- REQ-001: ミスした打点マップのセルは、本数でなく**割合（そのセルのミス数 ÷ 表示中の全ミス数、% 整数丸め）**を表示しなければならない。本数はホバー内訳・選択パネルに残す 🔵
- REQ-002: セルのホバー（SVG title）とクリック（タップ環境向け）で、そのセルの内訳を表示しなければならない。内訳 = 球種ごとの本数 × 決着種別（ネット / アウト）。クリックは選択パネル（マップ下）に表示し、同一セル再クリックで解除 🔵
- REQ-003: 内訳の決着種別は placement の `dest_kind`（'net' / 'out'）から導出する（追加入力なし・クライアント集計のみ）

### ② アウト位置リング（11 枠）

- REQ-101: 対象は **配球ヒートマップ（探針 F）** と **サーブ周りの返球コース図（レシーブ詳細 Level 3）** の 2 箇所 🔵
- REQ-102: 相手半面の周囲に 11 枠を配置しなければならない: **左サイド 3（相手半面の行 0〜2 に対応）/ 右サイド 3 / 奥 3（列 0〜2 に対応）/ 奥角 2（左奥・右奥）**。枠はコートセルより小さくてよい 🔵 *ヒアリング 2026-09-28（11 個・少し小さく・数を表示）*
- REQ-103: 枠にはアウト本数を表示し、**アウトと分かる色（赤系）** で塗る。0 本の枠は淡色（枠の存在は見せる）🔵
- REQ-104: RPC（`stats_shot_placement` / `stats_receive_detail`）は out の行き先を 11 枠へ割り当てられる粒度で返さなければならない:
  - `dest_out` に角 2 値を追加: `'left' | 'right' | 'back' | 'left_back' | 'right_back'`
    （角の判定 = x 範囲外 かつ y > 1。従来は side 優先で潰していた）
  - サイドアウト（left/right）は `dest_row` に**相手半面の行 0〜2**（0 = ネット側。y を相手半面へクランプ）を返す
  - バックアウト（back）は `dest_col` に**列 0〜2**（x をクランプ）を返す
  - 角は dest_row/col とも NULL
  - CREATE OR REPLACE（シグネチャ不変・返却値の意味追加のみ）。手前側（y < 0.5）に落ちた
    アウトはネット側サイド枠（row 0）へクランプ算入
- REQ-105: ネットは従来どおり単一枠（ネット位置の記録は無いため）。既存のネット表示位置を維持する
- REQ-106: 従来の 4 方向合算表示（ネット/左/右/奥のテキスト枠）はリングに**置き換える**

### 制約要件

- REQ-401: 読み取り専用 RPC の置換のみ（テーブル変更なし）。クライアントの旧 dest_out 消費箇所（buildDestExtras / buildCourses / SV は無関係）を新語彙に追従させる
- REQ-402: 母数併記・既存フィルタ連動は現状維持

## Edgeケース

- EDGE-001: ミスが 0 本 → マップは従来どおり空表示、% は表示しない
- EDGE-002: 割合の合計が丸めで 100% にならないのは許容（各セル整数丸め）
- EDGE-003: 旧 dest_out（'left'/'right'/'back'）データは存在しない（RPC 導出のため再計算される）— 移行処理不要

## 受け入れ基準（抜粋）

- [ ] ミスセルに % が出て、ホバー/クリックで「球種 n 本（ネット x / アウト y）」が読める
- [ ] 配球ヒートマップ・返球コース図の周囲に 11 枠が出て、アウト本数が赤系で表示される
- [ ] 角のアウト（従来 side に合算）が角枠に分離される
