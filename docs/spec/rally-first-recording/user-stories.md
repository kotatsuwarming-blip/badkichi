# rally-first-recording ユーザストーリー

**作成日**: 2026-11-01
**関連**: [requirements.md](requirements.md) / [acceptance-criteria.md](acceptance-criteria.md)

## ストーリー1: 試合を倍速で一気に記録する

- **である** 試合の記録係（運営の代行入力を含む） **として**
- **私は** 1 打ずつ「打った」を押さず、ラリーの開始と得点者だけを 1.5〜2 倍速で押して試合を記録したい
- **そうすることで** 42 分の試合の記録が 40 分から 21〜28 分に縮み、ラリーの間の何も起きない時間を見なくてよくなる

対応要件: REQ-001 / REQ-002 / REQ-003 / REQ-004 / REQ-005 / REQ-101 / REQ-104 / NFR-001 / NFR-201

## ストーリー2: 打刻と打点を 1 回のパスで済ませる

- **である** 分析担当 **として**
- **私は** ラリー中の映像だけを低速で流し、打球の瞬間にコート図をタップして、時刻と打点を同時に入れたい
- **そうすることで** 同じショットを打刻と打点で 2 回訪ねなくてよくなり、ループを待たずに流れで入力できる

対応要件: REQ-006 / REQ-007 / REQ-009 / REQ-010 / REQ-108 / REQ-203 / NFR-002 / NFR-003 / NFR-202 / NFR-203

## ストーリー3: 速い打ち合いでも追いつく

- **である** 分析担当 **として**
- **私は** 0.5 倍速で追いつけない打ち合いでは、キーを押している間だけ 0.25 倍速に落としたい
- **そうすることで** 1 打あたり 2〜3 秒の余裕を作れ、タップの時刻精度（±0.2 秒）を保てる

対応要件: REQ-010 / REQ-108 / NFR-003

## ストーリー4: 押し間違いをすぐ直す

- **である** 分析担当 **として**
- **私は** タップを間違えたら Backspace で直前の 1 打を消し、ラリーごと崩れたら頭から流し直したい
- **そうすることで** ループに戻って探し直すことなく、流れを止めずに訂正できる

対応要件: REQ-106 / REQ-107 / REQ-111 / EDGE-104

## ストーリー5: 種別と打者はこれまでどおり入れる

- **である** 分析担当 **として**
- **私は** 流しで作ったショットに、既存の種別パスで種別と打者（個人）を入れたい
- **そうすることで** 覚え直す操作が無く、サーブ自動確定や打者二択などの既存の仕組みがそのまま使える

対応要件: REQ-008 / REQ-011 / EDGE-107

## ストーリー6: 決まり方の入力がショット無しでも進む

- **である** 分析担当 **として**
- **私は** 流しの前にクイックパスで決まり方だけ先に入れることもしたい
- **そうすることで** パスの順序に縛られず、空いた時間で入力を進められる

対応要件: REQ-110 / REQ-012 / REQ-112

## ストーリー7: 従来の記録方式はそのまま使える

- **である** 既存の利用者 **として**
- **私は** これまでのショット単位の記録と注釈を、何も変わらずに使い続けたい
- **そうすることで** 過去の試合データと操作の記憶がそのまま活き、新方式はセット単位で試せる

対応要件: REQ-002 / REQ-105 / REQ-402 / REQ-408 / EDGE-201

## ストーリー8: 短縮の効果を数字で確かめる

- **である** プロダクトの作者 **として**
- **私は** 同じゲームを従来方式と新方式で入力し、所要時間を比べたい
- **そうすることで** BL-027 の目標（記録 + 打点が 60 分以下）に届いたかを判断し、次（種別パスの窓短縮・AI 下書き）の優先順位を決められる

対応要件: NFR-301
