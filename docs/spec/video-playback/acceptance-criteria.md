## REQ-001 / REQ-101 / REQ-102: 両ソースの再生 🔵

**信頼性**: 🔵 *PRD §F-02 / data-foundation schema*

### Given / When / Then
- **Given**: 有効な動画ソース（youtube URL または local ファイル）が与えられている
- **When**: プレーヤーを初期化して再生する
- **Then**: 動画が再生可能状態になり、再生が開始する

### テストケース
#### 正常系
- [ ] **TC-001-01**: youtube ソースで動画 ID が解決され再生開始 🔵 *REQ-101*
- [ ] **TC-001-02**: local ソースで選択ファイルが再生開始 🔵 *REQ-102*

#### 異常系
- [ ] **TC-001-E01**: 無効な YouTube URL（ID 抽出不可）→ 再生前にエラー提示 🔵 *EDGE-002*

## REQ-003 / REQ-006: 再生コントロール 🔵

**信頼性**: 🔵 *PRD §F-02*

### Given / When / Then
- **Given**: 再生可能状態の動画
- **When**: 再生 / 一時停止 / シーク / 速度変更を操作する
- **Then**: 各操作が即時に反映される

### テストケース
#### 正常系
- [ ] **TC-003-01**: 再生 → 一時停止 → 再開が状態に反映される 🔵
- [ ] **TC-003-02**: 速度を 0.5 / 1.0 / 2.0 倍に変更して反映される（境界の最小・等倍・最大） 🔵 *REQ-006*

## REQ-004 / REQ-202 / NFR-001: 現在時刻取得（ms） 🔵

**信頼性**: 🔵 *PRD 性能 NFR / B-14*

### Given / When / Then
- **Given**: 再生中の動画
- **When**: 現在時刻取得を呼ぶ
- **Then**: ms 単位の整数が同期的に即時返る

### テストケース
#### 正常系
- [ ] **TC-004-01**: 再生位置 X 秒で `Math.round(X*1000)` の ms 整数が返る 🔵
- [ ] **TC-004-02**: 取得呼び出しがポーリングを伴わず即時に返る（NFR-001 の遅延源にならない） 🔵 *NFR-001*

#### 境界値
- [ ] **TC-004-B01**: 動画 duration が 0 / 取得不可の状態で現在時刻取得が `null` を返す（NaN・負値を返さない） 🔵 *REQ-201 / EDGE-102*

## REQ-005 / REQ-104: 指定 ms へのシーク 🔵

**信頼性**: 🔵 *PRD US-04*

### Given / When / Then
- **Given**: 再生可能状態の動画（duration = D ms）
- **When**: 指定 ms 位置へシークする
- **Then**: 該当位置へ移動する（範囲外は 0〜D に丸める）

### テストケース
#### 正常系
- [ ] **TC-005-01**: 中間位置 ms へシークし現在時刻が一致する 🔵

#### 境界値
- [ ] **TC-005-B01**: 0ms へのシーク 🔵 *EDGE-101*
- [ ] **TC-005-B02**: duration ちょうどへのシーク 🔵 *EDGE-101*
- [ ] **TC-005-B03**: duration 超過 → duration に、負値 → 0 にクランプしてシーク 🔵 *REQ-104 / EDGE-101*

## REQ-103 / REQ-301 / NFR-101: ローカル動画の再選択 🔵

**信頼性**: 🔵 *ユーザヒアリング 2026-06-01（方式 A）*

### Given / When / Then
- **Given**: local ソースでページ再読み込みされ、オブジェクト URL が失効している
- **When**: 動画を再生しようとする
- **Then**: 同一ファイルの再選択を促す UI が表示され、自動再アクセスは行わない

### テストケース
#### 正常系
- [ ] **TC-103-01**: 参照失効状態で再選択促し UI が表示される 🔵
- [ ] **TC-103-02**: 再選択後に再生が復帰する 🔵

## REQ-008 / REQ-009: コントロール描画と汎用オーバーレイスロット 🔵

**信頼性**: 🔵 *ユーザヒアリング 2026-06-01*

### テストケース

## REQ-405 / REQ-406: 責務境界（ドメイン非依存・記録フィードバック） 🔵

**信頼性**: 🔵 *ユーザヒアリング 2026-06-01 / ADR-002 依存関係*

- [ ] **TC-405-01**: video-playback のコード・型に「ショット」「ラリー」等のドメイン概念が現れない（import 含め match-recording への依存ゼロ、設計/静的レビュー観点） 🔵 *REQ-405*
