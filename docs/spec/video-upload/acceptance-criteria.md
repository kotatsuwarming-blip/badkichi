# video-upload 受け入れ基準

**作成日**: 2026-11-24 (video-upload-analysis から分割)
**関連**: [requirements.md](requirements.md) / [user-stories.md](user-stories.md)

テスト ID は `TC-{REQ 番号}-{連番}` とし、E は Edge ケース由来を表す。
試料は戸塚ミックスの動画 (1280×720 30 fps、44 分) と、南区の動画 (縦向き)。

## 1. アップロードと同意

| ID | 前提 | 操作 | 期待結果 | 要件 |
|---|---|---|---|---|
| TC-002-01 | 試合あり | 同意のチェックを入れずにアップロードを開始 | 開始できない | REQ-002 |
| TC-002-02 | 同上 | 同意して開始 | 同意の日時と内容 (アップロード・解析・入力完了後の削除・原本の学習利用の 4 点、(2) に特徴量と訂正の利用を含む、原本の学習利用は既定値どおり) が記録される | REQ-002 |
| TC-002-03 | 同上 | 原本の学習利用をオンにして開始 | 学習提供の同意が試合に紐づいて保存され、`learning` の保持の理由が付く | REQ-002 / REQ-009 |
| TC-009-01 | 原本の学習利用をオフにした試合 | 人が下書きを確認・訂正する | `human_resolutions` と数値特徴量は学習用書き出しに含まれる (映像だけが除外される) | REQ-009 |
| TC-003-01 | 1 GB の動画 | アップロード | 進捗 (割合・転送量) が表示され、完了する | REQ-003 |

## 4. 保護とオプション

| ID | 前提 | 操作 | 期待結果 | 要件 |
|---|---|---|---|---|
| TC-401-01 | 他 Group の利用者 | 原本・`match_videos` に API でアクセス | いずれも取得・更新できない | REQ-401 / NFR-101 |
| TC-401-02 | 署名 URL | 有効期限後にアクセス | 取得できない。URL がログに残っていない | NFR-102 |
| TC-405-01 | 本単位のサーバー処理 | 実装を確認 | フレームの読み取り・推論を行っていない (メタデータと縮小のみ) | REQ-405 |
| TC-301-01 | プロキシ採用時、解析成功 | 自動 | 1280 幅・30 fps のプロキシに置き換わり、原本は削除、置き換えが記録される。保持の理由はプロキシに適用 | REQ-301 |
| TC-302-01 | 運営者 | 一覧を開く | Group ごとの使用量と保持の理由の内訳 | REQ-302 |
