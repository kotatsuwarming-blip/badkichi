## 共通集計規則（REQ-101〜105） 🔵

**信頼性**: 🔵 *note.md §3（確定事項の転記）*

### Given（前提条件）
- レット・未確定・注釈済み/未注釈が混在するラリー/ショットが記録されている

### When（実行条件)
- いずれかの統計 RPC / View を呼び出す

### Then（期待結果）
- `is_let=true`・`point_winner IS NULL`・`is_point_confirmed=false` のラリーが母数・分子から除外される
- `hand IS NULL` がフォアに算入されない
- out 細分・決定打が純関数（`deriveOutDirection` / `decisiveShotIndex`）と一致する
- 座標が選手視点にミラーされる（対象がチーム B のとき x→1−x, y→1−y）

### テストケース

#### 正常系
- [ ] **TC-C-01**: レットラリー（is_let=true・注釈なし・行は存在）を含むセット → 全統計の母数から除外 🔵 *note.md §3-2*
- [ ] **TC-C-02**: チーム B 選手の打点 (0.2, 0.3) → 選手視点で (0.8, 0.7) のゾーンに算入 🔵 *note.md §3-1*
- [ ] **TC-C-03**: end_reason=out・land_x=1.2（x 範囲外）→ out 細分が `deriveOutDirection` と同じ side になる（integration テストで純関数と突き合わせ） 🔵 *note.md §3-4 + REQ-406*
- [ ] **TC-C-04**: end_reason=in の決着ラリー → 決定打 = 最終ショット。end_reason=net → 最終の 1 つ前。service_fault → 決定打なし 🔵 *note.md §3-5*

#### 異常系
- [ ] **TC-C-E01**: land_x/y が null で out_direction のみ保存 → out_direction を採用 🔵 *note.md §3-4*
- [ ] **TC-C-E02**: 他 Group の試合 ID を指定して RPC 呼び出し → 0 件（RLS） 🔵 *stats-dashboard NFR-101 踏襲*

## REQ-001〜004: 表示場所・母数併記・バッジ・フィルタ 🔵

**信頼性**: 🔵 *ヒアリング2026-07-26/08-03*

### Given
- 試合単位 / Group 横断の stats 画面が表示できる

### When
- 「ショット分析」タブ/セクションを開く

### Then
- 8 枚のチャート（A/C/D/F/G/J/K/L。L は試合単位のみ）が到達可能
- 全チャートに n / N が併記され、ヘッダーに注釈率バッジが表示される
- 打者・球種・セット・hand のフィルタが機能し、既存グローバルフィルタと併用できる

### テストケース

#### 正常系
- [ ] **TC-001-01**: 種別注釈 72/100 ショットの試合 → バッジ「種別 72%」、D の母数表記「n=72 / N=100」 🔵
- [ ] **TC-004-01**: 球種フィルタ=smash → F のヒートマップが smash の打点のみに絞られる 🔵
- [ ] **TC-004-02**: セットフィルタ=セット2 + 既存の選手グローバルフィルタ併用 → 両方が AND で効く 🔵

#### 異常系
- [ ] **TC-003-E01**: 注釈 0 件の試合 → バッジ 0%・探針 5 枚は空状態、J/K/L は表示される（EDGE-002） 🔵

## REQ-005〜007: A 決着分析 🔵

**信頼性**: 🔵 *note.md §4-② + ヒアリング2026-08-03*

### Given
- クイックパス注釈（end_reason・land_x/y・打者）済みのラリーがある

### When
- 決着分析チャートを表示する

### Then
- 得点側が「エース（in/body）/ 相手ミス（out/net/not_over/service_fault）」、失点側が「被エース / 自ミス」に分解される
- 決定打球種ランキングと 3×3 落下点ゾーン図が表示される

### テストケース

#### 正常系
- [ ] **TC-005-01**: 勝ちラリー10件（in×4, 相手out×3, 相手net×2, service_fault×1）→ エース獲得4 / 相手ミス獲得6 🔵
- [ ] **TC-006-01**: 決定打 smash×5, cut×2 → ランキング1位 smash(5) 🔵
- [ ] **TC-007-01**: land (0.5, 0.9)（相手コート奥中央）→ 選手視点の該当ゾーンにカウント 🔵

#### 異常系
- [ ] **TC-005-E01**: end_reason=unknown → 決定打なし・内訳で「不明」別掲（EDGE-105） 🔵 *ヒアリング2026-08-03 確定*
- [ ] **TC-006-E01**: 決定打の shot_type 未注釈 → ランキングで「未注釈」として区別（REQ-108） 🔵 *ヒアリング2026-08-03 確定*

## REQ-009〜010: D 球種構成比・成果 🔵

### Given
- 種別パス注釈済みショットがある

### When
- 選手を選択して表示する

### Then
- 球種構成比（16 種）と、球種別のミス率・決定率（分母 = その球種の総打数）が表示される
- 球種の使用割合 × 球種別得点率（その球種を打ったラリーの得点率）の関係が対比表示される
- 打者は Group 内の任意の選手（対戦相手側含む）を選択できる

### テストケース

- [ ] **TC-009-01**: 選手Xの注釈済み50本（clear20/smash15/drop15）→ 構成比 40/30/30% (n=50) 🔵
- [ ] **TC-009-02**: 対戦相手側の選手Yを打者に選択 → Y のショットで同じチャートが表示される 🔵 *ヒアリング2026-08-03（相手のショットも分析）*
- [ ] **TC-010-01**: smash 100本中 決定打25・ミス決着15 → 決定率25%・ミス率15%（分母は総打数） 🔵 *ヒアリング2026-08-03（定義確定）*
- [ ] **TC-010-02**: 使用割合30%の球種の得点率45% → 割合×得点率の対比表示に反映される 🔵 *ヒアリング2026-08-03*
- [ ] **TC-009-B01**: 注釈済み 0 本の選手 → 空状態（REQ-201） 🔵

## REQ-015〜016 / REQ-106〜107: K 展開スピード分析 🔵

### Given
- 全ショットに video_timestamp_ms が記録されたラリーがある（1 本でも欠損があればそのラリーは対象外）

### When
- measure トグル（平均テンポ / 終盤テンポ）を切り替える

### Then
- 得点/失点ラリーのテンポ分布が連続値のまま重ねて表示され、近似値である旨が明示される

### テストケース

#### 正常系
- [ ] **TC-015-01**: ショット11本・10秒のラリー → 平均テンポ (11−1)/10 = 1.0 打/秒 🔵
- [ ] **TC-016-01**: 最後の3打が作る 2 間隔 0.4s, 0.6s → 終盤テンポ = 平均 0.5s 🔵 *ヒアリング2026-08-03（2間隔の平均で確定）*
- [ ] **TC-016-02**: トグル切替 → 分布が再計算され母数併記が変わる 🔵

#### 異常系・境界値
- [ ] **TC-106-E01**: 10 本中 1 本だけ時刻欠損のラリー → ラリーごと対象外・除外数を併記（部分欠損はノイズのため） 🔵 *ヒアリング2026-08-03（全ショット時刻ありの条件はユーザ指定）*
- [ ] **TC-106-E02**: ショット2本（全て時刻あり）のラリー → 平均テンポは対象、終盤テンポは対象外 🔵 *ヒアリング2026-08-03 確定*
- [ ] **TC-106-B01**: ラリー時間 0（同時刻）→ 対象外（EDGE-104） 🔵 *ヒアリング2026-08-03 確定*

## REQ-017〜019 / REQ-203: L セット推移チャート 🔵

### Given
- セットに確定ラリーが記録されている（動画アラインメント有無は混在可）

### When
- セットタブを選択し、チャート上のラリーをタップする

### Then
- 取ったら +1 / 取られたら −1 の階段折れ線（視点 = 選択中の選手/ペアのチーム）
- 3 連続以上の連取/連失に色帯、最大連取/連失の注記、11 点インターバル目印
- タップでその時点のスコア表示 + 該当ラリーへ動画ジャンプ + ラリー一覧の連動選択

### テストケース

#### 正常系
- [ ] **TC-017-01**: 勝敗系列 ○○○●●●●○ → 折れ線 +1,+2,+3,+2,+1,0,−1,0。4連失区間に色帯・「最大連失 4」注記 🔵
- [ ] **TC-018-01**: 11-8 到達ラリーの位置にインターバル目印 🔵
- [ ] **TC-019-01**: ラリータップ → スコア「14-11」表示・動画が該当 ms（既定 2 秒前、stats-dashboard REQ-015 踏襲）から再生 🔵

#### 異常系・境界値
- [ ] **TC-019-E01**: `video_start_timestamp_ms IS NULL` のラリータップ → ジャンプ不可の非リンク表示（既存 EDGE-103 踏襲） 🔵
- [ ] **TC-203-01**: 記録途中のセット（12ラリーまで）→ 12ラリーまで描画 🔵
- [ ] **TC-017-B01**: レットラリーを挟む系列 → レットは折れ線に点を作らない 🔵
