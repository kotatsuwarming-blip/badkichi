## エピック1: 動画を見たまま打点を入力する

### ストーリー 1.1: セットの最初にコートを教える（コート校正） 🔵

**信頼性**: 🔵 *ヒアリング2026-08-28（案A）+ note.md §2-1*

**私は** 試合動画に打点を後付けする注釈者 **として**
**セットの最初に動画上でコートの 4 隅を順にタップし、以降の打点タップをシステムに座標変換させたい**
**そうすることで** 毎打ごとに頭の中でカメラ視点を真上視点に変換してコート図を探す作業をなくせる

**関連要件**: REQ-001, REQ-002, REQ-003, REQ-005, REQ-008

**詳細シナリオ**:
1. 打点パスを開始すると「コート校正」のステップが表示される（未校正のセット）
2. ガイドに従い、手前左 → 手前右 → 奥右 → 奥左 の順に外周の隅をタップする（間違えたら直前の 1 点を取り消す）
3. 4 点目を打つとコートライン（外周・ネット・センター・サービスライン）が動画上に投影される
4. 実際のラインと重なっていることを目視で確認し、確定する。ズレていればやり直す
5. 校正はセットに保存され、次回このセットを開いたときはすぐ打点入力に入れる

**前提条件**:
- カメラは固定（三脚）で、コートの外周 4 隅が映像内に映っている
- 動画がロード済み（ローカルは再選択済み）

**優先度**: Must Have

### ストーリー 1.2: 選手の足元をタップするだけで打点が入る 🔵

**信頼性**: 🔵 *ヒアリング2026-08-28（案A）+ note.md §1/§2-2*

**私は** 注釈者 **として**
**動画フレーム上で打った選手の足元をタップするだけで打点が保存され、次のショットへ進みたい**
**そうすることで** 視線とカーソルを動画とコート図の間で往復させずに済み、長ラリーでも疲れず速く入力できる

**関連要件**: REQ-009, REQ-010, REQ-011, REQ-012, REQ-013, REQ-014, NFR-001, NFR-201

**詳細シナリオ**:
1. 校正済みセットの打点パスで、動画上に「打った選手の足元をタップ」のガイドが出る
2. ローカル動画: 静止フレーム上の足元をクリック。YouTube: スローループ中の足元をクリック
3. タップ点が動画上とミニマップの両方に点で表示され、次のショットへ自動前進する
4. 種別キー（数字・QWE・Shift）は今までどおり同時に押せる。Backspace で取り消し、skip で飛ばす
5. 動画面をクリックしても再生/停止は切り替わらない（プレーヤー操作はコントロールバーで行う）

**前提条件**:
- ストーリー 1.1 の校正が保存されている

**優先度**: Must Have

### ストーリー 1.3: 校正のズレに気付いて直す 🔵

**信頼性**: 🔵 *note.md §2-1（再校正ボタン）+ 🟡 REQ-005（ガイド線）*

**私は** 注釈者 **として**
**打点入力中もコートラインの投影を表示でき、三脚がズレたらすぐ再校正したい**
**そうすることで** ズレたまま何十打も入力してしまう事故を防げる

**関連要件**: REQ-004, REQ-005, REQ-102, EDGE-103

**詳細シナリオ**:
1. 入力中にガイド線を ON にすると、投影されたラインが実ラインから外れていることに気付く
2. 「再校正」ボタンを押し、4 隅を打ち直す
3. 以降のタップは新しい校正で変換される。すでに保存した座標はそのまま

**優先度**: Must Have

---

### ストーリー 1.4: 前セットの校正を使い回す 🟡

**信頼性**: 🟡 *note.md §5-2 への提案値（interview-record Q4）*

**私は** 注釈者 **として**
**2 セット目以降はワンタップで前セットの校正を引き継ぎたい**
**そうすることで** カメラが動いていないのに毎セット 4 隅を打ち直す手間を省ける

**関連要件**: REQ-007, REQ-008, REQ-109

**詳細シナリオ**:
1. 2 セット目の打点パスに入ると「前セットと同じ校正を使う」の選択肢が出る
2. 選ぶと即座に校正済みになり、ガイド線で妥当性を確認できる
3. 三脚を動かしていた場合は「新しく校正する」を選ぶ

**優先度**: Should Have

## エピック2: 落下点も同じ仕組みで

### ストーリー 2.1: 決着の落下点も動画上でタップする 🟡

**信頼性**: 🟡 *note.md §2-5 + §5-3 への提案値（interview-record Q5）*

**私は** 注釈者 **として**
**クイックパスの落下点入力でも、停止した動画フレーム上の落下地点を直接タップしたい**
**そうすることで** 決着ごとのコート図への視線移動もなくせる

**関連要件**: REQ-015, EDGE-101

**詳細シナリオ**:
1. クイックパスで end_reason に `floor` を選ぶと落下点ステップになり、動画上にタップ受付が出る
2. 落下地点（ライン外なら外のその場所）をタップする
3. 変換された座標が `land_x/land_y` に保存され、out 細分は座標から導出される
4. 校正していないセットや落下点が映っていない場合は、従来どおりミニマップで入力するかスキップする

**優先度**: Should Have

## エピック3: 校正できない動画・既存データとの共存

### ストーリー 3.1: 校正できない動画でも従来どおり入力できる 🟡

**信頼性**: 🟡 *note.md §5-1 への提案値（interview-record Q3）*

**私は** 注釈者 **として**
**コートの隅が映っていない動画では校正をスキップし、今までのコート図タップで入力を続けたい**
**そうすることで** 動画の撮り方に関係なく打点パスを完走できる

**関連要件**: REQ-006, REQ-011, REQ-101, REQ-202, EDGE-004

**詳細シナリオ**:
1. 校正ステップで「スキップ」を選ぶ
2. 動画タップは無効のまま、ミニマップ（従来のコート図）でタップ入力する
3. 後から校正したくなったら「再校正」ボタンから入れる

**優先度**: Must Have

---

### ストーリー 3.2: 既存の打点データと統計がそのまま使える 🔵

**信頼性**: 🔵 *note.md §2-3 + shot-stats REQ-105*

**私は** チームの分析担当 **として**
**動画タップで入力した打点と、以前コート図で入力した打点が同じ座標系で混在し、配球ヒートマップ等の統計にそのまま反映されてほしい**
**そうすることで** 入力方法の切替でデータが分断されない

**関連要件**: REQ-002, REQ-107, REQ-403, REQ-016

**詳細シナリオ**:
1. 動画タップで入力した打点が、ミニマップ上で「見たまま」の位置に表示される（カメラ手前が下）
2. shot-stats の配球ヒートマップ（F）で、新旧の打点が同じ選手視点変換で集計される
3. コートチェンジ後のラリーも、再校正なしに正しく統計に載る

**優先度**: Must Have
