## REQ-401: ホモグラフィ純関数 🔵

**信頼性**: 🔵 *note.md §4（4 点 DLT・外部ライブラリ不要・純関数 + 単体テスト）*

### Given
- 4 組の点対応（映像座標 → 単位矩形）

### When
- ホモグラフィを算出し、順変換 / 逆変換を適用する

### Then
- 4 隅がそれぞれ対応先へ写る（誤差 1e-9 以内）
- 逆変換 → 順変換の往復が恒等になる
- 退化した入力は算出を拒否する

### テストケース

#### 正常系
- [ ] **TC-401-01**: 単位正方形 → 単位正方形の 4 点対応 → 恒等変換（任意点が同じ座標に写る） 🔵
- [ ] **TC-401-02**: 台形（透視で奥が狭い典型形）→ 単位矩形。4 隅が (0,1)/(1,1)/(1,0)/(0,0) へ写り、台形の辺の中点がコート端の中点 (0.5,1)/(1,0.5) 等へ写る 🔵
- [ ] **TC-401-03**: 台形の対角線交点 → (0.5, 0.5)（射影不変量: 対角線交点は中心へ写る） 🔵
- [ ] **TC-401-04**: 順変換 → 逆変換の往復で元の映像座標に戻る（誤差 1e-9） 🔵
- [ ] **TC-401-05**: コート外（台形の外側）の点 → 範囲外値（<0 / >1）が返る。クランプされない（EDGE-101） 🔵

#### 異常系
- [ ] **TC-401-E01**: 3 点が共線の入力 → 退化として拒否（null / エラー値） 🔵
- [ ] **TC-401-E02**: 2 点が同一の入力 → 退化として拒否 🔵
- [ ] **TC-401-E03**: 自己交差（ねじれ）した四角形 → 非凸として拒否（REQ-103） 🔵
- [ ] **TC-401-E04**: 消失線の向こう側の点を順変換 → 同次座標 w ≤ 0 を検出し「無効」を返す（REQ-104） 🟡

## REQ-001〜003 / REQ-407: コート校正の状態機械と保存 🔵

**信頼性**: 🔵 *note.md §2-1/§2-6*

### Given
- 校正済み / 未校正のセットを含む試合で打点パスを開いている
- 動画がロード済み

### When
- 4 隅を順にタップし確定する

### Then
- 4 点の映像座標が再生面の正規化座標（0〜1）で保存される（REQ-406）
- 再読込後、同じセットで校正が復元される
- 再校正は上書きされる

### テストケース

#### 正常系
- [ ] **TC-001-01**: 手前左 → 手前右 → 奥右 → 奥左 の順に 4 タップ → 校正確定可能状態になる 🔵
- [ ] **TC-001-02**: 3 点目の後に「1 点取り消し」→ 3 点目の再入力待ちに戻る 🔵
- [ ] **TC-002-01**: 4 隅の対応先が (0,1)/(1,1)/(1,0)/(0,0)。台形の手前辺の中点をタップ → 変換結果 y ≈ 1、x ≈ 0.5（カメラ手前 = y=1） 🔵
- [ ] **TC-003-01**: 校正確定 → set_id をキーに保存され、ページ再読込後に同セットで復元される 🔵
- [ ] **TC-003-02**: 再校正で確定 → 同セットの校正が上書きされ、行/値は 1 つのまま 🔵
- [ ] **TC-406-01**: ウィンドウ幅を変えて再読込 → 復元した校正で同じ実位置のタップが同じ座標に変換される（EDGE-102） 🔵

#### 異常系
- [ ] **TC-103-01**: 共線・非凸・近接した 4 点で確定 → 保存されず、理由メッセージ + 再入力（REQ-103） 🔵
- [ ] **TC-108-01**: 校正保存の API が失敗 → クライアント側で校正を保持したまま動画タップが使え、toast が出る（REQ-108） 🔵
- [ ] **TC-105-01**: ローカル動画の再選択前 → 校正ステップも動画タップも無効、ミニマップのみ（REQ-105） 🔵
- [ ] **TC-NFR101-01**: 他 Group のメンバーが校正データを SELECT/INSERT/UPDATE → RLS で 0 件 / 拒否（integration） 🔵

## REQ-009〜014: 打点の動画直接タップ 🔵

**信頼性**: 🔵 *ヒアリング2026-08-28（案A）+ usePositionPass 現行実装*

### Given
- 校正済みセットで打点パスにいる
- 現在ショットが表示されている（ローカル: 静止フレーム / YouTube: スローループ）

### When
- 動画上の足元をタップする

### Then
- 変換した座標が `hit_x/hit_y` に保存され、次のショットへ前進する
- タップ点がミニマップと動画上に表示される
- 1/2 打目はサーバー/レシーバーが自動確定される
- YouTube では `annotated_timestamp_ms`（approx）が保存され、ローカルでは打刻を書かない

### テストケース

#### 正常系
- [ ] **TC-009-01**: 校正済みセットで動画タップ → `patchShot` が `hitX/hitY`（変換後）で呼ばれ、index が +1 される 🔵
- [ ] **TC-009-02**: 1 打目の動画タップ → `hitPlayerId = serverPlayerId` を同時保存。2 打目 → `receiverPlayerId`。3 打目以降 → hitPlayerId を書かない（2026-08-28 二択廃止） 🔵
- [ ] **TC-009-03**: YouTube でタップ → `annotatedTimestampMs`（round）+ `annotatedTimestampPrecision='approx'` を含む。ローカルでは含まない（REQ-106） 🔵
- [ ] **TC-011-01**: 動画タップ後、ミニマップの marker が変換後座標の位置に描画される 🔵
- [ ] **TC-011-02**: 校正済みでもミニマップをタップ → 同じ `setPosition` 経路で保存・前進（REQ-202） 🟡
- [ ] **TC-012-01**: 保存済みショットへ再訪 → 保存座標を逆変換した位置に動画上マーカーが出る 🟡
- [ ] **TC-013-01**: 動画タップ受付中に数字キー → `setType` が呼ばれ、前進しない（既存動作維持）。Backspace → undo + 位置復元 🔵
- [ ] **TC-014-01**: 動画タップ受付中に再生面をクリック → 再生/停止が切り替わらない。コントロールバーの再生ボタンは動く 🔵
- [ ] **TC-014-02**: YouTube でタップ受付中に再生面をクリック → iframe にフォーカスが移らず、YouTube 側の UI が反応しない 🔵
- [ ] **TC-010-01**: 打点パスの動画オーバーレイに「打った選手の足元をタップ」のガイド文言が表示される（i18n キー経由、REQ-405） 🔵

#### 異常系
- [ ] **TC-104-01**: 空（消失線の向こう側）をタップ → 保存されず警告、index は変わらない 🟡
- [ ] **TC-104-02**: 変換結果が閾値（例: [-1, 2]）外 → 保存されず警告 🟡
- [ ] **TC-101-01**: 未校正セットで動画をタップ → 何も保存されず、校正導線が表示される。ミニマップタップは保存される 🟡

## REQ-004 / 005 / 102: 再校正とガイド線 🔵

**信頼性**: 🔵 *note.md §2-1/§2-6* + 🟡 *REQ-005*

### Given
- 校正済みセットで入力中

### When
- ガイド線を ON にする / 再校正する

### Then
- 逆変換したコートラインが動画上に描画される
- 再校正後、以降のタップのみ新しい変換で保存される

### テストケース

#### 正常系
- [ ] **TC-005-01**: 校正確定直後、外周・ネット・センター・ショートサービスラインが動画上に描画される 🟡
- [ ] **TC-005-02**: ガイド線トグル OFF → 描画が消える。ON → 再表示 🟡
- [ ] **TC-004-01**: 打点パス中に「再校正」→ 校正ステップへ入り、巡回位置（index）は変わらない（REQ-201） 🔵
- [ ] **TC-102-01**: 再校正の前に保存した `hit_x/hit_y` が、再校正後も変化しない 🔵
- [ ] **TC-107-01**: セット途中で `camera_near_team` が反転したラリー（コートチェンジ）に進む → 校正・ガイド線はそのまま。再校正の促しが出ない（EDGE-105） 🔵

## REQ-006〜008 / 109: 校正導線・引き継ぎ・セット切替 🟡

**信頼性**: 🟡 *note.md §5-2 への提案値（interview-record Q4）*

### Given
- セット 1 が校正済み、セット 2 が未校正

### When
- セット 2 の打点パスに入る / セット 2 のラリーへジャンプする

### Then
- 「前セットと同じ」「新しく校正」「スキップ」の選択肢が出る
- 引き継いだ場合もセット 2 の校正として保存される

### テストケース

#### 正常系
- [ ] **TC-006-01**: 未校正セットで打点パス開始 → 校正ステップが提示され、スキップするとミニマップ入力になる 🟡
- [ ] **TC-007-01**: 「前セットと同じ」→ セット 1 の 4 点がセット 2 に保存され、即座に校正済みになる 🟡
- [ ] **TC-008-01**: パネルに校正状態バッジ（校正済み / 未校正 / 引き継ぎ）が出る 🟡
- [ ] **TC-109-01**: ラリー一覧からセット 2 のラリーへジャンプ → 校正がセット 2 のものに切り替わり、ガイド線が更新される（EDGE-106） 🔵
- [ ] **TC-203-01**: ローカル動画のフレームオフセット校正（冒頭 3 ショット）と、コート校正が同時に進行でき、UI の文言で区別できる 🔵

## REQ-015: 落下点の動画タップ 🟡

**信頼性**: 🟡 *note.md §2-5 + §5-3 への提案値（interview-record Q5）*
