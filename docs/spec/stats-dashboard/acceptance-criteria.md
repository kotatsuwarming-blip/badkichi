## REQ-003 / REQ-101: サービス/レシーブ得点率の算出 🔵

**信頼性**: 🔵 *PRD §F-04 + ヒアリング2026-06-06 + rallies 定義*

### 算出式（確定）

確定ラリー（`is_let=false` かつ `point_winner IS NOT NULL` かつ `is_point_confirmed=true`）のみを対象とする。

- **サービス時得点率(P)** = (P がサーバーのラリーのうち、サーブ側チーム = `serving_team` が `point_winner` のラリー数) ÷ (P がサーバーのラリー総数)
- **レシーブ時得点率(P)** = (P がレシーバーのラリーのうち、レシーブ側チーム = `serving_team` の相手が `point_winner` のラリー数) ÷ (P がレシーバーのラリー総数)

### Given / When / Then

- **Given**: 確定ラリー・レット・未確定が混在する 1 試合
- **When**: ダッシュボードを開く
- **Then**: レット・未確定を除外した母数で選手別得点率が算出・表示され、母数が併記される

### テストケース（集計 util の単体テスト）

#### 正常系
- [ ] **TC-003-01**: P がサーバーの確定ラリー 4 件中 3 件でサーブ側得点 → サービス時得点率 75%（母数 4） 🔵

#### 分岐 / 異常系
- [ ] **TC-101-01**: レット（`is_let=true`）と未確定（`is_point_confirmed=false`）を含む入力 → それらは母数・分子の双方から除外される 🔵
- [ ] **TC-202-01**: P がサーバーのラリーが 0 件 → 0 除算せず「-」/未算出を返す（EDGE-001） 🔵

#### 境界値
- [ ] **TC-003-B01**: 確定ラリー全件でサーブ側得点 → 100%、全件で失点 → 0% 🔵
